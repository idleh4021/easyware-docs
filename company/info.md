# 회사정보

지금 사용 중인 **회사의 기본정보**(회사명, 대표자, 연락처, 주소 등)를 확인하고 수정하는 화면입니다. 관리자에게는 **구독·결제 상태**도 함께 표시됩니다.

> 📷 **[이미지]** 단계별 일러스트: ① 회사관리 > 회사정보 열기 → ② 구독·결제 상태 확인(관리자) → ③ 회사 기본정보 수정 → ④ 저장 흐름을 한 장으로 보여주는 그림

| 사용자     | 할 수 있는 것                                |
| ------- | --------------------------------------- |
| **관리자** | 구독·결제 상태 확인, 회사 기본정보 수정                  |
| 일반 사용자  | 회사 기본정보 조회만 가능                           |

***

### 1. 구독 · 결제 상태 (관리자)

> 📷 **[이미지]** 회사정보 화면 위쪽의 '구독 · 결제 상태' 영역 (이용 상태·사용만료일/다음 자동결제일·보유 포인트·월사용료 · 자동결제 카드 4개와 아래 안내 문구, '포인트관리로 이동' 링크가 보이도록)

관리자에게만 표시되며, EasyWare 사용료와 관련된 상태를 카드 4개로 보여줍니다.

| 카드              | 내용                                                         |
| --------------- | ---------------------------------------------------------- |
| **이용 상태**       | **정상 이용 중 / 무료체험 중 / 유예 기간 중 / 사용 중지** 중 하나                    |
| **기한**          | 상태에 따라 **다음 자동결제일 / 무료체험 종료일 / 유예 종료일 / 사용만료일** 과 남은 일수 (예: _N일 남음_, _오늘 만료_) |
| **보유 포인트**      | 지금 가진 포인트와 원 환산 금액. 월사용료보다 적으면 _"월사용료보다 N 부족합니다. 포인트를 충전해주세요."_ 가 표시됩니다. |
| **월사용료 · 자동결제** | 매달 차감되는 사용료와 **자동결제 사용 / 자동결제 중지** 여부                       |

카드 아래에는 지금 상태에 맞는 안내 문구가 표시됩니다.

| 이용 상태      | 안내 예시                                                                     |
| ---------- | ------------------------------------------------------------------------- |
| 정상 이용 중    | 다음 자동결제일에 월사용료가 보유 포인트에서 자동 결제됩니다.                                        |
| 무료체험 중     | 무료체험이 끝나는 날 월사용료가 보유 포인트에서 자동 결제됩니다.                                      |
| 유예 기간 중    | 포인트가 부족해 월사용료가 결제되지 않았습니다. 유예 종료일까지 충전하지 않으면 사용이 중지됩니다.                    |
| 사용 중지      | 포인트가 부족해 월사용료가 결제되지 않아 사용이 중지되었습니다. 조회만 가능하며, 포인트가 충전되면 다시 사용할 수 있습니다.      |

자동결제를 중지한 상태라면 그에 맞는 안내가 표시됩니다.

{% hint style="info" %}
포인트 충전 내역, 자동결제 켜기·끄기는 오른쪽 위 **포인트관리로 이동**을 눌러 [포인트 관리](point.md)에서 처리합니다.
{% endhint %}

{% hint style="success" %}
체험 기업은 _"체험 기업은 사용료가 부과되지 않습니다."_ 만 표시됩니다.
{% endhint %}

### 2. 회사 기본정보

> 📷 **[이미지]** '회사 기본정보' 영역 (회사 코드·사업자번호(읽기 전용), 회사명·대표자·연락처·이메일 입력란, 주소의 우편번호·주소 검색·직접 입력·상세주소, 오른쪽 위 저장 버튼이 보이도록)

| 항목    |  필수 | 수정 | 설명                       |
| ----- | :-: | :-: | ------------------------ |
| 회사 코드 |     |  ❌  | 회사를 구분하는 코드              |
| 사업자번호 |     |  ❌  | 회사의 사업자등록번호              |
| 회사명   |  ✅  |  ✅  | 회사 이름                    |
| 대표자   |     |  ✅  | 대표자 이름                   |
| 연락처   |     |  ✅  | 회사 대표 연락처                |
| 이메일   |     |  ✅  | 회사 대표 이메일                |
| 주소    |     |  ✅  | 우편번호·기본주소·상세주소 (아래 2.2 참고) |

#### 2.1 수정 방법

1. 고칠 항목을 입력합니다.
2. 오른쪽 위의 💾 **저장**을 누릅니다.
3. _"회사 정보가 저장되었습니다."_ 가 표시됩니다.

회사명을 비우고 저장하면 _"회사명을 입력해주세요."_ 가 표시됩니다.

#### 2.2 주소 입력

1. **주소 검색**을 누르고 주소를 검색해서 고릅니다. 우편번호와 기본주소가 채워집니다.
2. **상세주소 (동·호수 등)** 를 입력합니다.

검색으로 찾을 수 없는 주소는 **직접 입력**을 눌러 기본주소를 직접 입력할 수 있습니다.

#### 2.3 수정할 수 없는 경우

아래 경우에는 입력란이 회색으로 잠기고, 사유가 표시됩니다.

| 상황              | 안내                                 |
| --------------- | ---------------------------------- |
| 관리자가 아님         | 회사 정보는 관리자만 수정할 수 있습니다.             |
| 체험 기업           | 체험 기업 정보는 수정할 수 없습니다.               |
| 사용 중지 상태        | 사용이 중지되어 회사 정보를 저장할 수 없습니다.         |

### 3. 자주 묻는 질문 (FAQ)

**Q. 사업자번호를 바꾸고 싶어요.** \
회사 코드와 사업자번호는 이 화면에서 바꿀 수 없습니다. [시스템 문의](../support/system-inquiry.md)로 요청해 주세요.

**Q. 구독 · 결제 상태가 안 보여요.** \
관리자에게만 표시됩니다. 체험 기업은 사용료 안내 한 줄만 표시됩니다.

**Q. "사용 중지"로 나와요.** \
포인트가 부족하거나 자동결제가 중지되어 월사용료가 결제되지 않은 상태입니다. [포인트 관리](point.md)에서 포인트를 충전하거나 자동결제를 재개해 주세요. 사용 중지 상태에서는 조회만 할 수 있습니다.
