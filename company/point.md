# 포인트 관리

## 포인트관리

서비스 이용료를 내기 위한 **포인트 잔액**과 **사용기한**을 확인하고, **자동결제**를 켜고 끄며, 포인트가 들어오고 나간 **이력**을 조회하는 화면입니다.

| 메뉴 위치            | 사용할 수 있는 사람     |
| ---------------- | --------------- |
| **회사관리 > 포인트관리** | **관리자** 권한 사용자만 |

{% hint style="warning" %}
포인트관리는 **관리자만** 보고 사용할 수 있습니다. 일반 사용자에게는 메뉴가 표시되지 않습니다.&#x20;
{% endhint %}

### 1. 포인트와 이용료

#### 1.1 포인트 단위

| 단위     | 금액         |
| ------ | ---------- |
| **1p** | **1,000원** |

예) 30p = 30,000원, 12.5p = 12,500원

#### 1.2 이용료가 빠져나가는 방식

포인트를 **미리 충전**해 두면, **사용기한이 될 때마다 월사용료가 자동으로 차감**되고 사용기한이 연장됩니다. 이것을 **자동결제**라고 합니다.

```
포인트 충전  →  사용기한 도래  →  월사용료 자동 차감  →  사용기한 연장
```

#### 1.3 서비스 상태

사용기한이 되었을 때 월사용료를 낼 수 없으면 서비스 상태가 바뀝니다.

| 상태                                                   | 의미                                                       |
| ---------------------------------------------------- | -------------------------------------------------------- |
| <mark style="background-color:green;">**정상**</mark>  | 서비스를 정상적으로 이용할 수 있습니다.                                   |
| <mark style="background-color:orange;">**유예**</mark> | 사용기한이 지났지만 월사용료가 차감되지 않은 상태입니다. **3일 동안** 계속 이용할 수 있습니다. |
| <mark style="background-color:red;">**사용 제한**</mark> | 유예 기간이 끝난 상태입니다. **데이터 저장이 제한**됩니다.                      |

이런 경우 월사용료가 차감되지 않습니다.

* 잔액이 월사용료보다 **부족**할 때
* **자동결제를 중지**해 두었을 때 (아래 3. 참고)

```
정상 ──(사용기한 도래, 차감 안 됨)──▶ 유예 ──(3일 후)──▶ 사용 제한
  ▲                                    │                   │
  └──────(포인트 충전 또는 자동결제 재개 → 월사용료 차감)─────┘
```

{% hint style="success" %}
**유예나 사용 제한 상태라도** 포인트를 충전하거나 자동결제를 재개해서 월사용료가 차감되면 바로 **정상**으로 돌아옵니다.
{% endhint %}

### 2. 포인트 요약

화면 위쪽에 네 가지 정보가 표시됩니다.

| 항목              | 설명                                                                            |
| --------------- | ----------------------------------------------------------------------------- |
| **보유 포인트**      | 현재 잔액 (포인트와 원 금액 함께 표시)                                                       |
| **서비스 상태**      | 정상 / 유예 / 사용 제한. 사용기한이 가까우면 안내 문구가 함께 표시됩니다.                                  |
| **사용기한**        | 다음 월사용료가 차감되는 날짜. 기한이 없는 회사는 _"제한 없음"_ 으로 표시됩니다. 유예 상태이면 **유예 종료** 시각도 표시됩니다. |
| **월사용료 · 자동결제** | 사용기한마다 차감되는 금액과 자동결제 상태, **자동결제 중지 / 재개** 버튼                                  |

**월사용료 · 자동결제** 카드의 표시

| 자동결제 | 표시                                                      | 안내 문구                         |
| ---- | ------------------------------------------------------- | ----------------------------- |
| 사용 중 | <mark style="background-color:blue;">**자동결제 사용**</mark> | 사용기한 도래 시 자동 차감               |
| 중지됨  | **자동결제 중지**                                             | 다음 갱신 안 함 · 사용기한 후 유예 3일 뒤 제한 |

***

### 3. 자동결제 중지 / 재개

다음 사용기한에 월사용료가 빠져나가지 않게 하려면 자동결제를 **중지**합니다. 다시 이용하려면 **재개**합니다.

1. **월사용료 · 자동결제** 카드의 **⏸ 자동결제 중지**(또는 **▶ 자동결제 재개**)를 누릅니다.
2. 확인 창의 안내를 읽고 **중지**(또는 **재개**)를 누릅니다.

![](<../.gitbook/assets/image (47).png>)

#### 3.1 자동결제를 중지하면

{% hint style="warning" %}
* 중지 상태에서는 **포인트를 충전해도 월사용료가 차감되지 않습니다.**
* **이미 결제된 기간은 환불되지 않습니다.**
* **보유 포인트는 그대로 유지**됩니다.&#x20;
{% endhint %}

중지했을 때 언제부터 제한되는지는 현재 상태에 따라 다릅니다.

| 현재 상태     | 중지 후                                               |
| --------- | -------------------------------------------------- |
| **정상**    | **사용기한까지는 정상 이용**합니다. 사용기한이 지나면 유예 3일 후 저장이 제한됩니다. |
| **유예**    | 유예 종료 시각이 지나면 저장이 제한됩니다.                           |
| **사용 제한** | 그대로 사용 제한 상태입니다. 충전해도 풀리지 않습니다.                    |

완료되면 _"자동결제가 중지되었습니다. 사용기한까지는 정상 이용할 수 있습니다."_ 메시지가 표시됩니다.

{% hint style="info" %}
실수로 중지하지 않도록, 중지 확인 창에서는 **취소** 버튼이 먼저 선택되어 있습니다.
{% endhint %}

#### 3.2 자동결제를 재개하면

| 현재 상태          | 재개 후                                                        |
| -------------- | ----------------------------------------------------------- |
| **정상**         | 다음 사용기한에 월사용료가 자동 차감됩니다.                                    |
| **유예 / 사용 제한** | **재개 즉시 월사용료가 차감**되고 서비스가 복구됩니다. 잔액이 부족하면 포인트를 충전한 뒤 복구됩니다. |

**재개 결과 안내**

| 안내                                         | 의미                      |
| ------------------------------------------ | ----------------------- |
| 자동결제가 재개되었습니다.                             | 재개 완료 (정상 상태)           |
| …월사용료가 차감되어 사용기한이 연장되었습니다.                 | 재개와 함께 차감되어 **정상으로 복구** |
| …잔액이 월사용료보다 부족해 유예 상태가 유지됩니다. 포인트를 충전해주세요. | 잔액 부족                   |
| …잔액이 월사용료보다 부족해 사용 제한이 유지됩니다. 포인트를 충전해주세요. | 잔액 부족                   |
| …월사용료 청구 중 오류가 발생했습니다. 잠시 후 다시 확인해주세요.     | 재개는 되었지만 차감 중 오류        |

#### 3.3 버튼이 보이지 않는 경우

**체험 계정**이거나 **사용기한이 없는(과금 대상이 아닌) 회사**는 자동결제 버튼이 표시되지 않습니다.

***

### 4. 포인트 충전 ( 개발중)

{% hint style="warning" %}
현재 베타버전으로, 포인트 충전없이 사용하실 수 있습니다.
{% endhint %}

충전한 포인트는 확인 후 지급되며, 지급되면 **포인트 이력**에 기록됩니다. 자동결제를 사용 중이고 유예·사용 제한 상태였다면, 충전과 함께 월사용료가 차감되어 정상으로 돌아옵니다.

***

### 5. 포인트 이력

#### 5.1 조회 조건

| 항목   | 설명                                                               |
| ---- | ---------------------------------------------------------------- |
| 유형   | 포인트 유형으로 걸러봅니다. 여러 개를 선택할 수 있습니다.                                |
| 조회기간 | 체크하면 날짜를 입력할 수 있습니다. (기본값: 한 달 전 \~ 오늘) 체크하지 않으면 기간 제한 없이 조회합니다. |

조건을 정한 뒤 **🔍 조회**를 누릅니다. 화면에 들어오면 전체 이력이 자동으로 조회됩니다.

#### 5.2 이력 컬럼

| 컬럼  | 설명                                                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------- |
| 일시  | 처리된 일시 (한국 시간)                                                                                                               |
| 유형  | 포인트 유형 (색상 뱃지)                                                                                                               |
| 증감  | 늘어난 포인트는 <mark style="color:blue;">**+파란색**</mark>, 줄어든 포인트는 <mark style="color:red;">**−빨간색**</mark>. 마우스를 올리면 원 금액이 표시됩니다. |
| 잔액  | 처리 후 남은 포인트                                                                                                                  |
| 청구월 | 월사용료 차감인 경우 어느 달 사용료인지                                                                                                       |
| 비고  | 처리 사유                                                                                                                        |
| 처리자 | 처리한 사람. 자동 차감처럼 시스템이 처리한 경우 _"시스템"_                                                                                          |

한 페이지에 **100건**씩 표시됩니다. 하단에서 바꿀 수 있습니다.

### 6. 자주 묻는 질문 (FAQ)

**Q. 포인트관리 메뉴가 보이지 않아요.** \
포인트관리는 **관리자**만 사용할 수 있는 메뉴입니다. \
회사의 관리자에게 요청해 주세요.

**Q. 다른 직원도 포인트를 볼 수 있게 하고 싶어요.** \
해당 직원의 권한을 **관리자**로 바꿔야 합니다. \
권한은 [user](user/ "mention")에서 변경할 수 있습니다.

**Q. 월사용료는 언제 빠져나가나요?** \
자동결제를 사용 중이면 **사용기한**이 되는 시점에 자동으로 차감되고, 사용기한이 연장됩니다.

**Q. 서비스를 그만 쓰고 싶어요.** \
**자동결제 중지**를 누르세요. \
사용기한까지는 그대로 이용할 수 있고, 이후 유예 3일이 지나면 저장이 제한됩니다. \
이미 결제된 기간은 환불되지 않습니다.

**Q. 자동결제를 중지하면 남은 포인트는 어떻게 되나요?** \
그대로 유지됩니다. 나중에 자동결제를 재개하면 남은 포인트로 월사용료가 차감됩니다.

**Q. 충전했는데 아직 "사용 제한"이에요.** \
두 가지를 확인해 주세요.

1. **자동결제가 중지**되어 있으면 충전해도 차감되지 않습니다. **자동결제 재개**를 누르세요.
2. 잔액이 **월사용료보다 적으면** 상태가 그대로입니다. 보유 포인트와 월사용료를 비교해 주세요.

**Q. 서비스 상태가 "유예"로 바뀌었어요.** \
사용기한이 되었는데 월사용료가 차감되지 않은 상태입니다. \
**유예 종료** 시각 전에 포인트를 충전하거나 자동결제를 재개해 주세요.

**Q. 자동결제 버튼이 보이지 않아요.** \
체험 계정이거나 과금 대상이 아닌(사용기한이 없는) 회사입니다.

**Q. 포인트가 소수점으로 표시돼요.** \
1p = 1,000원이라 원 단위 금액은 소수점으로 표시됩니다. \
(예: 12,500원 = 12.5p) 증감에 마우스를 올리면 원 금액을 볼 수 있습니다.

**Q. 처리자가 "시스템"으로 나와요.** \
월사용료 자동 차감처럼 시스템이 처리한 내역입니다.

**Q. 포인트 이력이 잘못된 것 같아요.** \
[system-inquiry.md](../support/system-inquiry.md "mention")로 해당 일시와 내용을 알려주세요.

**Q.** 포인트를 환불받고 싶어요. \
[system-inquiry.md](../support/system-inquiry.md "mention")로 남겨주세요.
