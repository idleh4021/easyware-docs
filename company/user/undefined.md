# 사용자 정보

내 **이름·연락처**를 수정하고, **이메일**과 **비밀번호**를 바꾸고, 소속된 **회사 목록**을 확인하거나 회사에서 **나가거나 계정을 탈퇴**할 수 있는 팝업창입니다.

<figure><img src="../../.gitbook/assets/image (55).png" alt=""><figcaption></figcaption></figure>

***

### 1. 여는 방법

1. 화면 오른쪽 위의 **내 이름(프로필)** 을 누릅니다.
2. 메뉴에서 **👤 사용자 정보**를 누릅니다.

<figure><img src="../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
**권한대기** 상태여도 사용자 정보는 열 수 있습니다. 사업자번호를 잘못 입력해 엉뚱한 회사에 합류했다면, 여기서 그 회사를 직접 나갈 수 있습니다.&#x20;
{% endhint %}

**닫기**: 오른쪽 위 **✕**, 팝업창 바깥 클릭, 또는 `Esc` (저장하지 않은 수정 내용이 있으면 _"저장하지 않은 변경사항이 있습니다. 닫으시겠습니까?"_ 확인 창이 나타납니다.)

***

### 2. 계정 정보

| 항목  |  필수 | 설명                                   |
| --- | :-: | ------------------------------------ |
| 아이디 |     | 로그인 아이디. **변경할 수 없습니다.**             |
| 이름  |  ✅  | 최대 50자                               |
| 이메일 |     | 주소와 **인증됨 / 미인증** 상태 표시. 여기서 직접 고치지 않고 **이메일 변경** 버튼으로 바꿉니다. (아래 3. 참고) |
| 연락처 |     | 숫자와 `-`만, 8\~15자. 예: `010-0000-0000` |

1. 바꿀 항목을 수정합니다.
2. **저장**을 누릅니다. (수정한 내용이 있을 때만 누를 수 있습니다.)
3. _"저장되었습니다."_ 가 표시되면 완료입니다.

| 상황        | 안내 메시지                  |
| --------- | ----------------------- |
| 이름이 비어 있음 | 이름을 입력해주세요.             |
| 연락처 형식 오류 | 숫자와 -만 입력해주세요. (8\~15자) |

{% hint style="info" %}
* 이름·연락처·이메일은 **소속된 모든 회사에 똑같이** 적용됩니다.
* **이메일 주소는 본인만** 볼 수 있습니다. 관리자 화면(사용자관리)에는 인증 여부만 표시됩니다.
* 이름을 바꾸면 화면 오른쪽 위의 이름도 바로 바뀝니다.
* 연락처를 지우고 저장하면 빈 값으로 저장됩니다.
{% endhint %}

### 3. 이메일 등록·변경

이메일은 **인증 메일의 링크를 눌러야** 바뀝니다. 이메일 칸 오른쪽 버튼은 상태에 따라 이름이 다릅니다.

| 현재 상태        | 버튼        |
| ------------ | --------- |
| 이메일 없음       | **이메일 등록** |
| 이메일 있음, 미인증  | **이메일 수정** |
| 이메일 인증됨      | **이메일 변경** |

1. 버튼을 누릅니다.
2. **새 이메일**과 **현재 비밀번호**를 입력합니다.
3. **인증 메일 보내기**를 누릅니다.
4. _"인증 메일을 보냈어요. 메일함을 확인해주세요."_ 가 표시되면 새 이메일의 메일함에서 링크를 누릅니다.
5. 인증이 끝나면 새 이메일로 바뀝니다.

{% hint style="info" %}
* 인증된 이메일을 바꾸는 중이면 **인증을 마칠 때까지 지금 이메일이 그대로** 유지됩니다. 이메일 칸 아래에 _"(새 주소)(으)로 변경하려면 메일의 링크를 눌러 인증해주세요."_ 가 표시됩니다.
* 메일을 못 받았다면 **인증 메일 다시 보내기**를 누르세요. (1분에 한 번, 하루 횟수 제한이 있습니다.)
* 이메일이 바뀌면 이전 이메일로 **\[EasyWare] 계정 이메일이 변경되었어요** 알림 메일이 갑니다.
* 인증 링크는 **24시간** 동안 한 번만 사용할 수 있습니다.
{% endhint %}

| 안내 메시지                         | 의미                       |
| ------------------------------ | ------------------------ |
| 지금 쓰고 있는 이메일이에요. 다른 이메일을 입력해주세요. | 지금 인증된 이메일과 같은 주소를 입력했습니다. |
| 이메일 형식이 올바르지 않아요.              | 이메일 주소 형식이 틀렸습니다.        |
| 현재 비밀번호가 일치하지 않아요.             | 현재 비밀번호를 잘못 입력했습니다.      |
| 인증 메일을 방금 보냈어요. 1분 뒤에 다시 시도해주세요. | 1분 안에 다시 요청했습니다.         |

### 4. 비밀번호 변경

1. 계정 정보 아래의 **비밀번호 변경**을 누릅니다.
2. **현재 비밀번호**, **새 비밀번호**, **새 비밀번호 확인**을 입력합니다.
3. **변경**을 누릅니다.
4. _"비밀번호가 변경되었어요. 다른 기기에서는 다시 로그인해야 해요."_ 가 표시되면 완료입니다.

| 상황               | 안내 메시지                               |
| ---------------- | ------------------------------------ |
| 비밀번호 규칙에 맞지 않음   | 비밀번호는 8자 이상이며 특수문자를 1개 이상 포함해야 합니다. |
| 현재 비밀번호와 같음      | 현재 비밀번호와 다른 비밀번호를 입력해주세요.            |
| 새 비밀번호 확인이 다름    | 새 비밀번호와 비밀번호 확인이 일치하지 않습니다.          |
| 현재 비밀번호가 틀림      | 현재 비밀번호가 일치하지 않아요.                   |
| 여러 번 틀려 잠김       | 비밀번호를 여러 번 잘못 입력했어요. 잠시 후 다시 시도해주세요. |

{% hint style="info" %}
* 비밀번호를 바꾸면 **지금 쓰는 기기는 그대로** 로그인되어 있고, **다른 기기에서는 다시 로그인**해야 합니다.
* 현재 비밀번호를 잊었다면 로그아웃한 뒤 로그인 화면의 **비밀번호 찾기**를 이용하세요. ([계정과 회사구조 이해하기](../../getting-started/undefined.md) 5.1 참고)
{% endhint %}

{% hint style="warning" %}
**현재 비밀번호를 30분 안에 5번 틀리면 잠시 잠깁니다.** 비밀번호 변경·이메일 변경·회사 나가기·계정 탈퇴에서 입력한 비밀번호 오류 횟수가 **합산**됩니다. 잠기면 잠시 후 다시 시도하세요.
{% endhint %}

### 5. 소속 회사

내가 소속된 회사가 모두 표시됩니다. 제목 옆 숫자는 소속 회사 수입니다.

| 표시        | 설명                                                                           |
| --------- | ---------------------------------------------------------------------------- |
| 회사명       | 소속 회사. 지금 로그인한 회사에는<mark style="color:blue;">**접속 중**</mark> 표시              |
| 권한 / 부서   | 그 회사에서의 내 권한과 부서. 아직 권한을 받지 못했으면 <mark style="color:orange;">**권한대기**</mark> |
| 합류일       | 그 회사에 합류한 날                                                                  |
| **퇴사** 버튼 | 그 회사에서 나가기 (아래 6. 참고)                                                        |

{% hint style="info" %}
권한과 부서는 여기서 바꿀 수 없습니다. **각 회사의 관리자**가 사용자관리에서 변경합니다.
{% endhint %}

***

### 6. 회사 나가기

소속 회사에서 직접 나갈 수 있습니다.

1. 나갈 회사 줄의 **퇴사** 버튼을 누릅니다.
2. 펼쳐진 **안내 문구**를 확인합니다.
3. **비밀번호**를 입력합니다.
4. **회사 나가기**를 누릅니다. (`Enter`도 가능)

그만두려면 **취소**를 누르세요.

<figure><img src="../../.gitbook/assets/image (57).png" alt=""><figcaption></figcaption></figure>

#### 6.1 나가는 회사에 따라 달라지는 결과

| 나가는 회사          | 안내 문구                                                         | 결과                                                       |
| --------------- | ------------------------------------------------------------- | -------------------------------------------------------- |
| 접속 중이 **아닌** 회사 | 이 회사의 데이터에 더 이상 접근할 수 없습니다. 다시 합류하려면 '회사 추가' 후 관리자 승인이 필요합니다. | 목록에서 사라지고 계속 이용할 수 있습니다.                                 |
| 지금 **접속 중인** 회사 | 현재 접속 중인 회사입니다. 나가면 로그아웃되며, 다른 회사로 다시 로그인해야 합니다.              | _"(회사명)에서 나갔습니다. 다시 로그인해주세요."_ 후 **로그인 화면**으로 이동         |
| **마지막** 소속 회사   | 마지막 소속 회사입니다. 나가면 계정도 함께 탈퇴되어 다시 로그인할 수 없으며, 되돌릴 수 없습니다.     | _"회사에서 나갔습니다. 소속 회사가 없어 계정도 함께 탈퇴되었습니다."_ 후 **로그인 화면**으로 이동 |

{% hint style="danger" %}
**마지막 소속 회사에서 나가면 계정도 함께 탈퇴됩니다.** 계정 탈퇴와 똑같이 개인정보가 정리되며(아래 7.2 참고), 다시 사용하려면 새로 회원가입해야 합니다.
{% endhint %}

#### 6.2 나가면 어떻게 되나요?

* 그 회사에 **더 이상 접속할 수 없고**, 그 회사의 데이터와 이력도 볼 수 없습니다.
* 내가 처리한 입출고 등의 **기록은 회사에 그대로 남습니다.**
* **다른 회사의 소속에는 영향이 없습니다.**
* 관리자의 **복직처리로 되돌릴 수 없습니다.** 다시 합류하려면 **회사 추가** 후 그 회사 관리자의 승인을 받아야 합니다.

| 안내 메시지        | 의미                    |
| ------------- | --------------------- |
| 비밀번호를 입력해주세요. | 비밀번호가 비어 있습니다.        |
| (서버가 알려주는 사유) | 비밀번호가 틀렸거나 나갈 수 없는 경우 |

{% hint style="warning" %}
**관리자**라면 나가기 전에 다른 사람을 관리자로 지정해 주세요. 회사에는 관리자가 최소 1명 있어야 합니다.&#x20;
{% endhint %}

### 7. 계정 탈퇴

**모든 소속 회사에서 한 번에 나가고 계정을 삭제**합니다. 사용자 정보 팝업창 **맨 아래**에 있습니다.

1. 맨 아래의 **계정 탈퇴**를 누릅니다.
2. 안내 내용을 확인합니다.
3. **현재 비밀번호**를 입력합니다.
4. **탈퇴**를 누릅니다.
5. 로그아웃되고 로그인 화면으로 이동합니다.

#### 7.1 탈퇴하면 이렇게 처리됩니다

* 소속된 **모든 회사**에서 나가게 됩니다.
* **이 아이디로 다시 로그인할 수 없습니다.**
* 탈퇴 후에는 **되돌릴 수 없습니다.**
* 회사에 남은 등록 기록(입출고 등)에는 **이름만** 남습니다.

#### 7.2 정리되는 개인정보

| 정보          | 탈퇴 후                                    |
| ----------- | --------------------------------------- |
| 아이디         | 삭제 (회사 화면에는 **"탈퇴한 사용자"** 로 표시)          |
| 이메일·연락처·비고  | 삭제                                      |
| 비밀번호        | 사용할 수 없게 처리                             |
| 이름          | 누가 처리했는지 확인할 수 있도록 회사 기록에 남김             |
| 로그인 상태      | **모든 기기에서 로그아웃**                        |

{% hint style="warning" %}
* **한 회사만 그만두려면** 계정 탈퇴 대신 소속 회사 목록에서 그 회사의 **퇴사** 버튼(회사 나가기)을 이용하세요. 나머지 회사는 계속 이용할 수 있습니다.
* 소속 회사 중 **내가 유일한 관리자인 회사**가 있으면 탈퇴할 수 없습니다. _"'(회사명)'에 다른 관리자가 없어요. 다른 사용자에게 관리자 권한을 위임한 뒤 탈퇴해주세요."_ 가 표시되면 그 회사에서 다른 사람을 관리자로 지정한 뒤 다시 시도하세요.
* 현재 비밀번호 오류는 비밀번호 변경과 횟수가 합산됩니다. (4. 비밀번호 변경 참고)
{% endhint %}

### 8. 자주 묻는 질문 (FAQ)

**Q. 아이디를 바꾸고 싶어요.**&#x20;

아이디는 변경할 수 없습니다.

**Q. A 회사에서 이름을 바꿨는데 B 회사에서도 바뀌었어요.** \
정상입니다. 이름·연락처·이메일은 계정 정보라 모든 회사에 똑같이 적용됩니다.

**Q. 이메일 칸을 직접 수정할 수 없어요.** \
이메일은 **이메일 변경** 버튼으로 바꿉니다. 새 이메일로 온 인증 메일의 링크를 눌러야 반영됩니다.

**Q. 이메일을 바꿨는데 예전 이메일이 그대로 보여요.** \
새 이메일의 인증을 아직 마치지 않았습니다. 새 메일함에서 인증 메일의 링크를 눌러 주세요.

**Q. 비밀번호를 바꿨더니 다른 PC에서 로그아웃됐어요.** \
정상입니다. 비밀번호를 바꾸면 지금 쓰는 기기를 제외한 다른 기기에서는 다시 로그인해야 합니다.

**Q. "비밀번호를 여러 번 잘못 입력했어요"라고 나와요.** \
현재 비밀번호를 30분 안에 5번 틀려 잠시 잠겼습니다. 잠시 후 다시 시도하세요. \
비밀번호가 기억나지 않으면 로그인 화면의 **비밀번호 찾기**를 이용하세요.

**Q. 내 권한이나 부서를 바꾸고 싶어요.** \
그 회사의 **관리자**에게 요청해 주세요.

**Q. 잘못된 회사에 합류했어요. 권한대기라 아무것도 못 해요.** \
권한대기 상태에서도 사용자 정보는 열 수 있습니다. \
올바른 회사를 먼저 **회사 추가**한 뒤, 잘못 합류한 회사를 **회사 나가기** 하세요. \
그 회사가 유일한 소속일 때 먼저 나가면 계정이 탈퇴 처리됩니다.

**Q. 탈퇴하고 싶어요.** \
팝업창 맨 아래의 **계정 탈퇴**를 누르세요. 모든 회사에서 한 번에 나가고 계정이 삭제됩니다.

**Q. 탈퇴하려는데 "다른 관리자가 없어요"라고 나와요.** \
그 회사의 관리자가 나 혼자이기 때문입니다. 사용자관리에서 다른 사람을 관리자로 지정한 뒤 다시 탈퇴하세요.

**Q. 탈퇴한 아이디로 다시 가입할 수 있나요?** \
탈퇴하면 아이디가 삭제되므로, 같은 아이디로 새로 회원가입할 수 있습니다. 단, 이전 계정의 소속·권한은 이어지지 않습니다.

**Q. 회사 나가기를 눌렀는데 로그인 화면으로 이동했어요.** \
