# 사용자 정보

내 **이름·이메일·연락처**를 수정하고, 소속된 **회사 목록**을 확인하거나 회사에서 **나갈** 수 있는 팝업창입니다.

<figure><img src="../../.gitbook/assets/image (55).png" alt=""><figcaption></figcaption></figure>

***

### 1. 여는 방법

1. 화면 오른쪽 위의 **내 이름(프로필)** 을 누릅니다.
2. 메뉴에서 **👤 사용자 정보**를 누릅니다.

<figure><img src="../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
**권한대기** 상태여도 사용자 정보는 열 수 있습니다. 사업자번호를 잘못 입력해 엉뚱한 회사에 합류했다면, 여기서 그 회사를 직접 나갈 수 있습니다.&#x20;
{% endhint %}

**닫기**: 오른쪽 위 **✕**, 팝업창 바깥 클릭, 또는 `Esc` (저장하지 않은 수정 내용이 있으면 _"저장하지 않은 변경사항이 있습니다. 닫으시겠습니까?"_ 확인 창이 나타납니다.)

***

### 2. 계정 정보

| 항목  |  필수 | 설명                                   |
| --- | :-: | ------------------------------------ |
| 아이디 |     | 로그인 아이디. **변경할 수 없습니다.**             |
| 이름  |  ✅  | 최대 50자                               |
| 이메일 |     | 예: `example@company.com`             |
| 연락처 |     | 숫자와 `-`만, 8\~15자. 예: `010-0000-0000` |

1. 바꿀 항목을 수정합니다.
2. **저장**을 누릅니다. (수정한 내용이 있을 때만 누를 수 있습니다.)
3. _"저장되었습니다."_ 가 표시되면 완료입니다.

| 상황        | 안내 메시지                  |
| --------- | ----------------------- |
| 이름이 비어 있음 | 이름을 입력해주세요.             |
| 이메일 형식 오류 | 이메일 형식이 올바르지 않습니다.      |
| 연락처 형식 오류 | 숫자와 -만 입력해주세요. (8\~15자) |

{% hint style="info" %}
* 이름·이메일·연락처는 **소속된 모든 회사에 똑같이** 적용됩니다.
* 이름을 바꾸면 화면 오른쪽 위의 이름도 바로 바뀝니다.
* 이메일·연락처를 지우고 저장하면 빈 값으로 저장됩니다.
{% endhint %}

***

### 3. 소속 회사

내가 소속된 회사가 모두 표시됩니다. 제목 옆 숫자는 소속 회사 수입니다.

| 표시        | 설명                                                                           |
| --------- | ---------------------------------------------------------------------------- |
| 회사명       | 소속 회사. 지금 로그인한 회사에는<mark style="color:blue;">**접속 중**</mark> 표시              |
| 권한 / 부서   | 그 회사에서의 내 권한과 부서. 아직 권한을 받지 못했으면 <mark style="color:orange;">**권한대기**</mark> |
| 합류일       | 그 회사에 합류한 날                                                                  |
| **퇴사** 버튼 | 그 회사에서 나가기 (아래 4. 참고)                                                        |

{% hint style="info" %}
권한과 부서는 여기서 바꿀 수 없습니다. **각 회사의 관리자**가 사용자관리에서 변경합니다.
{% endhint %}

***

### 4. 회사 나가기

소속 회사에서 직접 나갈 수 있습니다.

1. 나갈 회사 줄의 **퇴사** 버튼을 누릅니다.
2. 펼쳐진 **안내 문구**를 확인합니다.
3. **비밀번호**를 입력합니다.
4. **회사 나가기**를 누릅니다. (`Enter`도 가능)

그만두려면 **취소**를 누르세요.

<figure><img src="../../.gitbook/assets/image (57).png" alt=""><figcaption></figcaption></figure>

#### 4.1 나가는 회사에 따라 달라지는 결과

| 나가는 회사          | 안내 문구                                                         | 결과                                                       |
| --------------- | ------------------------------------------------------------- | -------------------------------------------------------- |
| 접속 중이 **아닌** 회사 | 이 회사의 데이터에 더 이상 접근할 수 없습니다. 다시 합류하려면 '회사 추가' 후 관리자 승인이 필요합니다. | 목록에서 사라지고 계속 이용할 수 있습니다.                                 |
| 지금 **접속 중인** 회사 | 현재 접속 중인 회사입니다. 나가면 로그아웃되며, 다른 회사로 다시 로그인해야 합니다.              | _"(회사명)에서 나갔습니다. 다시 로그인해주세요."_ 후 **로그인 화면**으로 이동         |
| **마지막** 소속 회사   | 마지막 소속 회사입니다. 나가면 계정이 종료되어 더 이상 로그인할 수 없습니다.                  | _"회사에서 나갔습니다. 소속 회사가 없어 계정이 종료되었습니다."_ 후 **로그인 화면**으로 이동 |

{% hint style="danger" %}
**마지막 소속 회사에서 나가면 계정이 종료됩니다.** 다시 사용하려면 새로 회원가입해야 합니다.
{% endhint %}

#### 4.2 나가면 어떻게 되나요?

* 그 회사에 **더 이상 접속할 수 없고**, 그 회사의 데이터와 이력도 볼 수 없습니다.
* 내가 처리한 입출고 등의 **기록은 회사에 그대로 남습니다.**
* **다른 회사의 소속에는 영향이 없습니다.**
* 관리자의 **복직처리로 되돌릴 수 없습니다.** 다시 합류하려면 **회사 추가** 후 그 회사 관리자의 승인을 받아야 합니다.

| 안내 메시지        | 의미                    |
| ------------- | --------------------- |
| 비밀번호를 입력해주세요. | 비밀번호가 비어 있습니다.        |
| (서버가 알려주는 사유) | 비밀번호가 틀렸거나 나갈 수 없는 경우 |

{% hint style="warning" %}
**관리자**라면 나가기 전에 다른 사람을 관리자로 지정해 주세요. 회사에는 관리자가 최소 1명 있어야 합니다.&#x20;
{% endhint %}

### 5. 자주 묻는 질문 (FAQ)

**Q. 아이디를 바꾸고 싶어요.**&#x20;

아이디는 변경할 수 없습니다.

**Q. A 회사에서 이름을 바꿨는데 B 회사에서도 바뀌었어요.** \
정상입니다. 이름·이메일·연락처는 계정 정보라 모든 회사에 똑같이 적용됩니다.

**Q. 내 권한이나 부서를 바꾸고 싶어요.** \
그 회사의 **관리자**에게 요청해 주세요.

**Q. 잘못된 회사에 합류했어요. 권한대기라 아무것도 못 해요.** \
권한대기 상태에서도 사용자 정보는 열 수 있습니다. \
올바른 회사를 먼저 **회사 추가**한 뒤, 잘못 합류한 회사를 **회사 나가기** 하세요. \
그 회사가 유일한 소속일 때 먼저 나가면 계정이 종료됩니다.

**Q. 탈퇴하고 싶어요.** \
소속 회사를 모두 **회사 나가기** 하세요. \
마지막 회사에서 나갈 때 계정이 종료됩니다.

**Q. 회사 나가기를 눌렀는데 로그인 화면으로 이동했어요.** \
**접속 중인 회사**에서 나갔기 때문입니다. \
다른 소속 회사로 다시 로그인하세요.

**Q. 실수로 회사에서 나갔어요.** \
**회사 추가**로 다시 합류하고, 그 회사 관리자에게 권한을 다시 받으세요.
