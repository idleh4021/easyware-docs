# 사용자 관리

회사에 소속된 사용자의 **권한, 부서**를 지정하고, 가입한 사용자를 **승인**하거나 **퇴사·복직처리**하는 화면입니다.

| 메뉴 위치            | 사용할 수 있는 사람                          |
| ---------------- | ------------------------------------ |
| **회사관리 > 사용자관리** | **관리자**: 조회·수정 / 일반 사용자: **조회만** |

{% hint style="warning" %}
사용자 관리 화면은 관리자만 수정할 수 있습니다. 관리자가 아닌 사용자에게는 _"조회 전용 · 변경은 관리자만 가능합니다"_ 가 표시되고, **승인 대기**·**퇴사처리**·**복직처리** 버튼이 보이지 않으며 **저장**이 비활성화됩니다.
{% endhint %}

### 1. 사용자 상태

| 상태                                                     | 의미                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| <mark style="background-color:blue;">**재직**</mark>     | 권한이 지정되어 업무를 할 수 있는 사용자                                    |
| <mark style="background-color:orange;">**승인대기**</mark> | 회사에 가입했거나 복직했지만 아직 **권한이 지정되지 않은** 사용자. 업무 기능을 사용할 수 없습니다. |
| **퇴사**                                                 | 퇴사처리되었거나 직접 회사를 나간 사용자. 이 회사에 접속할 수 없습니다.                  |

```
            가입                       권한 지정
  (신규) ─────────▶ 승인대기 ─────────────────▶ 재직
                       ▲                         │
                       │ 복직처리                │ 퇴사처리
                       └────────── 퇴사 ◀────────┘
```

#### 새 직원이 들어왔을 때

1. 직원이 **회사 사업자번호**로 회원가입합니다.
2. 사용자관리에 **승인대기**로 표시됩니다.
3. 관리자가 **권한**을 지정하고 저장합니다.
4. **재직** 상태가 되어 업무를 시작합니다.

{% hint style="success" %}
새 직원이 가입했는데 아무 기능도 쓸 수 없다고 하면, 사용자관리에서 **승인 대기** 버튼을 눌러 권한을 지정해 주세요.
{% endhint %}

### 2. 화면 구성

#### 2.1 상단 툴바

| 버튼/요소                                                      | 설명                                                          |
| ---------------------------------------------------------- | ----------------------------------------------------------- |
| 검색창                                                        | 아이디 또는 이름으로 검색합니다. `Enter`를 눌러도 조회됩니다.                      |
| 상태 선택                                                      | 조회할 사용자 상태를 고릅니다. 기본값은 **재직자**이며, 퇴사자는 상태를 바꿔야 보입니다.        |
| 🔍 조회                                                      | 조건에 맞는 사용자를 조회합니다.                                          |
| <mark style="background-color:orange;">**승인 대기 N명**</mark> | 권한 지정을 기다리는 사용자 수. 누르면 **승인대기 사용자만** 보이고, 다시 누르면 전체로 돌아갑니다. |
| 💾 저장                                                      | 그리드에서 수정한 내용을 저장합니다. 퇴사자를 조회 중일 때는 비활성화됩니다.                 |

#### 2.2 사용자 목록 컬럼

| 컬럼   | 설명                              |  수정 |
| ---- | ------------------------------- | :-: |
| 상태   | 재직 / 승인대기 / 퇴사                  |  —  |
| 아이디  | 로그인 아이디                         |  —  |
| 이름   | 사용자 이름                          |  —  |
| 권한   | 사용자의 권한 (클릭해서 선택)               |  ✅  |
| 부서   | 소속 부서 (클릭해서 선택, _부서 없음_ 가능)     |  ✅  |
| 이메일  | 이메일                             |  —  |
| 연락처  | 연락처                             |  —  |
| 비고   | 메모                              |  ✅  |
| 가입일  | 회사에 가입한 날                       |  —  |
| 퇴사일  | 퇴사한 날 (퇴사자를 조회할 때만 표시)          |  —  |
| (작업) | 재직자는 **퇴사처리**, 퇴사자는 **복직처리** 버튼 |  —  |

{% hint style="info" %}
* 아이디, 이름, 이메일, 연락처는 사용자 본인이 관리하는 정보라 여기서 수정할 수 없습니다.
* **퇴사자**는 회색으로 표시되며 수정할 수 없습니다. **복직처리**만 할 수 있습니다.&#x20;
{% endhint %}

### 3. 권한·부서 지정

1. 수정할 사용자의 **권한** 또는 **부서** 칸을 **한 번 클릭**합니다.
2. 목록에서 원하는 값을 선택합니다.
3. 필요하면 **비고**도 입력합니다.
4. 여러 사용자를 수정한 뒤 💾 **저장**을 누르면 한 번에 반영됩니다.

> 저장 완료! (N건)

| 상황        | 안내             |
| --------- | -------------- |
| 변경 사항이 없음 | 변경된 데이터가 없습니다. |
| 저장 실패     | 서버가 알려주는 사유 표시 |

{% hint style="warning" %}
저장은 **전부 성공하거나 전부 실패**합니다. 여러 명을 수정했는데 한 명이라도 문제가 있으면 아무것도 저장되지 않으니, 안내된 사유를 확인하고 다시 저장해 주세요.
{% endhint %}

#### 3.1 권한

권한은 사용자가 쓸 수 있는 기능을 정합니다.

| 권한        | 설명                                                  |
| --------- | --------------------------------------------------- |
| **관리자**   | 모든 메뉴 사용 가능. 포인트관리, 사용자관리 같은 관리자 전용 메뉴도 사용할 수 있습니다. |
| **일반사용자** | 관리자 전용 메뉴를 제외한 업무 메뉴 사용                             |

{% hint style="info" %}
회사에는 **관리자가 최소 1명** 있어야 합니다. 마지막 남은 관리자의 권한을 바꾸면 저장되지 않습니다.
{% endhint %}

{% hint style="warning" %}
**관리자 권한은 꼭 필요한 사람에게만** 주세요. 관리자는 다른 사용자의 권한을 바꾸고 퇴사·복직처리할 수 있으며, 포인트와 자동결제도 관리할 수 있습니다.
{% endhint %}

#### 3.2 부서

부서 목록은 부서 관리에 등록된 부서입니다. 원하는 부서가 없다면 부서 관리에서 먼저 등록해 주세요.

***

### 4. 퇴사처리

퇴사한 직원이 더 이상 회사에 접속하지 못하게 합니다.

1. 퇴사할 사용자 줄의 **퇴사처리** 버튼을 누릅니다.
2. 확인 창에서 **퇴사처리**를 누릅니다.

> 퇴사처리할까요? 홍길동(hong) 사용자는 퇴사 후 이 회사에 접속할 수 없습니다.

완료되면 _"퇴사처리되었습니다."_ 메시지가 표시되고 재직자 목록에서 사라집니다. 상태를 퇴사자로 바꿔 조회하면 볼 수 있습니다.

{% hint style="info" %}
* 퇴사처리해도 그 사용자가 등록한 **입출고 등의 기록은 그대로 남습니다.**
* **본인**은 퇴사처리할 수 없습니다. (본인 줄에는 버튼이 없습니다.)
* 실수로 누르지 않도록 확인 창에서는 **취소**가 먼저 선택되어 있습니다.
* 잘못 퇴사처리했다면 **복직처리**로 되돌릴 수 있습니다. (아래 5. 참고)
{% endhint %}

***

### 5. 복직처리

퇴사처리한 사용자를 다시 회사에 접속할 수 있게 합니다.

1. **상태**를 퇴사자로 바꿔 조회합니다.
2. 복직할 사용자 줄의 **복직처리** 버튼을 누릅니다.
3. 확인 창에서 **복직처리**를 누릅니다.

> 복직처리할까요? 홍길동(hong) 사용자가 다시 이 회사에 접속할 수 있게 됩니다. 권한은 '권한부여대기'로 초기화되니 복직 후 권한을 다시 지정해주세요.

완료되면 _"복직처리되었습니다."_ 메시지가 표시됩니다.

{% hint style="warning" %}
**복직하면 권한이 초기화되어 승인대기 상태가 됩니다.** 상태를 재직자로 바꾸고 **승인 대기** 버튼을 눌러 권한을 다시 지정해 주세요. 권한을 지정하기 전까지는 업무 기능을 사용할 수 없습니다.&#x20;
{% endhint %}

#### 5.1 복직할 수 없는 경우

| 안내 메시지                    | 의미                                             |
| ------------------------- | ---------------------------------------------- |
| 본인이 직접 나간 사용자는 복직할 수 없습니다 | 관리자가 퇴사처리한 것이 아니라 **사용자가 직접 회사를 나간** 경우입니다.    |
| 이미 재직 중인 사용자입니다           | 다른 관리자가 먼저 복직처리했거나 이미 재직 중입니다. 목록을 다시 조회해 주세요. |

{% hint style="info" %}
**직접 회사를 나간 사용자가 다시 합류하려면**

1. 사용자가 로그인한 뒤 오른쪽 위 회사 메뉴에서 **회사 추가**를 눌러 회사의 사업자번호로 다시 합류를 신청합니다.
2. 관리자가 사용자 관리에서 **승인 대기** 버튼을 눌러 그 사용자의 권한을 지정하고 저장합니다.

자세한 내용은 [계정과 회사구조 이해하기](../../getting-started/undefined.md)를 참고하세요.
{% endhint %}

### 6. 저장하지 않은 변경 내용

권한·부서·비고를 수정하고 저장하지 않은 상태에서 아래 동작을 하면 확인 창이 나타납니다.

* 조회, 상태 변경, **승인 대기** 버튼
* 페이지 이동, 표시 개수 변경
* 퇴사처리, 복직처리

> 저장하지 않은 변경 내용이 있습니다 변경 내용을 무시하고 진행할까요?

**진행**을 누르면 수정한 내용이 사라지고, **취소**를 누르면 그대로 돌아갑니다.

***

### 7. 체험 기업

체험(테스트) 기업으로 접속한 경우에는 **본인 정보만 조회**되며 수정할 수 없습니다.

* _"테스트 기업은 본인 정보만 조회됩니다"_ 안내가 표시됩니다.
* **승인 대기**, **퇴사처리**, **복직처리** 버튼이 표시되지 않고, **저장** 버튼이 비활성화됩니다.

***

### 8. 자주 묻는 질문 (FAQ)

**Q. 새 직원이 가입했는데 아무것도 할 수 없대요.** \
아직 **승인대기** 상태입니다. \
**승인 대기 N명** 버튼을 눌러 해당 직원에게 권한을 지정하고 저장해 주세요.

**Q. 직원을 사용자관리에서 직접 추가할 수 있나요?** \
아니요. 직원이 회원가입할 때 **회사 사업자번호**로 가입하면 이 화면에 승인대기로 표시됩니다.

**Q. 퇴사한 직원이 목록에 안 보여요.** \
기본적으로 재직자만 표시됩니다. **상태**를 퇴사  또는 전체로 바꿔 조회해 주세요.

**Q. 실수로 퇴사처리했어요.** \
상태를 퇴사로 바꿔 조회한 뒤 **복직처리**를 누르세요. \
복직하면 권한이 초기화되니 다시 지정해 주세요.

**Q. 복직시켰는데 아무것도 할 수 없대요.** \
복직하면 권한이 초기화되어 **승인대기** 상태가 됩니다. \
**승인 대기** 버튼을 눌러 권한을 다시 지정하고 저장해 주세요.

**Q. 복직처리 버튼을 눌렀는데 "본인이 직접 나간 사용자"라고 나와요.** \
그 사용자는 관리자가 퇴사처리한 것이 아니라 직접 회사를 나갔기 때문에 복직처리할 수 없습니다.

**Q. 퇴사자의 권한이나 부서를 바꿀 수 없어요.** \
퇴사자는 수정할 수 없습니다. \
복직처리 후 수정해 주세요.

**Q. 관리자 권한을 다른 사람에게 넘기고 싶어요.** \
먼저 다른 사람의 권한을 **관리자**로 바꿔 저장한 뒤, 본인의 권한을 바꾸세요. \
회사에는 관리자가 최소 1명 있어야 해서, 순서를 반대로 하면 저장되지 않습니다.

**Q. 내 줄에는 퇴사처리 버튼이 없어요.**\
&#x20;본인은 퇴사처리할 수 없습니다.

**Q. 이름이나 연락처를 바꾸고 싶어요.** \
이 화면에서는 수정할 수 없습니다. \
사용자 본인이 직접 수정해야 합니다.

**Q. 저장했는데 아무것도 반영되지 않았어요.** \
저장은 전부 성공하거나 전부 실패합니다. \
오류 메시지를 확인하고 문제가 된 사용자를 수정한 뒤 다시 저장해 주세요.
