# 구매내역

장비·소모품 구매에서 주문한 내역과 **배송 상태**를 확인하고, 필요하면 **주문을 취소**하는 화면입니다.

| 사용할 수 있는 사람    |
| -------------- |
| **관리자** 권한 사용자 |

<figure><img src="../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure>

**여는 방법**

* 장비·소모품 구매 화면 오른쪽 위의 **🧾 구매내역**
* 주문을 마치면 자동으로 구매내역으로 이동하고, 방금 주문한 **주문 상세가 바로 열립니다.**

구매내역 화면 오른쪽 위의 **🛒 장비·소모품 구매**를 누르면 구매 화면으로 돌아갑니다.

***

### 1. 주문 상태

```
주문접수  →  배송준비  →  배송중  →  배송완료
   │
   └─▶ 취소 (주문접수 상태에서만 직접 취소 가능)
```

| 상태       | 의미                          | 직접 취소 |
| -------- | --------------------------- | :---: |
| **주문접수** | 주문이 들어와 확인을 기다리는 상태         |   ✅   |
| **배송준비** | 상품을 준비하고 있는 상태              |   —   |
| **배송중**  | 발송되어 배송 중인 상태. 송장번호가 표시됩니다. |   —   |
| **배송완료** | 배송이 끝난 상태                   |   —   |
| **취소**   | 주문이 취소되어 포인트가 환불된 상태        |   —   |

***

### 2. 조회 조건

| 항목      | 설명                                                               |
| ------- | ---------------------------------------------------------------- |
| 상태      | 주문 상태로 걸러봅니다. 여러 개를 함께 선택할 수 있고, **전체**를 누르면 선택이 모두 해제됩니다.       |
| 주문번호·상품 | 주문번호 또는 상품명으로 검색합니다. `Enter`를 눌러도 조회됩니다.                         |
| 주문기간    | 체크하면 날짜를 입력할 수 있습니다. (기본값: 한 달 전 \~ 오늘) 체크하지 않으면 기간 제한 없이 조회합니다. |

조건을 정한 뒤 **🔍 조회**를 누릅니다. 화면에 들어오면 전체 주문이 자동으로 조회됩니다.

***

### 3. 주문 목록

| 컬럼   | 설명                            |
| ---- | ----------------------------- |
| 주문번호 | 주문을 구분하는 번호                   |
| 상태   | 주문 상태                         |
| 주문상품 | 주문한 상품 (여러 개면 대표 상품명으로 표시)    |
| 결제   | 결제한 포인트. 마우스를 올리면 원 금액이 보입니다. |
| 송장   | 택배사와 송장번호 (발송된 뒤에 표시)         |
| 주문일시 | 주문한 일시                        |
| 주문자  | 주문한 관리자                       |

목록에서 주문을 **클릭**하면 주문 상세가 열립니다. 한 페이지에 **50건**씩 표시됩니다.

{% hint style="info" %}
같은 회사의 다른 관리자가 주문한 내역도 함께 표시됩니다. **주문자**에서 누가 주문했는지 확인할 수 있습니다.&#x20;
{% endhint %}

### 4. 주문 상세

<figure><img src="../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure>

| 영역    | 내용                                                                       |
| ----- | ------------------------------------------------------------------------ |
| 주문 정보 | 상태, 주문일시, 주문자                                                            |
| 배송 정보 | 송장(택배사·송장번호), 발송일시, 배송완료 일시                                              |
| 주문 상품 | 상품별 단가·수량·금액. 옵션이 있으면 상품명 아래에 표시되고, 단가에 마우스를 올리면 **기본가 + 옵션 추가금**이 보입니다. |
| 결제 금액 | 상품금액, 배송비, 결제 포인트                                                        |
| 배송지   | 받는 분, 연락처, 주소, 요청사항                                                      |
| 취소 정보 | 취소된 주문만 표시. 취소일시, 환불 포인트, 취소 사유                                          |

{% hint style="success" %}
배송이 늦어진다면 주문 상세의 **송장번호**로 택배사 홈페이지에서 배송 위치를 확인할 수 있습니다.
{% endhint %}

### 5. 주문 취소

#### 5.1 직접 취소 (주문접수 상태)

**주문접수** 상태인 주문은 직접 취소할 수 있으며, **결제한 포인트 전액**이 환불됩니다.

1. 목록에서 취소할 주문을 클릭해 주문 상세를 엽니다.
2. 오른쪽 위의 **🚫 주문 취소**를 누릅니다.
3. 확인 창에서 **취소 사유**를 입력합니다. (선택)
4. **주문 취소**를 누릅니다.

> 주문을 취소하시겠습니까? N p가 포인트로 환불됩니다.

완료되면 _"주문이 취소되고 포인트가 환불되었습니다."_ 가 표시되고, 상태가 **취소**로 바뀝니다.

{% hint style="info" %}
* 실수로 취소하지 않도록 확인 창에서는 **닫기**가 먼저 선택되어 있습니다.
* 환불된 포인트는 바로 보유 포인트에 반영되고, 포인트관리의 포인트 이력에 기록됩니다. \{% endhint %\}
{% endhint %}

{% hint style="warning" %}
취소하는 사이에 상태가 **배송준비**로 바뀌었다면 취소되지 않고 안내 메시지가 표시됩니다. 주문 상세가 최신 상태로 다시 표시되니 확인해 주세요.
{% endhint %}

#### 5.2 배송준비 이후 취소·반품

**배송준비**나 **배송중** 상태에서는 직접 취소할 수 없습니다. 주문 상세에 다음 안내가 표시됩니다.

> 배송 준비가 시작되어 직접 취소할 수 없습니다. 취소·반품은 시스템 문의로 요청해주세요.

시스템문의에 **주문번호**와 취소·반품 사유를 남겨 주세요.

{% hint style="info" %}
배송준비 이후에 취소되면 배송비 등을 제외한 **일부 금액만 환불**될 수 있습니다. 이 경우 주문 상세의 환불 금액 옆에 _(결제 N p 중 일부)_ 로 표시됩니다.
{% endhint %}

### 6. 자주 묻는 질문 (FAQ)

**Q. 주문 취소 버튼이 보이지 않아요.** \
**주문접수** 상태일 때만 직접 취소할 수 있습니다. \
배송준비가 시작되었다면 시스템문의로 요청해 주세요.

**Q. 취소했는데 포인트가 돌아왔나요?** \
네. 주문접수 상태에서 취소하면 결제한 포인트가 **전액** 바로 환불됩니다. \
포인트관리의 이력에서 확인할 수 있습니다.

**Q. 일부 금액만 환불됐어요.** \
배송준비 이후에 취소·반품된 경우 일부만 환불될 수 있습니다.\
자세한 내용은 시스템문의로 문의해 주세요.

**Q. 송장번호가 보이지 않아요.** \
아직 발송되지 않은 주문입니다. \
발송되면 송장번호가 표시됩니다.

**Q. 다른 관리자가 주문한 내역도 보이나요?** \
네. 같은 회사의 주문은 모두 표시됩니다. \
**주문자**에서 누가 주문했는지 확인하세요.

**Q. 받은 상품이 불량이에요.** \
시스템문의에 주문번호와 증상을 사진과 함께 남겨 주세요.
