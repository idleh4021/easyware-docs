# 화면구성

EasyWare의 화면은 **조회는 메인 화면에서, 등록·수정·상세 확인은 팝업창에서** 하는 구조로 거의 모든 메뉴가 같은 방식으로 동작합니다.

[기준정보](https://app.gitbook.com/s/Pd5zp2Co7sL6fXg6Xfh6/master "mention") 메뉴는 이 구조에서 제외되며, 해당 메뉴 설명 페이지에서 따로 안내합니다.

### 메인 화면: 조회

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

* 상단의 조회 조건으로 원하는 데이터를 찾습니다.
* 아래 목록에서 조회 결과를 확인합니다.
* 목록의 행을 선택하면 상세정보 팝업이 열립니다.\
  ![](<../.gitbook/assets/image (3).png>)

### 팝업창: 등록, 수정, 상세 조회

<figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>

* **등록**: 메인 화면의 등록 버튼을 누르면 등록 팝업이 열립니다.
* **수정**: 목록에서 대상을 선택해 상세 팝업을 열고 수정합니다.
* **상세 조회**: 선택한 데이터의 자세한 내용을 팝업에서 확인합니다.

***

### 목록(표) 공통 기능

대부분의 화면에서 목록은 같은 방식으로 동작합니다.

> 📷 **[이미지]** 목록 아래쪽의 '12번째 / 전체 N건' 표시와, 툴바의 행 복제 버튼이 보이는 화면 예시

| 기능            | 사용 방법                                                                 |
| ------------- | --------------------------------------------------------------------- |
| **위치·건수 표시**  | 목록 아래에 _"12번째 / 전체 N건"_ 처럼 지금 클릭한 행의 위치와 전체 건수가 표시됩니다.                    |
| **바로 입력**     | 입력할 수 있는 칸은 **한 번 클릭**하면 바로 입력 상태가 됩니다. `Enter`로 확정, `Esc`로 취소합니다.          |
| **체크박스 선택**   | 행의 체크박스를 클릭하거나, 칸을 선택하고 `스페이스`를 누릅니다. 머리글의 체크박스로 전체 선택·해제합니다.           |
| **행 복제**      | 등록·수정 화면에서 복사할 행을 클릭하고 **행 복제**(또는 `Ctrl + Shift + Enter`)를 누르면 바로 아래에 복사됩니다. |

### 품목 검색

품목 칸에서 품목을 고를 때 열리는 **품목 검색** 팝업창에서는 품목명으로 검색할 수 있습니다. **상세조건**을 누르면 **대·중·소분류**로 범위를 좁힐 수 있고, 걸어 둔 분류 개수가 _상세조건 (N)_ 으로 표시됩니다.
