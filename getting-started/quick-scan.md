# 퀵스캔

**바코드 하나만 스캔해서 재고를 바로 확인**하는 기능입니다. 어느 화면에 있든 사이드바 맨 위의 **퀵스캔**을 눌러 쓸 수 있습니다.

> 📷 **[이미지]** 단계별 일러스트: ① 사이드바 '퀵스캔' 클릭 → ② 품목 라벨 또는 로케이션 바코드 스캔 → ③ 재고 상세 창에서 재고 확인 → ④ 창을 닫고 다음 바코드 스캔 흐름을 한 장으로 보여주는 그림

| 이런 경우에 사용합니다                       |
| ---------------------------------- |
| 손에 든 물건이 창고 어디에 얼마나 있는지 알고 싶을 때      |
| 랙 앞에서 이 로케이션에 무엇이 있는지 확인하고 싶을 때       |
| 메뉴를 옮기지 않고 작업 중에 잠깐 재고를 확인하고 싶을 때    |

***

### 1. 사용 방법

> 📷 **[이미지]** '퀵스캔' 창 (안내 문구 '품목 또는 로케이션 바코드로 재고를 조회합니다.'와 '품목/로케이션 바코드 스캔' 입력란이 보이도록)

1. 사이드바 맨 위의 **퀵스캔**을 누릅니다. (사이드바를 접어 둔 상태에서는 스캔 아이콘)
2. **품목/로케이션 바코드 스캔** 입력란에 바코드를 스캔합니다.
3. 바코드 종류에 맞춰 **재고 상세** 창이 열립니다.
4. 재고 상세 창을 닫으면 다시 퀵스캔 창으로 돌아와 **다음 바코드를 바로 스캔**할 수 있습니다.

| 스캔한 바코드       | 열리는 화면                                    |
| ------------- | ----------------------------------------- |
| **품목 라벨**     | 그 품목이 **어느 로케이션에** 얼마나 있는지 (품목 기준 재고 상세)  |
| **로케이션 바코드**  | 그 로케이션에 **어떤 품목이** 얼마나 있는지 (로케이션 기준 재고 상세) |

재고 상세 창의 사용법(로트번호 검색, 바코드 출력, SN 확인 등)은 [재고현황](../stock/stock.md)을 참고하세요.

{% hint style="success" %}
퀵스캔 창을 닫으려면 창 밖을 누르거나 오른쪽 위 ✕를 누르세요.
{% endhint %}

### 2. 안내 메시지

| 상황                          | 안내 메시지                              |
| --------------------------- | ----------------------------------- |
| 등록되지 않은 품목 바코드              | 등록되지 않은 품목입니다: (코드)                 |
| 등록되지 않은 로케이션 바코드            | 등록되지 않은 로케이션입니다: (코드)               |
| 같은 코드의 로케이션이 여러 창고에 있음      | 같은 코드의 로케이션이 여러 창고에 있습니다: (코드)      |
| 품목·로케이션 바코드가 아님             | 퀵스캔에서 지원하지 않는 바코드 타입입니다              |

{% hint style="info" %}
**같은 코드의 로케이션이 여러 창고에 있다**고 나오면, [로케이션관리](../master/location.md)에서 출력한 EasyWare 로케이션 라벨을 스캔하세요. 이 라벨에는 창고 정보가 함께 들어 있습니다.
{% endhint %}

### 3. 자주 묻는 질문 (FAQ)

**Q. 출고계획서 QR을 스캔했는데 안 돼요.** \
퀵스캔은 **품목 라벨과 로케이션 바코드**만 조회합니다. 출고계획·피킹 QR은 각 작업 화면에서 스캔하세요.

**Q. 품목을 스캔했는데 재고가 안 보여요.** \
그 품목의 재고가 없는 상태입니다. 입고가 끝났는지 [가입고](../inbound/pre-inbound.md)·[입고(적치)](../inbound/putaway.md)를 확인해 보세요.
