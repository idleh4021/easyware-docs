# 대시보드

EasyWare에 로그인하면 처음 보이는 화면입니다. **지금 처리해야 할 작업과 주의가 필요한 항목**을 한눈에 확인하고, 카드를 눌러 해당 화면으로 바로 이동할 수 있습니다.

> 📷 **[이미지]** 단계별 일러스트: ① 로그인 후 대시보드 확인 → ② 대기 중인 작업 카드 클릭 → ③ 해당 작업 화면으로 이동해 처리 흐름을 한 장으로 보여주는 그림

사이드바 맨 위의 **대시보드** 메뉴나 왼쪽 위 **EasyWare** 로고를 누르면 언제든 이 화면으로 돌아옵니다.

***

### 1. 화면 구성

> 📷 **[이미지]** PC 대시보드 전체 (위쪽 창고 선택·새로고침, KPI 카드 4개, 작업 흐름, 주의 알림, 입출고 수량 추이, 기타입출고 사유, 관리자 영역이 보이도록)

| 영역          | 내용                                       | 표시 화면     |
| ----------- | ---------------------------------------- | --------- |
| ① 창고 선택·새로고침 | 볼 창고를 고르고 최신 수치로 새로고침합니다.               | PC·모바일    |
| ② 대기 작업 카드  | 가입고·적치·가출고·출고 대기 수                       | PC·모바일    |
| ③ 작업 흐름     | 입고·출고 단계별로 다음 작업을 기다리는 건수                | PC        |
| ③ 바로 작업하기   | 현장 작업 4단계로 바로 이동하는 목록                    | 모바일       |
| ④ 주의 알림     | 확인이 필요한 재고·마감 항목                         | PC·모바일    |
| ⑤ 입출고 수량 추이 | 최근 며칠간 입고·출고 수량 막대그래프                    | PC        |
| ⑥ 기타입출고 사유  | 이번 달 기타입출고 사유 비율                         | PC        |
| ⑦ 관리자       | 포인트·사용기한·권한부여 대기·문의 현황                  | 관리자만      |

***

### 2. 창고 선택과 새로고침

* 오른쪽 위에서 **창고**를 고르면 그 창고 기준으로 수치가 바뀝니다.
* **새로고침**을 누르면 최신 수치로 다시 불러옵니다. 옆에 **기준일**과 **갱신 시각**이 표시됩니다.

{% hint style="info" %}
창고 선택은 입고계획·마이너스 재고·재고마감·기타입출고 사유에 적용됩니다. 입고존·출고존·출고계획은 창고 구분이 없어 **회사 전체 기준**으로 집계되며, 이런 항목에는 **전체 기준** 표시가 붙습니다.
{% endhint %}

***

### 3. 대기 작업 카드

지금 다음 단계를 기다리는 작업량입니다. 카드를 누르면 해당 화면으로 이동합니다(**바로가기 →**).

| 카드         | 설명         | 의미                                   |
| ---------- | ---------- | ------------------------------------ |
| **가입고 대기** | 확정 입고계획    | 확정됐지만 아직 가입고하지 않은 입고계획 라인 수          |
| **적치 대기**  | 입고존 보관     | 가입고 후 아직 적치하지 않고 입고존에 있는 품목 수         |
| **가출고 대기** | 계획 대비 잔여   | 아직 가출고하지 않은 출고계획 라인 수                |
| **출고 대기**  | 출고존 보관     | 가출고 후 아직 출고하지 않고 출고존에 있는 품목 수         |

카드 아래에는 해당 **수량**도 함께 표시됩니다.

***

### 4. 작업 흐름 (PC)

입고와 출고를 단계별로 나눠 **다음 작업을 기다리는 건수**를 보여줍니다. 단계를 누르면 해당 화면으로 이동합니다.

| 흐름 | 단계와 표시                                                                 |
| -- | ---------------------------------------------------------------------- |
| 입고 | 입고계획(작성 중) → 가입고(라인 대기) → 적치(품목 대기)                                    |
| 출고 | 출고계획(작성 중) → 피킹(진행 중) → 가출고(라인 잔여) → 출고(품목 대기)                         |

아래에는 **오늘 가입고 / 오늘 적치 / 오늘 가출고 / 오늘 출고** 처리 건수가 표시됩니다.

#### 바로 작업하기 (모바일)

모바일에서는 작업 흐름 대신 현장 작업 4단계(**가입고, 적치, 가출고, 출고**)로 바로 이동하는 목록이 표시됩니다.

> 📷 **[이미지]** 모바일 대시보드 (KPI 카드와 '바로 작업하기' 목록, 주의 알림이 보이도록)

***

### 5. 주의 알림

확인이 필요한 항목을 **위험 / 주의 / 안내**로 구분해 보여줍니다. 알림을 누르면 관련 화면으로 이동합니다. 문제가 없으면 _"확인이 필요한 항목이 없습니다."_ 가 표시됩니다.

| 알림                | 내용                                         | 확인할 곳                                |
| ----------------- | ------------------------------------------ | ------------------------------------ |
| **마이너스 재고**       | 수량이 0보다 적은 재고가 있습니다.                       | [재고현황](../stock/stock.md)            |
| **출고존 장기 체류**     | 가출고 후 일정 기간 이상 출고되지 않은 재고가 있습니다.            | [출고](../outbound-1.md)               |
| **입고존 적치 지연**     | 가입고 후 일정 기간 이상 적치되지 않은 재고가 있습니다.            | [입고(적치)](../inbound/putaway.md)      |
| **재고마감 필요**       | 마지막 마감 후 시간이 지난 창고가 있습니다. (또는 마감 이력 없음)     | [재고마감](../stock/close.md)            |
| **재고실사 조정**       | 최근 재고실사로 입출고 조정이 발생했습니다.                   | [재고수불부](../stock/history.md)         |

{% hint style="warning" %}
**재고마감 필요** 알림이 보이면 지난달 마감을 진행하세요. 3개월 넘게 마감하지 않으면 재고수불부에 재고수량이 표시되지 않습니다.
{% endhint %}

출고존 장기 체류와 입고존 적치 지연 알림에는 기준 일수와 수량이 함께 표시됩니다. (예: _가출고 후 N일 이상 미출고_)

***

### 6. 입출고 수량 추이 (PC)

최근 며칠간의 날짜별 **입고(파랑)·출고** 수량을 막대그래프로 보여줍니다. 막대에 마우스를 올리면 그날의 입고·출고 수량이 표시됩니다. 회사 전체 기준입니다.

{% hint style="info" %}
가입고·기타입고 / 실제출고·기타출고 기준입니다. 적치·가출고·재고이동·실사조정은 재고 위치만 바뀌거나 조정이라 포함하지 않습니다.
{% endhint %}

***

### 7. 기타입출고 사유 (PC)

이번 달 [기타입출고](../stock/etc-in-out.md)를 **사유별 건수와 비율**로 보여줍니다. 파손·분실처럼 특정 사유가 많다면 원인을 점검해 보세요.

### 9. 자주 묻는 질문 (FAQ)

**Q. 창고를 골랐는데 일부 수치가 바뀌지 않아요.** \
입고존·출고존·출고계획 관련 수치는 창고 구분이 없어 **회사 전체 기준**입니다. **전체 기준** 표시가 붙은 항목입니다.

**Q. 방금 처리한 작업이 반영되지 않았어요.** \
오른쪽 위의 **새로고침**을 눌러 주세요.

**Q. 관리자 영역이 안 보여요.** \
관리자 권한이 있는 사용자에게만 표시됩니다.
