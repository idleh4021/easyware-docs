# 입고(적치)

[가입고](pre-inbound.md)로 **입고존에 들어온 물건을 실제 보관할 로케이션으로 옮기는(적치)** 화면입니다. 적치를 완료하면 재고가 입고존에서 목적지 로케이션으로 이동합니다.

> 📷 **[이미지]** 단계별 일러스트: ① 입고존의 물건 → ② 품목 라벨 스캔 → ③ 보관할 랙의 로케이션 바코드 스캔 → ④ 적치 완료(재고가 로케이션으로 이동) 흐름을 한 장으로 보여주는 그림

```
입고존 (가입고된 재고)  →  적치  →  보관 로케이션 (예: A-1-3)
```

{% hint style="warning" %}
적치는 **적치 완료**를 누르는 즉시 재고 위치에 반영되며, 완료한 뒤에는 **수정하거나 삭제할 수 없습니다.** 잘못 적치했다면 [재고이동](../stock/move.md)으로 바로잡아 주세요.
{% endhint %}

{% hint style="info" %}
**입고존·출고존으로는 적치할 수 없습니다.** 목적지는 실제 보관 로케이션만 선택할 수 있습니다.
{% endhint %}

### 2. 적치 등록

목록 오른쪽 위의 **➕ 신규**를 누르면 등록 팝업창이 열립니다.

> 📷 **[이미지]** 입고(적치) 신규 등록 팝업창 (입고일자·제목·비고, '바코드 스캔 (품목 또는 로케이션)' 영역의 품목/목적지 로케이션 칸과 🔒 고정 버튼, 아래 적치 예정 목록이 보이도록)

#### 2.1 등록 순서

1. 적치할 라인을 추가합니다. 방법은 두 가지입니다.
   * **바코드 스캔** — 품목 라벨과 로케이션 바코드를 스캔합니다. (아래 2.2 참고, 권장)
   * **➕ 추가** — 품목과 목적지 로케이션을 직접 선택합니다. (아래 2.3 참고)
2. 라인마다 **적치수량**과 **목적지 로케이션**을 확인합니다.
3. 💾 **적치 완료**를 클릭합니다.

완료되면 _"입고(적치)가 완료되었습니다. (N건)"_ 메시지가 표시됩니다.

**상단 입력 항목**

| 항목   | 설명                                    |
| ---- | ------------------------------------- |
| 입고일자 | 적치한 날짜                                |
| 제목   | 적치 품목을 추가하면 자동으로 만들어집니다.              |
| 비고   | 문서 전체에 대한 메모                          |

#### 2.2 바코드 스캔

**바코드 스캔 (품목 또는 로케이션)** 영역에 **품목**과 **목적지 로케이션** 두 칸이 있습니다. 두 칸이 모두 채워지면 라인이 자동으로 추가됩니다.

1. 물건에 붙은 **품목 라벨**을 스캔합니다. 입고존에서 그 품목의 재고를 찾아 **품목** 칸에 표시합니다. (품목명 · 로트 · 수량)
2. 보관할 랙의 **로케이션 바코드**를 스캔합니다.
3. 라인이 추가되면 **적치수량**을 확인하고, 일부만 적치한다면 수량을 고칩니다.

순서는 상관없습니다. 로케이션을 먼저 스캔해도 됩니다.

{% hint style="info" %}
스캔으로 추가한 라인의 적치수량은 그 재고의 **입고존 남은 수량 전체**로 채워집니다. SN 관리 품목은 스캔한 SN 개수가 적치수량이 됩니다.
{% endhint %}

**스캔 결과에 따른 동작**

| 상황                                 | 동작                                                         |
| ---------------------------------- | ---------------------------------------------------------- |
| 입고존에 일치하는 재고가 하나                   | 품목 칸이 채워집니다.                                               |
| 일치하는 재고가 여러 건                      | **적치 대기 재고 선택** 창이 열립니다. 적치할 재고를 고르세요. (아래 2.4 참고)      |
| 같은 품목·같은 로케이션 라인이 이미 있음             | 새 라인 대신 **기존 라인에 수량(또는 SN)이 합산**됩니다.                       |
| LOT 관리 품목인데 라벨에 로트번호가 없음            | _"로트번호가 포함된 바코드를 다시 스캔해주세요."_                              |
| 입고존에 그 품목의 재고가 없음                   | _"입고존에서 해당 품목의 재고를 찾을 수 없습니다."_                            |
| 입고존·출고존 로케이션을 스캔                    | _"입고존·출고존으로는 적치할 수 없습니다."_                                 |
| 등록되지 않은 로케이션                       | _"해당 로케이션을 찾을 수 없습니다."_                                    |
| 품목·로케이션 바코드가 아님                     | _"인식할 수 없는 바코드입니다."_                                       |

**로케이션 고정 🔒**

같은 로케이션에 여러 품목을 적치할 때는 목적지 로케이션 칸 오른쪽의 🔒 버튼을 누르세요. 로케이션이 고정되어 **품목 라벨만 연달아 스캔**하면 됩니다. 다시 누르면 고정이 풀립니다.

**스캔 초기화**

잘못 스캔했다면 스캔 입력란 옆의 **초기화** 버튼으로 스캔한 품목·로케이션을 비울 수 있습니다. 고정한 로케이션은 비워지지 않습니다.

#### 2.3 직접 추가

1. **➕ 추가**를 누릅니다.
2. **품목명**을 검색해서 선택합니다. 입고존에서 그 품목의 재고를 자동으로 찾습니다.
3. **목적지 로케이션**을 검색해서 선택합니다.
4. **적치수량**을 입력합니다.

| 찾은 결과                      | 동작                                                                         |
| -------------------------- | -------------------------------------------------------------------------- |
| 재고가 하나                     | 로트번호·입고일이 자동으로 채워집니다.                                                     |
| 재고가 여러 건                   | **적치 대기 재고 선택** 창이 열립니다.                                                   |
| LOT이 여러 건이라 정할 수 없음        | _"동일 품목의 재고가 여러 건입니다. 재고선택 또는 바코드 스캔으로 재고를 지정하세요."_                         |
| 입고존에 재고가 없음                | _"품목 \[품목명]의 입고존 재고를 찾을 수 없습니다."_                                          |

**행에 바코드 스캔하기**

라인 왼쪽의 스캔 아이콘(**이 행에 바코드 스캔**)을 누르면 **그 라인에만** 바코드를 적용할 수 있습니다.

* 로케이션 바코드를 스캔하면 그 라인의 목적지 로케이션이 바뀝니다. _"로케이션 \[…] 적용됨"_
* 품목 라벨을 스캔하면 그 라인의 재고가 정해집니다. _"품목 \[…] 적용됨"_

#### 2.4 적치 대기 재고 선택

같은 품목이 입고존에 **로트번호나 입고일이 다른 재고로 여러 건** 있으면 재고 선택 창이 열립니다.

> 📷 **[이미지]** '적치 대기 재고 선택' 창 (로트·입고일·잔량과 '검수 N 중 N 적치완료'가 표시된 재고 후보 목록)

* 후보마다 **로트번호, 입고일, 잔량**과 **검수 N 중 N 적치완료**(가입고된 수량 중 이미 적치한 수량)가 표시됩니다.
* 적치할 재고를 누르면 라인에 적용됩니다.
* 선택하거나 **취소**하기 전까지는 다른 작업(다음 스캔 등)을 할 수 없습니다.

{% hint style="info" %}
**선입선출을 관리하지 않는 품목**은 입고일을 따로 고르지 않습니다. 입고일만 다른 재고는 하나로 묶이고, 적치할 때 **입고일이 오래된 재고부터 자동으로** 적치됩니다. 이때 입고일 칸에는 **오래된 순 자동**으로 표시됩니다.
{% endhint %}

#### 2.5 적치 예정 목록 컬럼

| 컬럼          |  필수 | 설명                                                       |
| ----------- | :-: | -------------------------------------------------------- |
| (스캔 아이콘)    |     | 이 행에 바코드 스캔 (위 2.3 참고)                                   |
| 품목코드        |     | 품목                                                       |
| 품목명         |  ✅  | 클릭해서 품목을 검색·선택                                           |
| 로트번호        |     | 스캔이나 재고 선택으로 정해진 재고의 로트번호 (직접 입력 불가)                     |
| 입고일         |     | 적치할 재고의 입고일. 선입선출 미관리 품목은 **오래된 순 자동**                   |
| 적치수량        |  ✅  | 옮길 수량. SN 관리 품목은 SN 개수로 자동 입력                            |
| SN          | 조건부 | SN 관리 품목만 표시. **SN찾기 (N)** (아래 2.6 참고)                  |
| 목적지 로케이션    |  ✅  | 물건을 보관할 로케이션 (입고존·출고존 제외)                                |
| 🗑️ (삭제)    |     | 라인 삭제                                                    |

#### 2.6 SN 관리 품목

SN 관리 품목은 **입고존에 있는 SN 중에서 적치할 제품의 SN을 찾아서** 등록합니다. 찾은 SN 개수가 적치수량이 됩니다.

1. 라인의 **SN찾기 (N)** 버튼을 누릅니다.
2. **SN 찾기** 창에서 SN을 스캔하거나 입력하고 `Enter`를 누릅니다. 아래 **입고존 후보** 목록에서 골라도 됩니다.
3. **확인**을 누르면 SN 개수만큼 적치수량이 채워집니다.

{% hint style="success" %}
SN이 들어 있는 품목 라벨을 스캔하면 스캔만으로 SN이 등록됩니다. **로케이션을 고정**하고 제품 라벨만 연달아 스캔하면 같은 라인에 SN이 계속 합산됩니다.
{% endhint %}

* 재고가 정해지지 않은 라인은 **SN찾기** 버튼이 비활성화됩니다. 스캔이나 재고 선택으로 재고를 먼저 정해 주세요.
* 입고존에 없는 SN을 입력하면 _"입고존에서 해당 SN을 찾을 수 없습니다."_ 가 표시됩니다.
* 같은 SN을 여러 라인에 중복으로 등록할 수 없습니다.

#### 2.7 저장 전 확인 항목

| 상황                  | 안내 메시지                                    |
| ------------------- | ----------------------------------------- |
| 라인 없음               | 적치할 품목을 추가해주세요.                           |
| 재고가 정해지지 않음         | 품목 \[품목명]의 재고가 확정되지 않았습니다.                |
| 목적지 로케이션 없음         | 품목 \[품목명]의 목적지 로케이션이 필요합니다.               |
| 목적지가 입고존·출고존        | 품목 \[품목명]: 입고존·출고존으로는 적치할 수 없습니다.         |
| 적치수량 오류             | 품목 \[품목명]의 수량을 확인해주세요.                    |
| SN 개수와 적치수량이 다름     | 품목 \[품목명]의 SN을 수량만큼 찾아주세요. (N/N)          |

입고존 남은 수량보다 많이 적치하려 하거나 서버에서 처리가 거부되면 그 사유가 표시됩니다.

{% hint style="danger" %}
* 저장하지 않고 **닫기**를 누르면 입력한 라인이 모두 사라집니다.
* 적치 완료한 뒤에는 **수정하거나 삭제할 수 없습니다.** 목적지 로케이션과 수량을 꼭 확인하세요.
{% endhint %}

### 3. 입고(적치) 상세

목록에서 **입고번호**를 클릭하면 상세 화면이 열립니다. 상세 화면은 **조회 전용**입니다.

> 📷 **[이미지]** 입고(적치) 상세 팝업창 (적치 품목 목록과 SN 관리 품목의 SN 버튼이 보이도록)

* 위쪽에 **입고일자, 제목, 비고**가 표시됩니다.
* **적치 품목** 목록에서 품목, 로트번호, 입고일, 적치수량, 목적지 로케이션을 확인할 수 있습니다.
* SN 관리 품목은 **SN** 버튼을 눌러 적치한 SN 목록을 볼 수 있습니다.

### 4. 자주 묻는 질문 (FAQ)

**Q. 품목 라벨을 스캔했는데 "입고존에서 해당 품목의 재고를 찾을 수 없습니다"라고 나와요.** \
아직 가입고하지 않았거나 이미 모두 적치한 품목입니다. [가입고](pre-inbound.md) 등록 여부를 확인해 주세요.

**Q. 일부만 먼저 적치하고 싶어요.** \
**적치수량**을 옮길 만큼만 입력하세요. 나머지는 입고존에 남아 다음에 적치할 수 있습니다.

**Q. 한 품목을 두 로케이션에 나눠서 보관해요.** \
로케이션별로 라인을 나눠서 추가하고, 각각 적치수량을 입력하세요.

**Q. 재고 선택 창이 떠서 다음 스캔이 안 돼요.** \
같은 품목이 입고존에 여러 건(로트번호나 입고일이 다름) 있다는 뜻입니다. 적치할 재고를 고르거나 **취소**한 뒤 계속 스캔하세요.

**Q. 입고일 칸에 "오래된 순 자동"이라고 나와요.** \
선입선출을 관리하지 않는 품목입니다. 입고일을 고를 필요 없이 오래된 재고부터 자동으로 적치됩니다.

**Q. 잘못된 로케이션에 적치했어요.** \
적치는 수정·삭제할 수 없습니다. [재고이동](../stock/move.md)으로 올바른 로케이션으로 옮겨 주세요.
