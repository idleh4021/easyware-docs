# 가입고

거래처에서 **도착한 물건을 내리고 확인(검수)해서 등록**하는 화면입니다. 가입고를 저장하면 물건이 **입고존**에 재고로 들어오고, 이후 [입고(적치)](putaway.md)에서 보관 로케이션으로 옮깁니다.

> 📷 **[이미지]** 단계별 일러스트: ① 화물 도착 → ② 입고계획서 QR 스캔으로 계획 불러오기 → ③ 수량·LOT·SN 확인 후 저장(입고존에 재고) → ④ 품목 라벨 출력·부착 흐름을 한 장으로 보여주는 그림

| 이런 경우에 사용합니다                       |
| ---------------------------------- |
| 입고계획에 맞춰 물건이 도착했을 때                  |
| 계획 없이 물건이 들어와 바로 등록해야 할 때            |
| 들어온 물건에 붙일 **품목 라벨**을 출력할 때          |

{% hint style="warning" %}
가입고는 저장하는 즉시 **입고존에 재고가 반영**됩니다. 저장한 라인은 **수정하거나 삭제할 수 없으니** 수량·로트번호·SN을 꼭 확인하고 저장하세요.
{% endhint %}

***

### 1. 가입고 목록

> 📷 **[이미지]** 가입고 목록 화면 전체 (조회 조건, 목록, 오른쪽 위 신규·출력 버튼이 보이도록)

#### 1.1 조회 조건

| 항목      | 설명                                            |
| ------- | --------------------------------------------- |
| 거래처     | 특정 거래처의 가입고만 조회합니다.                           |
| 키워드     | **품목명/코드/제목**으로 검색합니다.                       |
| 조회기간 설정 | 체크하면 기간 입력란이 나타납니다. 체크하지 않으면 기간 제한 없이 조회합니다. |
| 🔍 조회   | 조건에 맞는 가입고를 조회합니다.                            |

#### 1.2 목록 컬럼

| 컬럼     | 설명                              |
| ------ | ------------------------------- |
| ☑ (선택) | 라벨을 출력할 가입고 선택                  |
| 가입고번호  | 문서 번호. **클릭하면 상세 화면**이 열립니다.    |
| 제목     | 가입고 제목                          |
| 가입고일자  | 가입고한 날짜                         |
| 거래처    | 물건을 보낸 거래처                      |
| 상태     | 가입고 상태                          |
| 비고     | 메모                              |
| 작성자    | 가입고를 등록한 사람                     |

#### 1.3 목록 버튼

| 버튼     | 설명                                                 |
| ------ | -------------------------------------------------- |
| ➕ 신규   | 가입고 등록 팝업창을 엽니다.                                   |
| 🖨️ 출력 | 선택한 가입고의 **모든 품목 라벨**을 출력합니다. (아래 4. 참고) |

### 2. 가입고 등록

목록 오른쪽 위의 **➕ 신규**를 누르면 등록 팝업창이 열립니다.

> 📷 **[이미지]** 가입고 신규 등록 팝업창 (가입고일자·거래처·제목·비고 입력란, '입고계획 불러오기' 스캔 입력란과 목록에서 선택 버튼, 품목 목록이 보이도록)

#### 2.1 등록 순서

1. **입고계획 불러오기**로 들어온 물건의 계획을 불러옵니다. (아래 2.2 참고)
   * 계획 없이 들어온 물건은 **➕ 추가**로 직접 입력합니다. (아래 2.3 참고)
2. 라인마다 실제로 들어온 **가입고수량**을 확인하고 고칩니다.
3. LOT 관리 품목은 **로트번호**를, SN 관리 품목은 **SN**을 등록합니다.
4. 💾 **저장**을 클릭합니다.

저장되면 _"가입고가 저장되었습니다. (N건)"_ 메시지가 표시됩니다.

**상단 입력 항목**

| 항목    |  필수 | 설명                                                             |
| ----- | :-: | -------------------------------------------------------------- |
| 가입고일자 |  ✅  | 기본값은 오늘입니다. 저장한 뒤에는 바꿀 수 없습니다.                                 |
| 거래처   |  ✅  | 물건을 보낸 거래처. 입고계획을 불러오면 자동으로 채워집니다. 저장한 뒤에는 바꿀 수 없습니다.          |
| 제목    | 조건부 | **자동생성**에 체크하면 품목 기준으로 자동으로 만들어집니다. 체크를 해제하면 직접 입력하며, 이때는 필수입니다. |
| 비고    |     | 가입고 전체에 대한 메모                                                  |

#### 2.2 입고계획 불러오기

입고계획을 불러오면 계획의 품목·수량·로트번호가 한 번에 채워집니다. 방법은 두 가지입니다.

| 방법             | 설명                                                                     |
| -------------- | ---------------------------------------------------------------------- |
| **바코드 스캔**     | **입고계획 불러오기** 입력란에서 입고계획서의 QR 코드를 스캔하거나 **계획번호를 입력**하고 `Enter`를 누릅니다.     |
| **목록에서 선택** | 입력란 옆의 🔍 버튼을 눌러 **입고계획 불러오기** 창에서 계획을 고릅니다.                           |

**목록에서 선택하기**

> 📷 **[이미지]** '입고계획 불러오기' 창 (위쪽 입고계획 목록에서 체크한 계획과, 계획번호를 클릭해 아래에 상세 미리보기가 펼쳐진 상태)

1. 거래처, 상태, 키워드(**품목명 / 코드 / 계획번호**)로 계획을 찾고 **조회**를 누릅니다.
2. 가져올 계획의 **☑ 체크박스**를 선택합니다. 여러 계획을 함께 고를 수 있습니다.
3. **계획번호**를 클릭하면 아래에 상세 항목이 미리보기로 표시됩니다.
4. **가져오기**를 누릅니다.

{% hint style="info" %}
* 이 창에는 **남은 수량이 있고 강제완료되지 않은** 계획만 표시됩니다.
* **거래처가 다른 계획은 함께 가져올 수 없습니다.**
* 미리보기에서 작성 상태인 라인은 상태 옆에 **(제외)** 로 표시됩니다.
{% endhint %}

**불러올 때 채워지는 내용**

| 항목    | 채워지는 값                                    |
| ----- | ----------------------------------------- |
| 출처    | 입고계획번호 (직접 추가한 라인은 **수동**)               |
| 계획수량  | 입고계획의 계획수량                               |
| 가입고수량 | 계획의 **남은 수량** (SN 관리 품목은 `0`으로 시작, SN을 등록하면 채워짐) |
| 로트번호  | 입고계획에 입력한 로트번호                           |

**불러오기 규칙**

| 상황                       | 동작                                                         |
| ------------------------ | ---------------------------------------------------------- |
| 거래처가 비어 있음               | 계획의 거래처로 **자동 설정**됩니다.                                     |
| 입력한 거래처와 계획 거래처가 다름      | **거래처 불일치** 확인 창이 뜹니다. **진행**을 누르면 그대로 불러옵니다.               |
| 이미 불러온 라인                | _"N건은 이미 추가된 항목입니다."_ — 중복으로 추가되지 않습니다.                  |
| 작성 상태 라인이 섞여 있음          | _"작성 상태 라인 N건은 대상에서 제외했습니다."_                             |
| 확정된 라인이 하나도 없음           | _"확정된 라인이 없습니다. 계획에서 라인을 확정한 후 진행해주세요."_                  |
| 남은 수량이 없는 라인             | 불러오지 않습니다.                                                 |
| 강제완료된 계획                 | _"강제완료된 입고계획입니다: (계획번호). 작업하려면 목록에서 강제완료를 취소해주세요."_        |
| 없는 계획번호                  | _"입고계획 \[계획번호]을 찾을 수 없습니다."_                              |

{% hint style="warning" %}
입고계획에서 **확정**한 라인만 불러올 수 있습니다. 불러와지지 않는다면 [입고계획](plan.md)에서 라인 상태를 확인해 주세요.
{% endhint %}

#### 2.3 직접 추가 (계획 없이)

1. **➕ 추가**를 누릅니다. 새 라인이 추가되고 품목명 칸이 입력 상태가 됩니다.
2. **품목명**을 검색해서 선택합니다.
3. **가입고수량**을 입력합니다.
4. 필요하면 로트번호, 비고를 입력합니다.

직접 추가한 라인은 **출처**가 **수동**으로 표시됩니다.

#### 2.4 품목 목록 컬럼

| 컬럼        |  필수 | 설명                                                      |
| --------- | :-: | ------------------------------------------------------- |
| ☑ (선택)    |     | 라벨 출력 대상 선택 (저장된 라인만 선택 가능)                              |
| 출처        |     | 입고계획번호 또는 **수동**                                        |
| 품목코드      |     | 품목을 선택하면 자동 입력                                          |
| 품목명       |  ✅  | 클릭해서 품목을 검색·선택                                          |
| 계획수량      |     | 입고계획의 계획수량 (참고용)                                        |
| 가입고수량     |  ✅  | 실제로 들어온 수량. SN 관리 품목은 등록한 SN 개수로 자동 입력                   |
| 단위        |     | 품목의 단위                                                  |
| 로트번호      | 조건부 | **LOT 관리 품목은 필수**입니다.                                   |
| SN        | 조건부 | SN 관리 품목만 표시. 저장 전 **SN등록 (N)**, 저장 후 **SN조회** (아래 2.6 참고) |
| 비고        |     | 라인 메모                                                   |
| 🗑️ (삭제)  |     | **저장 전**에 추가한 라인만 삭제할 수 있습니다.                           |

#### 2.5 LOT 관리 품목

{% hint style="warning" %}
**LOT 관리 품목은 가입고할 때 로트번호가 반드시 있어야 합니다.** 입고계획에서 비워 두었더라도 여기서는 입력해야 저장됩니다.
{% endhint %}

입고계획에서 불러온 라인의 로트번호를 **계획과 다른 값**으로 바꾸면 확인 창이 뜹니다.

> **계획 LOT과 다릅니다**\
> \[품목명] 계획 LOT(…)과 다른 LOT(…)으로 가입고합니다. 계속하시겠습니까?

**변경**을 누르면 바꾼 값으로, **취소**를 누르면 원래 값으로 돌아갑니다. 저장할 때 계획 LOT과 다른 라인이 있으면 _"계획 LOT과 다른 라인이 있습니다"_ 확인 창이 한 번 더 표시됩니다.

#### 2.6 SN 관리 품목

SN 관리 품목은 수량을 직접 입력하지 않고 **SN을 등록**합니다. 등록한 SN 개수가 가입고수량이 됩니다.

> 📷 **[이미지]** 'SN 등록' 창 (SN 입력란, 추가·자동생성 버튼, 등록된 SN 목록과 아래 '총 N건'·확인 버튼이 보이도록)

1. 라인의 **SN등록 (N)** 버튼을 누릅니다.
2. **SN 등록** 창에서 SN을 등록합니다.
   * SN을 스캔하거나 입력하고 `Enter`(또는 **➕ 추가**)를 누릅니다.
   * 제품에 SN이 없다면 **✨ 자동생성**을 누르고 **생성할 SN 개수**를 입력한 뒤 **생성**을 누릅니다. (한 번에 최대 99개)
3. **확인**을 누르면 SN 개수만큼 가입고수량이 채워집니다.

| 상황                | 안내 메시지                    |
| ----------------- | ------------------------- |
| 같은 창에서 이미 입력한 SN  | 이미 추가한 SN입니다.             |
| 다른 라인에 이미 등록한 SN  | 다른 라인에 이미 등록된 SN입니다.      |
| 자동생성 개수가 99개 초과   | 한 번에 최대 99개까지 생성 가능합니다.   |
| 자동생성한 SN 중 사용 중인 것 | 일부 SN이 이미 사용중이어서 제외되었습니다. |

저장한 뒤에는 버튼이 **SN조회**로 바뀌어 등록된 SN을 볼 수 있습니다. SN조회 창에서 SN을 골라 **라벨 출력**하면 고른 SN의 라벨만 출력됩니다. (아래 4.2 참고)

#### 2.7 저장 전 확인 항목

| 상황                 | 안내 메시지                            |
| ------------------ | --------------------------------- |
| 가입고일자 미입력          | 가입고일자는 필수입니다.                     |
| 거래처 미선택            | 거래처는 필수입니다.                       |
| 제목 직접 입력인데 비어 있음   | 제목을 입력해주세요.                       |
| 품목 없음              | 가입고 품목을 추가해주세요.                   |
| 품목 미선택             | 품목은 필수입니다.                        |
| SN 관리 품목인데 SN 미등록  | SN 관리 품목입니다. SN을 등록해주세요: (품목명)    |
| SN 중복              | SN이 중복되었습니다: (SN)                 |
| 가입고수량 미입력          | 품목 \[품목명]의 가입고수량을 입력해주세요.         |
| LOT 관리 품목인데 로트번호 없음 | LOT 관리 품목입니다. 로트번호를 입력해주세요: (품목명) |

### 3. 가입고 상세·추가 등록

목록에서 **가입고번호**를 클릭하면 상세 팝업창이 열립니다. 위쪽에 아래 안내가 표시됩니다.

> 등록된 라인은 수정·삭제할 수 없습니다. 신규 라인 추가와 제목·비고 수정만 가능합니다.

| 할 수 있는 것                                 | 할 수 없는 것                   |
| ---------------------------------------- | -------------------------- |
| 새 라인 추가 (입고계획 불러오기, ➕ 추가)                 | 저장된 라인의 품목·수량·로트번호·SN 수정    |
| 제목, 비고 수정                                | 저장된 라인 삭제                  |
| 저장된 라인의 SN 조회, 라벨 출력                     | 가입고일자, 거래처 변경              |

새 라인을 추가해서 저장하면 _"수정 완료! (신규 라인: N건)"_ 이 표시됩니다.

{% hint style="info" %}
같은 화물이 나눠서 도착한다면 **처음 가입고에 이어서 라인을 추가**하거나, **새 가입고**로 등록하면 됩니다. 입고계획의 남은 수량만큼 계속 불러올 수 있습니다.
{% endhint %}

***

### 4. 품목 라벨 출력

들어온 물건에 붙일 **품목 라벨**을 출력합니다. 라벨에는 품목 정보와 함께 LOT·SN·입고일이 들어가, 이후 적치·출고 때 스캔해서 사용할 수 있습니다.

| 출력하는 곳                    | 출력 대상                          |
| ------------------------- | ------------------------------ |
| 목록의 **🖨️ 출력**            | 선택한 가입고의 **모든 라인**             |
| 상세 팝업창의 **라벨 출력**         | 체크한 **저장된 라인**                 |
| SN조회 창의 **라벨 출력**         | 체크한 **SN만** (SN 1개당 1장)          |

#### 4.1 출력 순서

> 📷 **[이미지]** '품목 라벨 출력' 창 (라벨 형식 3가지, 매수 지정/가입고 수량만큼 선택, 라벨 1건당 매수, 'N개 품목 · 총 N장' 표시가 보이도록)

1. 출력할 가입고(또는 라인, SN)를 선택하고 출력 버튼을 누릅니다.
2. **품목 라벨 출력** 창에서 라벨 형식을 고릅니다.
3. 출력 매수를 정합니다.
4. **출력**을 누르면 새 탭에 출력 화면이 열립니다.

| 라벨 형식      | 내용                       |
| ---------- | ------------------------ |
| 라벨 100×50  | 품목코드, 품목명, 규격, LOT·SN·입고일 |
| 라벨 50×25   | 품목코드, 품목명, 핵심 정보 1개      |
| 라벨 30×30   | QR과 품목명                  |

**출력 매수**

| 방식           | 설명                                                                 |
| ------------ | ------------------------------------------------------------------ |
| **매수 지정**    | **라벨 1건당 매수**에 입력한 장수만큼 출력합니다. (최대 50장)                            |
| **가입고 수량만큼** | 라인의 가입고수량만큼 출력합니다. 소수 수량은 올림합니다. SN 관리 품목은 SN마다 1장입니다. (SN조회 창에서는 표시되지 않음) |

창 아래에 _"N개 품목 · 총 N장"_ 으로 예상 장수가 표시됩니다.

{% hint style="warning" %}
* 총 **300장**을 넘으면 _"총 N장을 출력합니다. 계속할까요?"_ 확인 창이 뜹니다.
* 총 **1,000장**을 넘으면 출력되지 않습니다. _"한 번에 1,000장까지 출력할 수 있습니다. 품목을 나눠서 출력해 주세요."_
* 목록에서는 한 번에 **최대 100건**까지 선택해서 출력할 수 있습니다.
{% endhint %}

#### 4.2 SN 골라서 출력하기

1. 상세 팝업창에서 SN 관리 라인의 **SN조회**를 누릅니다.
2. 출력할 SN의 **☑ 체크박스**를 선택합니다.
3. **라벨 출력**을 누르고 형식·매수를 정해 출력합니다.

선택한 SN이 없으면 _"출력할 SN을 선택해주세요."_ 가 표시됩니다. 한 번에 최대 500건까지 출력할 수 있습니다.

### 5. 자주 묻는 질문 (FAQ)

**Q. 입고계획을 불러왔는데 "확정된 라인이 없습니다"라고 나와요.** \
계획의 라인이 모두 **작성** 상태입니다. [입고계획](plan.md)에서 라인을 **확정**으로 바꿔 저장한 뒤 다시 불러오세요.

**Q. 저장한 라인의 수량을 잘못 입력했어요.** \
저장한 라인은 수정·삭제할 수 없습니다. \
[기타입출고](../stock/etc-in-out.md)에서 **입고존 로케이션**의 재고를 입고 또는 출고로 등록해 수량을 바로잡아 주세요. \
저장할 때 _"입고존·출고존 재고를 조정합니다. 입출고 계획의 진행 수량은 바뀌지 않습니다. 저장하시겠습니까?"_ 확인 창이 뜹니다.

{% hint style="warning" %}
기타입출고로 조정해도 **입고계획의 가입고수량은 바뀌지 않습니다.** 계획 잔여수량을 다시 가입고하지 않도록 주의하세요.
{% endhint %}

**Q. 계획보다 적게 들어왔어요.** \
들어온 만큼만 가입고수량을 입력해서 저장하세요. 남은 수량은 입고계획에 그대로 남아, 나중에 다시 불러올 수 있습니다. \
더 들어올 물건이 없다면 [입고계획](plan.md)에서 **강제완료**하세요.

**Q. LOT 관리 품목인데 계획에 로트번호가 없어요.** \
가입고 화면에서 로트번호를 직접 입력하면 됩니다. LOT 관리 품목은 로트번호 없이 저장되지 않습니다.

**Q. 제품에 SN이 없어요.** \
SN 등록 창의 **자동생성**으로 SN을 만들고, 저장 후 **SN조회 → 라벨 출력**으로 라벨을 붙여 주세요.

**Q. 거래처가 다른 계획 두 개를 한 번에 불러올 수 있나요?** \
아니요. 거래처가 다른 계획은 함께 가져올 수 없습니다. 거래처별로 가입고를 등록해 주세요.
