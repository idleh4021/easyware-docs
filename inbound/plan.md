# 입고계획

거래처에서 **들어올 물건의 예정 내용**(품목, 수량, 단가 등)을 미리 등록하는 화면입니다. 입고계획을 등록해 두면 물건이 도착했을 때 [가입고](pre-inbound.md)에서 계획을 불러와 바로 처리할 수 있습니다.

> 📷 **[이미지]** 단계별 일러스트: ① 입고계획 등록 → ② 품목 라인 확정 → ③ 가입고에서 계획 불러오기 → ④ 입고(적치) 흐름을 한 장으로 보여주는 그림

{% hint style="info" %}
입고계획은 **예정 정보**이므로 등록해도 **재고는 바뀌지 않습니다.** 재고는 [가입고](pre-inbound.md)를 저장할 때 입고존에 들어옵니다.
{% endhint %}

***

### 1. 상태 알아보기

입고계획은 계획 전체(상단)와 품목 라인마다 상태가 있습니다.

| 상태      | 의미                          | 가입고 대상 |
| ------- | --------------------------- | :----: |
| **작성**  | 아직 확정하지 않은 임시 상태            |   ❌    |
| **확정**  | 가입고할 준비가 된 상태               |   ✅    |
| **입고중** | 가입고가 일부 진행된 상태 (자동으로 바뀜)    |   ✅    |
| **완료**  | 계획수량만큼 가입고가 끝난 상태 (자동으로 바뀜) |   -    |

{% hint style="warning" %}
**확정된 라인만 가입고할 수 있습니다.** 작성 상태로 두면 가입고 화면에서 불러올 때 제외됩니다. 품목 입력을 마쳤다면 상태를 **확정**으로 바꿔 저장해 주세요.
{% endhint %}

***

### 2. 입고계획 목록

> 📷 **[이미지]** 입고계획 목록 화면 전체 (조회 조건, 목록, 오른쪽 위 신규·출력·삭제 버튼이 보이도록)

#### 2.1 조회 조건

| 항목      | 설명                                            |
| ------- | --------------------------------------------- |
| 거래처     | 특정 거래처의 계획만 조회합니다.                            |
| 상태      | 상태로 걸러봅니다. 여러 개를 선택할 수 있습니다. (기본값: 전체)        |
| 키워드     | **품목명/코드/제목**으로 검색합니다. `Enter`를 눌러도 조회됩니다.     |
| 조회기간 설정 | 체크하면 기간 입력란이 나타납니다. 체크하지 않으면 기간 제한 없이 조회합니다. |
| 🔍 조회   | 조건에 맞는 입고계획을 조회합니다.                           |

#### 2.2 목록 컬럼

| 컬럼     | 설명                                        |
| ------ | ----------------------------------------- |
| ☑ (선택) | 출력·삭제할 계획 선택. 머리글의 체크박스로 전체 선택/해제         |
| 입고계획번호 | 문서 번호. **클릭하면 상세 화면**이 열립니다.              |
| 제목     | 계획 제목                                     |
| 계획일자   | 입고 예정일                                    |
| 거래처    | 물건을 보내는 거래처                               |
| 상태     | 계획의 진행 상태                                 |
| 비고     | 메모                                        |
| 강제완료   | **강제완료** / **취소** 버튼 (아래 5. 참고)            |
| 작성자    | 계획을 등록한 사람                                |

#### 2.3 목록 버튼

| 버튼      | 설명                                                    |
| ------- | ----------------------------------------------------- |
| ➕ 신규    | 입고계획 등록 팝업창을 엽니다.                                     |
| 🖨️ 출력  | 선택한 계획을 출력합니다. (아래 6. 참고)                              |
| 🗑️ 삭제  | 선택한 계획을 삭제합니다. 확인 창에서 **삭제**를 누르면 _"N건이 삭제되었습니다."_ 가 표시됩니다. |

{% hint style="info" %}
가입고가 진행된 계획이나 강제완료된 계획은 삭제할 수 없습니다. 삭제할 수 없으면 그 사유가 표시됩니다.
{% endhint %}

### 3. 입고계획 등록

목록 오른쪽 위의 **➕ 신규**를 누르면 등록 팝업창이 열립니다.

> 📷 **[이미지]** 입고계획 신규 등록 팝업창 (계획일자·거래처·상태·제목·비고 입력란과 아래 품목 목록, 추가·행 복제 버튼이 보이도록)

#### 3.1 등록 순서

1. **계획일자**를 선택합니다.
2. **거래처**를 검색해서 선택합니다. 품목 목록이 비어 있으면 빈 라인이 자동으로 하나 추가됩니다.
3. 품목 목록에서 **품목명**을 검색해서 선택하고 **계획수량**을 입력합니다.
4. 필요하면 단가, 로트번호, 비고를 입력합니다.
5. 품목을 더 넣으려면 **➕ 추가**를 누릅니다.
6. 가입고할 준비가 됐다면 **상태**를 **확정**으로 바꿉니다.
7. 💾 **저장**을 클릭합니다.

저장되면 _"입고계획이 저장되었습니다. (N건)"_ 메시지가 표시됩니다.

#### 3.2 상단 입력 항목

| 항목   |  필수 | 설명                                                                         |
| ---- | :-: | -------------------------------------------------------------------------- |
| 계획일자 |  ✅  | 입고 예정일                                                                     |
| 거래처  |  ✅  | 물건을 보내는 거래처                                                                |
| 상태   |     | **작성 / 확정** 중 하나를 눌러 선택합니다. 입고중·완료는 자동으로 바뀌는 상태라 직접 고를 수 없습니다.              |
| 제목   | 조건부 | **자동생성**에 체크하면 품목 기준으로 자동으로 만들어집니다. 체크를 해제하면 직접 입력하며, 이때는 필수입니다.              |
| 비고   |     | 계획 전체에 대한 메모                                                               |

{% hint style="success" %}
**상단의 상태를 바꾸면 같은 상태였던 품목 라인도 함께 바뀝니다.** 예를 들어 모든 라인이 작성 상태일 때 상단을 **확정**으로 누르면 라인도 모두 확정됩니다. 가입고가 진행된 라인은 바뀌지 않습니다.
{% endhint %}

이미 저장된 확정 라인이 **작성**으로 바뀌게 되면 _"확정된 품목 N건이 작성으로 바뀝니다. 계속하시겠습니까?"_ 확인 창이 표시됩니다.

#### 3.3 품목 목록 컬럼

| 컬럼          |  필수 | 설명                                                    |
| ----------- | :-: | ----------------------------------------------------- |
| 품목코드        |     | 품목을 선택하면 자동 입력                                        |
| 품목명         |  ✅  | 클릭해서 품목을 검색·선택                                        |
| 계획수량        |  ✅  | 들어올 예정 수량                                             |
| 가입고수량       |     | 지금까지 가입고된 수량 (자동 표시)                                  |
| 잔여수량        |     | 계획수량 − 가입고수량 (자동 표시)                                  |
| 단위          |     | 품목의 단위 (자동 입력)                                        |
| 단가          |     | 입력하면 공급가액·부가세·합계금액이 자동으로 계산됩니다.                       |
| 공급가액        |     | 수량 × 단가. 직접 고칠 수도 있습니다.                               |
| 부가세         |     | 공급가액의 10% (원 미만 버림). 직접 고치면 합계금액이 다시 계산됩니다.           |
| 합계금액        |     | 공급가액 + 부가세                                           |
| 로트번호        |     | **LOT 관리 품목만** 입력할 수 있습니다. 입력하면 가입고할 때 기본값으로 채워집니다. |
| 비고          |     | 라인 메모                                                 |
| 상태          |     | 라인 상태. **작성 / 확정** 중에서 고릅니다.                          |
| 🗑️ (삭제)    |     | 라인 삭제 (아래 4.3 참고)                                     |

{% hint style="info" %}
* LOT 관리 품목이라도 입고계획에서는 로트번호를 **비워 둘 수 있습니다.** 로트번호는 **가입고할 때 반드시** 입력해야 합니다.
* 라인의 셀은 **한 번 클릭**하면 바로 입력 상태가 됩니다.
{% endhint %}

#### 3.4 행 추가와 행 복제

| 버튼                | 단축키                        | 설명                                                  |
| ----------------- | -------------------------- | --------------------------------------------------- |
| ➕ **추가**          | 품목 목록에서 `Shift + Enter`    | 빈 라인을 추가하고 품목명 칸을 입력 상태로 만듭니다.                       |
| **행 복제**          | 품목 목록에서 `Ctrl + Shift + Enter` | 마지막으로 클릭한 라인을 바로 아래에 복사합니다. 품목·수량·단가·로트번호 등이 그대로 복사됩니다. |

{% hint style="info" %}
복제한 라인은 원본 상태와 관계없이 **작성** 상태, 가입고수량 `0`인 새 라인이 됩니다. 삭제 표시한 라인은 복제할 수 없습니다.
{% endhint %}

#### 3.5 저장 전 확인 항목

| 상황              | 안내 메시지                     |
| --------------- | -------------------------- |
| 계획일자 미입력        | 계획일자는 필수입니다.               |
| 거래처 미선택         | 거래처는 필수입니다.                |
| 제목 직접 입력인데 비어 있음 | 제목을 입력해주세요.                |
| 품목 없음           | 입고 품목을 추가해주세요.             |
| 품목 미선택          | 품목은 필수입니다.                 |
| 계획수량 미입력        | 품목 \[품목명]의 계획수량을 입력해주세요.   |

사용하지 않는 거래처·품목으로는 저장할 수 없으며, 이때는 해당 코드가 함께 안내됩니다.

***

### 4. 입고계획 수정

목록에서 **입고계획번호**를 클릭하면 수정 팝업창이 열립니다. 오른쪽 위에는 작성자와 최종 수정자가 표시됩니다.

> 📷 **[이미지]** 입고계획 수정 팝업창 (가입고가 일부 진행되어 위쪽에 안내 문구가 보이고, 진행된 라인이 잠겨 있는 상태)

1. 내용을 고칩니다.
2. 💾 **저장**을 클릭합니다. _"입고계획이 수정되었습니다."_ 가 표시됩니다.

#### 4.1 확정된 라인 고치기

이미 저장된 **확정** 라인의 셀을 처음 클릭하면 확인 창이 뜹니다.

> **확정된 라인입니다.**\
> 가입고 대상으로 확정된 라인입니다. 수정하시겠습니까?

**수정**을 누르면 그 라인은 팝업창을 닫을 때까지 확인 없이 고칠 수 있습니다.

#### 4.2 가입고가 진행된 계획

가입고가 시작되면 위쪽에 아래 안내가 표시됩니다.

> 가입고가 진행된 라인이 있습니다. 진행된 라인과 거래처·전표 상태는 수정할 수 없으며, 나머지 라인은 수정할 수 있습니다.

| 구분              | 수정 가능 여부 |
| --------------- | :------: |
| 가입고가 진행된 라인     |    ❌     |
| 거래처, 상단 상태      |    ❌     |
| 진행되지 않은 라인, 새 라인 |    ✅     |
| 계획일자, 제목, 비고    |    ✅     |

진행된 라인의 상태 칸에 마우스를 올리면 _"가입고가 진행된 품목은 수정할 수 없습니다"_ 가 표시됩니다.

#### 4.3 라인 삭제

* 저장 전에 추가한 라인은 🗑️를 누르면 바로 사라집니다.
* 저장된 라인은 🗑️를 누르면 **삭제 표시**만 되고, **저장할 때 실제로 삭제**됩니다. 저장 전이라면 다시 눌러 되돌릴 수 있습니다.
* 저장된 확정 라인을 삭제하면 _"가입고 대상일 수 있는 라인입니다. 삭제하시겠습니까?"_ 확인 창이 뜹니다.
* 가입고가 진행된 라인은 삭제할 수 없습니다.

{% hint style="warning" %}
품목을 모두 지우고 저장할 수는 없습니다. _"품목이 1건 이상 있어야 합니다. 계획을 지우려면 계획 삭제 버튼을 이용해 주세요."_ 가 표시됩니다. 계획 자체를 지우려면 아래 4.4를 이용하세요.
{% endhint %}

#### 4.4 계획 삭제

팝업창 왼쪽 아래의 🗑️ **계획 삭제**를 누르고 확인 창에서 **삭제**를 누릅니다.

가입고가 진행된 라인이 있거나 강제완료된 계획은 버튼이 비활성화되며, 마우스를 올리면 사유가 표시됩니다.

#### 4.5 계획 복사

같은 거래처에서 비슷한 물건이 자주 들어온다면 기존 계획을 복사해서 새 계획을 만들 수 있습니다.

1. 복사할 계획의 수정 팝업창에서 **계획 복사**를 클릭합니다.
2. 복사한 내용이 채워진 **입고계획 신규 등록 (계획 복사)** 팝업창이 열립니다. 위쪽에 _"복사한 계획입니다. 저장해야 등록됩니다."_ 가 표시됩니다.
3. 내용을 확인하고 고친 뒤 💾 **저장**을 누릅니다.

| 복사되는 내용                                 | 새로 정해지는 내용               |
| --------------------------------------- | ------------------------ |
| 거래처, 비고, 품목 라인(품목·수량·단가·금액·로트번호·비고) | 계획일자(오늘), 상태(작성), 입고계획번호 |

{% hint style="info" %}
* **저장된 내용**을 기준으로 복사합니다. 고치던 내용이 있으면 _"저장하지 않은 내용은 복사되지 않습니다. 계속할까요?"_ 가 표시됩니다.
* 삭제 표시한 라인은 복사되지 않습니다.
* 저장하기 전까지는 새 계획이 등록되지 않습니다.
{% endhint %}

#### 4.6 저장하지 않고 닫을 때

고친 내용이 있는데 **닫기**를 누르면 _"저장하지 않은 변경사항이 있습니다."_ 확인 창이 뜹니다. **계속 편집**을 누르면 팝업창으로 돌아갑니다.

***

### 5. 강제완료

계획수량을 다 채우지 못했지만 **더 이상 들어올 물건이 없을 때** 사용합니다. 강제완료하면 남은 수량은 더 이상 가입고 대상으로 조회되지 않습니다.

> 📷 **[이미지]** 입고계획 목록의 강제완료 컬럼 (강제완료 버튼과, 강제완료된 계획의 취소 버튼이 함께 보이도록)

1. 목록의 **강제완료** 칸에서 **강제완료** 버튼을 누릅니다.
2. 확인 창에서 **강제완료**를 누릅니다. _"강제완료 처리되었습니다."_ 가 표시됩니다.

> **강제완료하시겠습니까?**\
> \[계획번호] 남은 수량을 더 이상 가입고 대상으로 조회하지 않습니다. 강제완료된 전표는 수정/삭제할 수 없으며(비고 제외), 나중에 취소할 수 있습니다.

* **작성** 상태이거나 **완료**된 계획에는 버튼이 표시되지 않습니다.
* 강제완료된 계획을 열면 _"강제완료된 입고계획입니다. 비고만 수정할 수 있으며, 다른 내용을 수정하려면 목록에서 강제완료를 취소해주세요."_ 가 표시되고 **비고만** 고칠 수 있습니다.
* 가입고에서 강제완료된 계획을 불러오면 _"강제완료된 입고계획입니다: (계획번호). 작업하려면 목록에서 강제완료를 취소해주세요."_ 가 표시됩니다.

**강제완료 취소**

강제완료된 계획은 같은 칸에 **취소** 버튼이 표시됩니다. 누르고 확인하면 남은 수량이 다시 가입고 대상이 됩니다.

### 6. 출력

입고계획서를 출력해서 현장에서 사용할 수 있습니다.

1. 목록에서 출력할 계획의 **☑ 체크박스**를 선택하고 **🖨️ 출력**을 누릅니다. (수정 팝업창 아래의 **출력** 버튼으로 그 계획만 출력할 수도 있습니다.)
2. **입고계획 출력** 창에서 형식을 고르고 **출력**을 누릅니다. 새 탭에 출력 화면이 열립니다.

| 형식            | 내용                |
| ------------- | ----------------- |
| A4 입고계획서      | 계획별 품목 목록과 QR 코드  |
| 라벨 100×150    | 계획당 1장, 제목과 QR 코드 |

{% hint style="success" %}
출력물의 **QR 코드를 가입고 화면에서 스캔**하면 그 계획을 바로 불러올 수 있습니다.
{% endhint %}

* 선택한 계획이 없으면 _"출력할 입고계획을 선택해주세요."_ 가 표시됩니다.
* 한 번에 **최대 100건**까지 출력할 수 있습니다.

### 7. 자주 묻는 질문 (FAQ)

**Q. 가입고 화면에서 계획을 불러왔는데 품목이 안 나와요.** \
라인이 **작성** 상태이면 가입고 대상에서 제외됩니다. \
입고계획에서 라인을 **확정**으로 바꿔 저장해 주세요.

**Q. 거래처를 바꿀 수 없어요.** \
가입고가 진행된 라인이 있으면 거래처와 상단 상태를 바꿀 수 없습니다.

**Q. 계획수량보다 적게 들어왔는데 남은 수량이 계속 보여요.** \
더 들어올 물건이 없다면 목록에서 **강제완료**하세요. 남은 수량이 가입고 대상에서 빠집니다.

**Q. 입고중·완료 상태를 직접 고를 수 없어요.** \
입고중·완료는 가입고 진행에 따라 **자동으로** 바뀌는 상태입니다.

**Q. 지난번과 같은 계획을 또 만들어야 해요.** \
기존 계획을 열고 **계획 복사**를 누르면 같은 내용으로 새 계획을 만들 수 있습니다.
