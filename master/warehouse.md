# 창고관리

재고를 보관하는 **창고**를 등록하고 관리하는 화면입니다.

창고는 로케이션의 상위 단위입니다. 창고를 먼저 등록한 뒤, 로케이션 관리에서 창고 안의 보관 위치를 만듭니다.

```
창고 (예: 본사 물류센터)
 └─ 로케이션 (예: A-1-1, A-1-2, B-2-3 …)
```

### 1. 화면 구성

#### 1.1 상단 툴바

| 버튼/요소 | 위치  | 설명                                    |
| ----- | --- | ------------------------------------- |
| 검색창   | 왼쪽  | 검색할 창고 코드를 입력합니다. `Enter`를 눌러도 조회됩니다. |
| 🔍 조회 | 왼쪽  | 조건에 맞는 창고를 조회합니다.                     |
| ➕ 버튼  | 오른쪽 | 새 창고 행을 추가합니다.                        |
| **행 복제** | 오른쪽 | 마지막으로 클릭한 행을 바로 아래에 복사합니다. 단축키는 목록에서 `Ctrl + Shift + Enter`입니다. |
| 💾 저장 | 오른쪽 | 추가/수정한 내용을 저장합니다.                     |

#### 1.2 창고 목록 컬럼

| 컬럼    | 설명          |      수정      |
| ----- | ----------- | :----------: |
| 창고 코드 | 창고를 구분하는 코드 | ✅ (가상 창고 제외) |
| 창고명   | 창고의 이름      |       ✅      |
| 창고 구분 | 창고의 유형      |       ✅      |
| 주소    | (우편번호) 기본주소. 주소 검색으로 입력 (아래 4. 참고) |       ✅      |
| 상세주소  | 동·호수 등 나머지 주소 |       ✅      |
| 사용 여부 | 사용 / 미사용    | ✅ (가상 창고 제외) |

#### 1.3 하단 페이지 이동 영역

| 요소                     | 설명                                       |
| ---------------------- | ---------------------------------------- |
| `«` `‹` 페이지 번호 `›` `»` | 처음 / 이전 / 해당 페이지 / 다음 / 마지막 페이지로 이동      |
| 표시 개수                  | 한 페이지에 표시할 개수 선택 (20 / 50 / 100 / 150개씩) |
| 총 N건                   | 조회 조건에 해당하는 전체 창고 수                      |

***

### 2. 창고 조회

1. 검색창에 **창고 코드**를 입력합니다.
2. **조회** 버튼을 누르거나 `Enter`를 누릅니다.
3. 검색창을 비우고 조회하면 전체 창고가 표시됩니다.

{% hint style="info" %}
조회하면 항상 **1페이지**부터 다시 표시됩니다.
{% endhint %}

***

### 3. 창고 추가

1. 툴바의 **➕ 버튼**을 클릭합니다.
2. 목록 맨 아래에 새 행이 추가되고, **창고 코드 칸이 바로 입력 상태**가 됩니다.
3. 창고명, 창고 구분, 주소를 입력합니다.
4. 💾 **저장**을 클릭합니다.

#### 창고 코드 자동 생성

* 첫 번째 행은 서버에서 다음 창고 코드를 받아옵니다.
* 저장하기 전에 행을 연달아 추가하면 이어지는 번호로 생성됩니다.
* 자동 생성된 코드는 필요하면 직접 수정할 수 있습니다.
* 코드를 생성하는 동안 ➕ 버튼에 로딩 표시가 나타납니다.

{% hint style="warning" %}
**창고 코드**와 **창고명**은 반드시 입력해 주세요.
{% endhint %}

{% hint style="success" %}
창고를 저장한 뒤에는 로케이션 관리에서 해당 창고의 로케이션을 만들어 주세요. 로케이션이 없으면 창고에 재고를 보관할 수 없습니다.&#x20;
{% endhint %}

#### 행 복제

비슷한 행을 여러 개 등록할 때는 복사할 행을 클릭하고 툴바의 **행 복제**를 누르세요. (단축키: 창고 목록에서 `Ctrl + Shift + Enter`) 클릭한 행 바로 아래에 새 행이 추가됩니다.

{% hint style="info" %}
창고 코드는 새로 자동 생성되고, 창고명·구분·주소 등이 복사됩니다. 가상창고(입고존·출고존)는 복제할 수 없습니다. 복제한 행도 💾 **저장**해야 등록됩니다.
{% endhint %}

***

### 4. 창고 수정

| 컬럼                       | 수정 방법           |
| ------------------------ | --------------- |
| 창고 코드 / 창고명 / 창고 구분 / 상세주소 | 셀을 더블클릭하여 직접 입력 |
| 주소                       | 🔍 돋보기로 주소 검색 (아래 참고) |
| 사용 여부                    | 체크박스 클릭         |

수정한 뒤에는 반드시 **💾 저장**을 눌러야 반영됩니다.

#### 주소 입력

주소 칸은 직접 타이핑하지 않고 **주소 검색 팝업창**으로 입력합니다.

1. 주소 칸의 🔍 돋보기를 누릅니다. (칸을 선택한 상태에서 `Enter`를 눌러도 됩니다.)
2. 주소를 검색해서 고릅니다. 우편번호와 기본주소가 채워지고 **상세주소** 칸이 바로 입력 상태가 됩니다.
3. 상세주소(동·호수 등)를 입력합니다.

검색으로 찾을 수 없는 주소(해외 주소 등)는 팝업창의 **직접 입력**을 이용하세요.

***

### 5. 가상 창고

목록에 있는 **가상 창고**는 시스템에서 사용하는 특수 창고입니다. 실제 보관 장소가 아니며, 시스템 운영을 위해 기본으로 만들어져 있습니다.

| 항목               | 가상 창고에서         |
| ---------------- | --------------- |
| 창고 코드            | 수정 불가           |
| 사용 여부            | 변경 불가 (체크박스 잠김) |
| 창고명 / 창고 구분 / 주소 | 수정 가능           |

{% hint style="warning" %}
가상 창고는 삭제하거나 미사용 처리할 수 없습니다. 가상 창고에 속한 로케이션도 사용 여부를 변경할 수 없습니다.
{% endhint %}

***

### 6. 저장

저장 버튼을 누르면 **새로 추가된 행**과 **수정된 행**만 골라서 한 번에 저장합니다. 저장이 끝나면 목록을 다시 불러오고, 다음과 같은 메시지가 표시됩니다.

> 저장 완료! (신규: N건, 수정: N건)

| 상황                      | 안내 메시지               |
| ----------------------- | -------------------- |
| 변경 사항이 없음               | 변경된 데이터가 없습니다.       |
| 저장 실패 (필수값 누락, 중복 코드 등) | 저장 중 시스템 오류가 발생했습니다. |

{% hint style="danger" %}
저장하지 않은 상태에서 **조회, 페이지 이동, 표시 개수 변경**을 하면 입력한 내용이 사라집니다. 반드시 저장 후 이동하세요.
{% endhint %}

***

### 7. 창고 삭제 대신 "미사용" 처리

저장된 창고는 목록에서 삭제할 수 없습니다. 더 이상 사용하지 않는 창고는 **사용 여부 체크를 해제**한 뒤 저장하세요.

***

### 8. 자주 묻는 질문 (FAQ)

**Q. 창고를 만들었는데 재고를 넣을 수 없어요.** \
창고 안에 로케이션이 있어야 합니다. \
로케이션 관리에서 로케이션을 만들어 주세요.

**Q. 어떤 창고는 코드가 수정되지 않고, 사용 여부도 바뀌지 않아요.** \
시스템용 **가상 창고**입니다. \
코드와 사용 여부는 변경할 수 없습니다. (위 5번 참고)

**Q. 저장 중 오류가 발생했다고 나와요.** \
창고 코드가 이미 사용 중인지, 창고 코드와 창고명이 모두 입력되었는지 확인해 주세요. \
계속 발생하면 관리자에게 문의해 주세요.

**Q. 행을 잘못 추가했어요. 어떻게 지우나요?** \
저장하기 전이라면 **조회** 버튼을 눌러 목록을 다시 불러오면 추가한 행이 사라집니다. \
(단, 저장하지 않은 다른 수정 내용도 함께 사라집니다.)

**Q. 창고를 삭제하고 싶어요.** \
저장된 창고는 삭제되지 않습니다. \
**사용 여부를 해제**하여 미사용 처리해 주세요.
