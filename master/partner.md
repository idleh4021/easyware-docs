# 거래처관리

물건을 공급받거나 출고하는 **거래처**를 등록하고 관리하는 화면입니다.

<figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

***

### 1. 거래처 구분

거래처는 **공급처**와 **고객사**로 구분합니다. 한 거래처가 두 가지 역할을 모두 할 수도 있습니다.

| 구분            | 의미                         | 예시          |
| ------------- | -------------------------- | ----------- |
| **공급처**       | 우리 창고로 물건을 보내주는 거래처 (입고처)  | 제조사, 도매상    |
| **고객사**       | 우리 창고에서 물건을 받아가는 거래처 (출고처) | 판매처, 대리점    |
| **공급처 + 고객사** | 물건을 공급하기도 하고 받아가기도 하는 거래처  | 상호 거래하는 협력사 |

***

### 2. 화면 구성

#### 2.1 상단 툴바

| 버튼/요소 | 위치  | 설명                                   |
| ----- | --- | ------------------------------------ |
| 검색창   | 왼쪽  | 검색할 거래처명을 입력합니다. `Enter`를 눌러도 조회됩니다. |
| 🔍 조회 | 왼쪽  | 조건에 맞는 거래처를 조회합니다.                   |
| ➕ 버튼  | 오른쪽 | 새 거래처 행을 추가합니다.                      |
| 💾 저장 | 오른쪽 | 추가/수정한 내용을 저장합니다.                    |

#### 2.2 거래처 목록 컬럼

| 컬럼      | 설명                               |  수정 |
| ------- | -------------------------------- | :-: |
| 거래처 코드  | 거래처를 구분하는 코드                     |  ✅  |
| 거래처명    | 거래처의 이름                          |  ✅  |
| 공급처     | 공급처(입고처) 여부                      |  ✅  |
| 고객사     | 고객사(출고처) 여부                      |  ✅  |
| 사업자번호   | 사업자등록번호 (`000-00-00000` 형식으로 표시) |  ✅  |
| 대표자     | 대표자 이름                           |  ✅  |
| 연락처     | 거래처 대표 연락처                       |  ✅  |
| 담당자     | 거래처 담당자 이름                       |  ✅  |
| 담당자 연락처 | 담당자 연락처                          |  ✅  |
| 담당자 이메일 | 담당자 이메일                          |  ✅  |
| 비고      | 메모                               |  ✅  |
| 사용 여부   | 사용 / 미사용                         |  ✅  |

#### 2.3 하단 페이지 이동 영역

| 요소                     | 설명                                       |
| ---------------------- | ---------------------------------------- |
| `«` `‹` 페이지 번호 `›` `»` | 처음 / 이전 / 해당 페이지 / 다음 / 마지막 페이지로 이동      |
| 표시 개수                  | 한 페이지에 표시할 개수 선택 (20 / 50 / 100 / 150개씩) |
| 총 N건                   | 조회 조건에 해당하는 전체 거래처 수                     |

### 3. 거래처 조회

1. 검색창에 **거래처명**을 입력합니다.
2. **조회** 버튼을 누르거나 `Enter`를 누릅니다.
3. 검색창을 비우고 조회하면 전체 거래처가 표시됩니다.

***

### 4. 거래처 추가

1. 툴바의 **➕ 버튼**을 클릭합니다.
2. 목록 맨 아래에 새 행이 추가되고, **거래처 코드 칸이 바로 입력 상태**가 됩니다.
3. 거래처명을 입력하고 **공급처 / 고객사** 여부를 체크합니다.
4. 사업자번호, 담당자 정보 등 나머지 항목을 입력합니다.
5. 💾 **저장**을 클릭합니다.

#### 거래처 코드 자동 생성

* 첫 번째 행은 서버에서 다음 거래처 코드를 받아옵니다.
* 행을 연달아 추가하면 이어지는 번호로 생성됩니다.
* 자동 생성된 코드는 필요하면 직접 수정할 수 있습니다.

{% hint style="warning" %}
**거래처 코드**와 **거래처명**은 반드시 입력해 주세요.
{% endhint %}

{% hint style="success" %}
**공급처 / 고객사 체크를 꼭 확인해 주세요.** 거래처의 역할을 정확히 지정해 두면 입고·출고 업무에서 거래처를 찾기 쉽습니다.
{% endhint %}

***

### 5. 거래처 수정

| 컬럼                                      | 수정 방법                   |
| --------------------------------------- | ----------------------- |
| 거래처 코드 / 거래처명 / 대표자 / 연락처 / 담당자 정보 / 비고 | 셀을 더블클릭하여 직접 입력         |
| 사업자번호                                   | 셀을 더블클릭하여 숫자 입력 (아래 참고) |
| 공급처 / 고객사 / 사용 여부                       | 체크박스 클릭                 |

수정한 뒤에는 반드시 **💾 저장**을 눌러야 반영됩니다.

#### 사업자번호 입력

* **숫자만** 입력하면 됩니다. 하이픈(`-`)을 함께 입력해도 숫자만 저장됩니다.
* 최대 **10자리**까지 저장되며, 화면에는 `123-45-67890` 형식으로 표시됩니다.

| 입력             | 저장되는 값     | 화면 표시        |
| -------------- | ---------- | ------------ |
| `1234567890`   | 1234567890 | 123-45-67890 |
| `123-45-67890` | 1234567890 | 123-45-67890 |

***

### 6. 저장

저장 버튼을 누르면 **새로 추가된 행**과 **수정된 행**만 골라서 한 번에 저장합니다. 저장이 끝나면 목록을 다시 불러오고, 다음과 같은 메시지가 표시됩니다.

> 저장 완료 (신규: N, 수정: N)

| 상황                      | 안내 메시지           |
| ----------------------- | ---------------- |
| 변경 사항이 없음               | 변경된 데이터가 없습니다.   |
| 저장 실패 (필수값 누락, 중복 코드 등) | 저장 중 오류가 발생했습니다. |

{% hint style="danger" %}
저장하지 않은 상태에서 **조회, 페이지 이동, 표시 개수 변경**을 하면 입력한 내용이 사라집니다. 반드시 저장 후 이동하세요.&#x20;
{% endhint %}

***

### 7. 거래처 삭제 대신 "미사용" 처리

저장된 거래처는 목록에서 삭제할 수 없습니다. 더 이상 거래하지 않는 거래처는 **사용 여부 체크를 해제**한 뒤 저장하세요.

***

### 8. 자주 묻는 질문 (FAQ)

**Q. 공급처와 고객사를 둘 다 체크해도 되나요?** \
네. 물건을 공급하기도 하고 받아가기도 하는 거래처라면 둘 다 체크해 주세요.

**Q. 사업자번호에 하이픈을 넣어야 하나요?** \
아니요. 숫자만 입력해도 화면에는 `000-00-00000` 형식으로 자동 표시됩니다.

**Q. 저장 중 오류가 발생했다고 나와요.** \
거래처 코드가 이미 사용 중인지, 거래처 코드와 거래처명이 모두 입력되었는지 확인해 주세요. \
계속 발생하면 관리자에게 문의해 주세요.

**Q. 행을 잘못 추가했어요. 어떻게 지우나요?** \
저장하기 전이라면 **조회** 버튼을 눌러 목록을 다시 불러오면 추가한 행이 사라집니다. \
(단, 저장하지 않은 다른 수정 내용도 함께 사라집니다.)

**Q. 거래처를 삭제하고 싶어요.** \
저장된 거래처는 삭제되지 않습니다. \
**사용 여부를 해제**하여 미사용 처리해 주세요.
