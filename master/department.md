# 부서관리

## 부서 관리

회사의 **부서(조직) 정보**를 등록하고 관리하는 화면입니다. 여기서 등록한 부서는 사용자 관리 등 다른 화면에서 사용됩니다.

***

### 1. 화면 구성

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

화면은 **상단 툴바**, **부서 목록**, **하단 페이지 이동 영역**으로 구성됩니다.

#### 1.1 상단 툴바

| 버튼/요소 | 위치  | 설명                                    |
| ----- | --- | ------------------------------------- |
| 검색창   | 왼쪽  | 검색할 부서 코드를 입력합니다. `Enter`를 눌러도 조회됩니다. |
| 🔍 조회 | 왼쪽  | 검색 조건으로 부서 목록을 조회합니다.                 |
| ➕ 버튼  | 오른쪽 | 새 부서 행을 추가합니다.                        |
| **행 복제** | 오른쪽 | 마지막으로 클릭한 행을 바로 아래에 복사합니다. 단축키는 목록에서 `Ctrl + Shift + Enter`입니다. |
| 💾 저장 | 오른쪽 | 추가/수정한 내용을 저장합니다.                     |

#### 1.2 부서 목록 컬럼

| 컬럼     | 설명                    |  수정 |
| ------ | --------------------- | :-: |
| 부서 코드  | 부서를 구분하는 코드 (대문자로 표시) |  ✅  |
| 부서명    | 부서의 이름                |  ✅  |
| 정렬 순서  | 목록에서 표시되는 순서 (숫자)     |  ✅  |
| 사용 여부  | 체크박스로 사용/미사용 전환       |  ✅  |
| 비고     | 메모                    |  ✅  |
| 최종 수정일 | 마지막으로 수정된 일시          |  —  |

#### 1.3 하단 페이지 이동 영역

| 요소                     | 설명                                       |
| ---------------------- | ---------------------------------------- |
| `«` `‹` 페이지 번호 `›` `»` | 처음 / 이전 / 해당 페이지 / 다음 / 마지막 페이지로 이동      |
| 표시 개수                  | 한 페이지에 표시할 개수 선택 (20 / 50 / 100 / 150개씩) |
| 총 N건                   | 조회 조건에 해당하는 전체 부서 수                      |

***

### 2. 기본 사용 흐름

```
① 조회  →  ② 행 추가 또는 셀 수정  →  ③ 저장
```

1. 화면에 들어오면 부서 목록이 자동으로 조회됩니다.
2. ➕ 버튼으로 부서를 추가하거나, 기존 부서의 셀을 수정합니다.
3. 💾 **저장**을 눌러 반영합니다.

***

### 3. 부서 조회

1. 검색창에 **부서 코드**를 입력합니다.
2. **조회** 버튼을 누르거나 `Enter`를 누릅니다.
3. 검색창을 비우고 조회하면 전체 부서가 표시됩니다.

***

### 4. 부서 추가

1. 툴바의 **➕ 버튼**을 클릭합니다.
2. 목록 맨 아래에 새 행이 추가되고, **부서 코드 칸이 바로 입력 상태**가 됩니다.
3. 부서명 등 나머지 항목을 입력합니다.
4. 💾 **저장**을 클릭합니다.

#### 4.1 부서 코드 자동 생성

새 행을 추가하면 **부서 코드가 자동으로 생성**됩니다.

* 첫 번째 행은 서버에서 다음 부서 코드를 받아옵니다.
* 저장하기 전에 행을 연달아 추가하면 이어지는 번호로 생성됩니다.
* 자동 생성된 코드는 필요하면 직접 수정할 수 있습니다.

{% hint style="warning" %}
**부서 코드**와 **부서명**은 필수입니다. 비어 있으면 저장되지 않습니다.
{% endhint %}

#### 행 복제

비슷한 행을 여러 개 등록할 때는 복사할 행을 클릭하고 툴바의 **행 복제**를 누르세요. (단축키: 부서 목록에서 `Ctrl + Shift + Enter`) 클릭한 행 바로 아래에 새 행이 추가됩니다.

{% hint style="info" %}
부서 코드는 새로 자동 생성되고, 나머지 내용이 복사됩니다. 복제한 행도 💾 **저장**해야 등록됩니다.
{% endhint %}

***

### 5. 부서 수정

수정하려는 셀을 **더블클릭**하면 편집할 수 있습니다.

| 컬럼               | 수정 방법                              |
| ---------------- | ---------------------------------- |
| 부서 코드 / 부서명 / 비고 | 셀을 더블클릭하여 직접 입력                    |
| 정렬 순서            | 셀을 더블클릭하여 숫자 입력 (숫자가 아니면 `0`으로 저장) |
| 사용 여부            | 체크박스 클릭                            |

수정한 뒤에는 반드시 **💾 저장**을 눌러야 반영됩니다.

***

### 6. 저장

저장 버튼을 누르면 **새로 추가된 행**과 **수정된 행**만 골라서 한 번에 저장합니다. 저장이 끝나면 목록을 다시 불러오고, 다음과 같은 메시지가 표시됩니다.

> 저장 완료! (신규: N건, 수정: N건)

| 상황                | 안내 메시지               |
| ----------------- | -------------------- |
| 변경 사항이 없음         | 변경된 데이터가 없습니다.       |
| 필수값(부서 코드/부서명) 누락 | 누락된 항목에 대한 안내 메시지    |
| 저장 실패             | 저장 중 시스템 오류가 발생했습니다. |

{% hint style="danger" %}
저장하지 않은 상태에서 **조회, 페이지 이동, 표시 개수 변경**을 하면 입력한 내용이 사라집니다. 반드시 저장 후 이동하세요.
{% endhint %}

***

### 7. 부서 삭제 대신 "미사용" 처리

저장된 부서는 목록에서 삭제할 수 없습니다. 더 이상 사용하지 않는 부서는 **사용 여부 체크를 해제**한 뒤 저장하세요.

***

### 8. 자주 묻는 질문 (FAQ)

**Q. 부서명으로 검색이 안 돼요.** \
현재 검색은 **부서 코드** 기준으로 동작합니다. 부서 코드로 검색해 주세요.

**Q. 행을 잘못 추가했어요. 어떻게 지우나요?** \
저장하기 전이라면 **조회** 버튼을 눌러 목록을 다시 불러오면 추가한 행이 사라집니다. (단, 저장하지 않은 다른 수정 내용도 함께 사라집니다.)

**Q. 저장 중 오류가 발생했다고 나와요.** \
부서 코드가 이미 사용 중인지, 필수값이 모두 입력되었는지 확인해 주세요. \
계속 발생하면 관리자에게 문의해 주세요.

**Q. 부서를 삭제하고 싶어요.** \
저장된 부서는 삭제되지 않습니다. \
**사용 여부를 해제**하여 미사용 처리해 주세요.

**Q. 한 화면에 더 많은 부서를 보고 싶어요.** \
하단의 표시 개수에서 50 / 100 / 150개씩을 선택해 주세요.

***

### 9. 키 조작 요약

| 키       | 위치     | 동작    |
| ------- | ------ | ----- |
| `Enter` | 검색창    | 조회    |
| `Enter` | 셀 편집 중 | 편집 확정 |
| `Esc`   | 셀 편집 중 | 편집 취소 |
| `Ctrl + Shift + Enter` | 부서 목록 | 마지막으로 클릭한 행 복제 |
