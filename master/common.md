# 공통코드

## 공통코드 관리

시스템 전반에서 사용하는 **상태값, 구분값, 분류값** 등을 한곳에서 등록하고 관리하는 화면입니다.

공통코드는 **그룹 코드**와 **상세 코드**의 2단계 구조로 구성됩니다.

| 구분    | 설명            | 예시                        |
| ----- | ------------- | ------------------------- |
| 그룹 코드 | 코드의 묶음(분류)    | `INBOUND-STAT` (입고상태코드)   |
| 상세 코드 | 그룹에 속한 실제 코드값 | `INBOUND-STAT-001` (입고대기) |

***

### 1. 화면 구성

화면은 좌우 두 영역으로 나뉩니다.

<figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

| 영역      | 위치  | 역할                           |
| ------- | --- | ---------------------------- |
| ① 그룹 코드 | 왼쪽  | 그룹 코드 목록 조회, 등록, 수정          |
| ② 상세 코드 | 오른쪽 | 선택한 그룹의 상세 코드 조회, 추가, 수정, 저장 |

#### 1.1 그룹 코드 영역

| 버튼/요소   | 설명                          |
| ------- | --------------------------- |
| 🔄 새로고침 | 그룹 코드 목록을 다시 불러옵니다.         |
| 검색창     | 목록 내 모든 컬럼을 대상으로 즉시 필터링합니다. |
| ➕ 버튼    | 새 그룹 코드를 등록하는 팝업을 엽니다.      |

**목록 컬럼**

| 컬럼     | 설명                       |
| ------ | ------------------------ |
| 그룹 코드  | 그룹을 구분하는 코드 (대문자로 표시)    |
| 그룹 코드명 | 그룹의 이름                   |
| 수정 권한  | 이 그룹을 수정하려면 필요한 최소 권한 레벨 |
| 사용 여부  | 사용 / 미사용                 |

#### 1.2 상세 코드 영역

| 버튼/요소   | 설명                                              |
| ------- | ----------------------------------------------- |
| 그룹 배지   | 현재 선택된 그룹 코드를 표시합니다. 선택 전에는 "그룹을 선택하세요"로 표시됩니다. |
| 🔄 새로고침 | 선택한 그룹의 상세 코드를 다시 불러옵니다. (그룹 선택 후 사용 가능)        |
| 검색창     | 상세 코드 목록 내 즉시 필터링                               |
| ➕ 버튼    | 상세 코드 행을 추가합니다.                                 |
| **행 복제** | 마지막으로 클릭한 행을 바로 아래에 복사합니다. 단축키는 목록에서 `Ctrl + Shift + Enter`입니다. |
| 💾 저장   | 추가/수정한 내용을 서버에 저장합니다.                           |

**목록 컬럼**

| 컬럼           | 설명                       | 비고                            |
| ------------ | ------------------------ | ----------------------------- |
| 상세 코드        | 코드값                      | 신규 행은 자동 생성됩니다.               |
| 상세 코드명       | 코드의 이름                   | 필수                            |
| 색상           | 코드에 연결할 색상               | 클릭하면 색상 선택창이 열립니다.            |
| 정렬 순서        | 목록에서 표시되는 순서             | 숫자                            |
| 값1 / 값2 / 값3 | 추가 속성값                   | 컬럼명은 그룹 설정에 따라 바뀝니다. (3.2 참고) |
| 사용 여부        | 체크박스로 사용/미사용 전환          |                               |
| 수정 권한        | 이 코드를 수정하려면 필요한 최소 권한 레벨 | 드롭다운 선택                       |
| 작업           | 신규 행에만 **취소** 버튼 표시      | 저장 전 행 제거용                    |

***

### 2. 기본 사용 흐름

```
① 그룹 코드 등록  →  ② 그룹 선택  →  ③ 상세 코드 추가  →  ④ 저장
```

1. 왼쪽에서 **그룹 코드**를 등록합니다. (이미 있다면 생략)
2. 그룹 목록에서 원하는 그룹을 **클릭**합니다.
3. 오른쪽에서 **상세 코드**를 추가하고 값을 입력합니다.
4. **저장** 버튼을 눌러 반영합니다.

***

### 3. 그룹 코드 관리

#### 3.1 그룹 코드 등록

1. 그룹 코드 영역 상단의 **➕ 버튼**을 클릭합니다.
2. 팝업에서 항목을 입력합니다.
3. **저장**을 클릭합니다.

<figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

| 항목       |  필수 | 설명                      | 예시             |
| -------- | :-: | ----------------------- | -------------- |
| 그룹 코드    |  ✅  | 그룹을 구분하는 고유 코드          | `INBOUND-STAT` |
| 그룹 코드명   |  ✅  | 그룹의 이름                  | `입고상태코드`       |
| 수정 가능 레벨 |     | 이 그룹을 수정할 수 있는 최소 권한 레벨 | 기본값: 내 권한 레벨   |
| 사용 여부    |     | 사용 / 미사용                | 기본값: 사용        |
| 추가 설정    |     | 값1\~3 명칭 (아래 참고)        |                |

{% hint style="warning" %}
**그룹 코드**와 **그룹 코드명**은 필수 항목입니다. 비어 있으면 저장되지 않습니다. 이미 사용 중인 코드 등 서버에서 거부된 경우에는 사유가 화면 메시지로 표시됩니다.
{% endhint %}

#### 3.2 추가 설정: 값1/값2/값3 명칭

팝업의 \*\*추가 설정 ▾\*\*을 누르면 `값1 명칭`, `값2 명칭`, `값3 명칭` 입력란이 펼쳐집니다.

상세 코드는 코드·이름 외에 최대 3개의 추가 값(값1\~3)을 가질 수 있는데, 여기에 입력한 명칭이 **상세 코드 목록의 컬럼 제목**으로 표시됩니다.

| 그룹 설정          | 상세 코드 컬럼 제목         |
| -------------- | ------------------- |
| 값1 명칭 = `상태색상` | 값1 → **상태색상**       |
| 값2 명칭 = `아이콘`  | 값2 → **아이콘**        |
| 값3 명칭 입력 안 함   | 값3 → **값3** (기본 제목) |

#### 3.3 그룹 코드 수정

1. 그룹 목록에서 수정할 그룹을 **더블클릭**합니다.
2. 팝업에서 내용을 수정한 뒤 **저장**을 클릭합니다.

{% hint style="info" %}
한 번 클릭하면 상세 코드가 조회되고, **더블클릭**하면 수정 팝업이 열립니다.
{% endhint %}

***

### 4. 상세 코드 관리

#### 4.1 상세 코드 조회

왼쪽 그룹 목록에서 그룹을 **클릭**하면 오른쪽에 해당 그룹의 상세 코드가 표시됩니다. **사용 여부와 관계없이 미사용 코드도 모두 표시**됩니다.

#### 4.2 상세 코드 추가

1. 그룹을 선택한 상태에서 **➕ 버튼**을 클릭합니다. (단축키: 상세 코드 그리드에서 `Shift + Enter`)
2. 목록 맨 아래에 새 행이 추가되고, **상세 코드 칸이 바로 입력 상태**가 됩니다.
3. 상세 코드명 등 나머지 항목을 입력합니다.
4. 💾 **저장**을 클릭합니다.

새 행의 기본값은 다음과 같습니다.

| 항목    | 기본값                                                      |
| ----- | -------------------------------------------------------- |
| 상세 코드 | 그룹 코드를 기준으로 자동 생성 (예: `INBOUND-STAT-001`, 필요 시 직접 수정 가능) |
| 정렬 순서 | 현재 행 개수를 기준으로 자동 부여                                      |
| 사용 여부 | 사용                                                       |
| 수정 권한 | 내 권한 레벨                                                  |

{% hint style="warning" %}
**상세 코드**와 **상세 코드명**은 필수입니다. 비어 있으면 저장되지 않습니다.
{% endhint %}

#### 행 복제

비슷한 행을 여러 개 등록할 때는 복사할 행을 클릭하고 툴바의 **행 복제**를 누르세요. (단축키: 상세 코드 목록에서 `Ctrl + Shift + Enter`) 클릭한 행 바로 아래에 새 행이 추가됩니다.

{% hint style="info" %}
상세 코드는 새로 생성되고 이름·색상·순서·값1~3이 복사됩니다. 내 권한보다 높은 레벨로 잠긴 코드는 복제할 수 없습니다. 복제한 행도 저장해야 등록됩니다.
{% endhint %}

#### 4.3 상세 코드 수정

수정하려는 셀을 **더블클릭**(색상은 **한 번 클릭**)하면 편집할 수 있습니다.

| 컬럼                             | 수정 방법              |
| ------------------------------ | ------------------ |
| 상세 코드 / 상세 코드명 / 정렬 순서 / 값1\~3 | 셀을 더블클릭하여 직접 입력    |
| 색상                             | 셀을 클릭하면 색상 선택창이 열림 |
| 사용 여부                          | 체크박스 클릭            |
| 수정 권한                          | 드롭다운에서 레벨 선택       |

수정한 뒤에는 반드시 **💾 저장**을 눌러야 서버에 반영됩니다.

#### 4.4 상세 코드 저장

저장 버튼을 누르면 **신규 추가된 행**과 **수정된 행**만 골라서 한 번에 저장합니다.

저장이 끝나면 다음과 같은 메시지가 표시됩니다.

> 저장 완료! (신규: N건, 수정: N건)

| 상황                 | 안내 메시지               |
| ------------------ | -------------------- |
| 그룹을 선택하지 않고 저장     | 저장할 그룹을 먼저 선택하세요     |
| 변경 사항이 없음          | 변경된 데이터가 없습니다.       |
| 필수값(상세 코드/코드명) 누락  | 누락된 항목에 대한 안내 메시지    |
| 서버에서 거부 (예: 중복 코드) | 서버가 알려주는 사유 표시       |
| 그 외 오류             | 저장 중 시스템 오류가 발생했습니다. |

{% hint style="danger" %}
수정 후 **저장하지 않고** 다른 그룹을 선택하거나 새로고침하면 **입력한 내용이 사라집니다.** 반드시 저장 후 이동하세요.
{% endhint %}

#### 4.5 추가한 행 취소

저장하기 전 새로 추가한 행은 오른쪽 **작업** 컬럼의 **\[취소]** 버튼으로 목록에서 제거할 수 있습니다.

#### 4.6 상세 코드 삭제 대신 "미사용" 처리

이미 저장된 상세 코드는 목록에서 삭제할 수 없습니다. 더 이상 사용하지 않는 코드는 **사용 여부 체크를 해제**한 뒤 저장하세요.

***

### 5. 수정 권한 (권한 레벨)

공통코드는 데이터마다 **수정 가능 레벨**이 지정되어 있어, 내 권한 레벨보다 높은 레벨로 지정된 데이터는 수정할 수 없습니다.

| 구분            | 설명               |
| ------------- | ---------------- |
| 내 권한 레벨       | 로그인한 사용자의 권한 레벨  |
| 데이터의 수정 가능 레벨 | 그룹/상세 코드마다 지정된 값 |

#### 5.1 규칙

* **내 레벨 ≥ 데이터의 수정 가능 레벨** → 수정 가능
* **내 레벨 < 데이터의 수정 가능 레벨** → 잠금(수정 불가)

#### 5.2 잠긴 데이터의 표시

**상세 코드 목록**

* 행 배경이 **회색**으로 표시됩니다.
* 상세 코드, 상세 코드명, 정렬 순서, 값1\~3은 편집할 수 없습니다.
* 사용 여부, 수정 권한 항목도 변경할 수 없습니다.
* 마우스를 올리면 사용 불가 커서(🚫)가 표시됩니다.

**그룹 코드 수정 팝업**

* 수정 가능 레벨 선택이 비활성화됩니다.
* 하단에 🔒 _해당 데이터를 수정할 권한이 없습니다._ 문구가 표시됩니다.
* **저장 버튼이 비활성화**됩니다.

#### 5.3 수정 가능 레벨 지정 시 유의사항

* 수정 가능 레벨을 선택할 때, **내 권한 레벨보다 높은 레벨은 선택할 수 없습니다.** (🔒 표시)
* 신규 등록 시 기본값은 **내 권한 레벨**입니다.

{% hint style="warning" %}
수정 가능 레벨을 내 레벨보다 낮게 설정하면 하위 권한 사용자도 해당 코드를 수정할 수 있습니다. 중요한 코드는 적절한 레벨로 지정해 주세요.&#x20;
{% endhint %}

### 6. 자주 묻는 질문 (FAQ)

**Q. 그룹을 클릭했는데 상세 코드가 비어 있어요.** \
해당 그룹에 등록된 상세 코드가 없는 경우입니다. ➕ 버튼으로 추가해 주세요.

**Q. 상세 코드를 추가했는데 저장이 안 돼요.** \
상세 코드와 상세 코드명이 모두 입력되었는지 확인해 주세요. 서버 오류 메시지가 표시되면 해당 내용(예: 중복 코드)을 확인해 주세요.

**Q. 어떤 행은 수정이 안 돼요.** \
내 권한 레벨보다 높은 수정 가능 레벨로 지정된 데이터입니다. (5. 수정 권한 참고) 필요한 경우 관리자에게 문의해 주세요.

**Q. 상세 코드를 삭제하고 싶어요.** \
저장된 코드는 삭제되지 않습니다. **사용 여부를 해제**하여 미사용 처리해 주세요.

**Q. 목록이 너무 많아서 찾기 어려워요.** \
각 영역 상단의 검색창에 키워드를 입력하면 해당 목록에서 즉시 필터링됩니다. 컬럼 제목을 클릭하면 정렬, 컬럼 경계를 드래그하면 너비 조절도 가능합니다.
