# 품목관리

창고에서 관리하는 **품목(상품)** 과 품목을 분류하는 **카테고리**를 등록하고 관리하는 메뉴입니다.

### 품목과 카테고리의 관계

카테고리는 **대분류 → 중분류 → 소분류**의 3단계로 구성되며, 각 품목은 하나의 카테고리에 속합니다.

```
전체 카테고리
 └─ [대] 식품
     └─ [중] 과자
         └─ [소] 스낵
               ├─ 새우깡
               └─ 감자칩
```

카테고리에는 **기본 단위, LOT 관리, S/N 관리, 선입선출, 출고 검수** 설정을 지정할 수 있습니다. 품목에서 카테고리를 선택하면 이 설정이 품목에 **자동으로 채워집니다.**

```
카테고리 기본값 설정  →  품목에서 카테고리 선택  →  단위·LOT·S/N·선입선출·출고 검수 자동 입력
```

***

### 처음 사용한다면

{% hint style="success" %}
**카테고리를 먼저 등록**하는 것을 권장합니다. 카테고리별 기본값을 설정해 두면 품목을 등록할 때 반복 입력이 줄어듭니다.
{% endhint %}

1. **카테고리 관리**에서 대분류 → 중분류 → 소분류를 등록하고 기본값을 설정합니다.
2. **품목 관리**에서 품목을 추가하고 카테고리를 선택합니다.

***

### 공통 안내

* 탭을 바꿔도 작업 중이던 내용은 그대로 유지됩니다. 단, **저장하기 전까지는 서버에 반영되지 않습니다.**
* 저장된 품목과 카테고리는 삭제할 수 없습니다. 더 이상 사용하지 않는다면 **사용 여부를 해제**해 주세요.
* 카테고리 관리에서 저장한 내용은 품목 관리 탭의 카테고리 선택 목록에 바로 반영됩니다.
