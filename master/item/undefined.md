# 품목 관리



창고에서 관리하는 **품목(상품)** 을 등록, 수정, 조회하는 화면입니다.

### 1. 화면 구성

#### 1.1 상단 툴바

| 버튼/요소           | 위치  | 설명                                       |
| --------------- | --- | ---------------------------------------- |
| 대분류 / 중분류 / 소분류 | 왼쪽  | 카테고리 조회 조건 (상위 분류를 고르면 하위 분류가 활성화됩니다)    |
| 검색창             | 왼쪽  | 품목명 또는 품목 코드를 입력합니다. `Enter`를 눌러도 조회됩니다. |
| 🔍 조회           | 왼쪽  | 조건에 맞는 품목을 조회합니다.                        |
| ➕ 버튼            | 오른쪽 | 새 품목 행을 추가합니다.                           |
| 💾 저장           | 오른쪽 | 추가/수정한 내용을 저장합니다.                        |

#### 1.2 품목 목록 컬럼

| 컬럼         | 설명                          |  수정 |
| ---------- | --------------------------- | :-: |
| 카테고리       | 품목이 속한 카테고리 (드롭다운 선택)       |  ✅  |
| 품목 코드      | 품목을 구분하는 코드 (대문자로 표시)       |  ✅  |
| 품목명        | 품목의 이름                      |  ✅  |
| 품목 요약설명    | 품목에 대한 간단한 설명               |  ✅  |
| 단위         | 수량 단위 (예: EA, BOX)          |  ✅  |
| 안전 재고      | 유지해야 할 최소 재고 수량             |  ✅  |
| 박스당 수량     | 한 박스에 들어가는 수량               |  ✅  |
| Pallet당 수량 | 한 팔레트에 들어가는 수량              |  ✅  |
| 표준 입고가     | 기준 입고 단가                    |  ✅  |
| 표준 출고가     | 기준 출고 단가                    |  ✅  |
| LOT 관리     | LOT(생산 묶음) 번호로 관리하는 품목인지 여부 |  ✅  |
| S/N 관리     | 시리얼 번호로 개별 관리하는 품목인지 여부     |  ✅  |
| 선입선출       | 먼저 들어온 재고를 먼저 출고할지 여부       |  ✅  |
| 사용 여부      | 사용 / 미사용                    |  ✅  |
| 등록 일시      | 품목이 처음 등록된 일시               |  —  |
| 수정 일시      | 마지막으로 수정된 일시                |  —  |

#### 1.3 하단 페이지 이동 영역

| 요소                     | 설명                                       |
| ---------------------- | ---------------------------------------- |
| `«` `‹` 페이지 번호 `›` `»` | 처음 / 이전 / 해당 페이지 / 다음 / 마지막 페이지로 이동      |
| 표시 개수                  | 한 페이지에 표시할 개수 선택 (20 / 50 / 100 / 150개씩) |
| 총 N건                   | 조회 조건에 해당하는 전체 품목 수                      |

### 2. 품목 조회

1. 필요하면 대분류 → 중분류 → 소분류 순서로 카테고리를 선택합니다.
2. 검색창에 품목명 또는 품목 코드를 입력합니다.
3. **조회** 버튼을 누르거나 `Enter`를 누릅니다.

\{% hint style="info" %\}

* 분류는 선택한 단계 중 **가장 하위 분류**를 기준으로 조회합니다. (예: 대분류와 중분류를 선택하면 중분류 기준)
* 상위 분류를 바꾸면 하위 분류 선택은 초기화됩니다.
* 조회하면 항상 **1페이지**부터 다시 표시됩니다. \{% endhint %\}

***

### 3. 품목 추가

1. 툴바의 **➕ 버튼**을 클릭합니다.
2. 목록 맨 아래에 새 행이 추가되고, **품목 코드 칸이 바로 입력 상태**가 됩니다.
3. **카테고리**를 선택합니다. (선택하면 단위·LOT·S/N·선입선출이 자동 입력됩니다. 아래 5번 참고)
4. 품목명 등 나머지 항목을 입력합니다.
5. 💾 **저장**을 클릭합니다.

새 행의 기본값은 다음과 같습니다.

| 항목                          | 기본값                   |
| --------------------------- | --------------------- |
| 품목 코드                       | 자동 생성 (필요 시 직접 수정 가능) |
| 카테고리                        | 선택 안 함                |
| 단위                          | EA                    |
| 안전 재고 / 박스당 수량 / Pallet당 수량 | 0                     |
| 표준 입고가 / 표준 출고가             | 0                     |
| LOT 관리 / S/N 관리             | 미사용                   |
| 선입선출                        | 사용                    |
| 사용 여부                       | 사용                    |

#### 품목 코드 자동 생성

* 첫 번째 행은 서버에서 다음 품목 코드를 받아옵니다.
* 저장하기 전에 행을 연달아 추가하면 이어지는 번호로 생성됩니다.
* 코드를 생성하는 동안 ➕ 버튼에 로딩 표시가 나타나며, 잠시 클릭할 수 없습니다.

{% hint style="warning" %}
**품목 코드**와 **품목명**은 필수입니다. 비어 있으면 저장되지 않습니다.&#x20;
{% endhint %}

***

### 4. 품목 수정

| 컬럼                             | 수정 방법                              |
| ------------------------------ | ---------------------------------- |
| 카테고리                           | 셀의 드롭다운에서 선택                       |
| 품목 코드 / 품목명 / 요약설명 / 단위        | 셀을 더블클릭하여 직접 입력                    |
| 안전 재고 / 수량 / 단가                | 셀을 더블클릭하여 숫자 입력 (숫자가 아니면 `0`으로 저장) |
| LOT 관리 / S/N 관리 / 선입선출 / 사용 여부 | 체크박스 클릭                            |

수정한 뒤에는 반드시 **💾 저장**을 눌러야 반영됩니다.

***

### 5. 카테고리 선택 시 자동 입력

품목의 카테고리를 선택하면, 해당 카테고리에 설정된 기본값이 품목에 **자동으로 채워집니다.**

| 품목 항목  | 채워지는 값          |
| ------ | --------------- |
| 단위     | 카테고리의 **기본 단위** |
| LOT 관리 | 카테고리의 LOT 관리 설정 |
| S/N 관리 | 카테고리의 S/N 관리 설정 |
| 선입선출   | 카테고리의 선입선출 설정   |

카테고리 선택을 해제하면 단위는 `EA`, LOT·S/N 관리는 미사용, 선입선출은 사용으로 되돌아갑니다.

카테고리별 기본값은 카테고리 관리 화면에서 설정합니다.

{% hint style="warning" %}
**기존 품목**의 카테고리를 바꿀 때도 단위·LOT·S/N·선입선출 값이 새 카테고리 기준으로 **덮어써집니다.** 품목별로 따로 설정해 둔 값이 있다면 카테고리 변경 후 다시 확인해 주세요.
{% endhint %}

***

### 6. 저장

저장 버튼을 누르면 **새로 추가된 행**과 **수정된 행**만 골라서 한 번에 저장합니다. 저장이 끝나면 목록을 다시 불러오고, 다음과 같은 메시지가 표시됩니다.

> 저장 완료! (신규: N건, 수정: N건)

| 상황                 | 안내 메시지               |
| ------------------ | -------------------- |
| 변경 사항이 없음          | 변경된 데이터가 없습니다.       |
| 필수값(품목 코드/품목명) 누락  | 누락된 항목에 대한 안내 메시지    |
| 서버에서 거부 (예: 중복 코드) | 서버가 알려주는 사유 표시       |
| 그 외 오류             | 저장 중 시스템 오류가 발생했습니다. |

{% hint style="danger" %}
저장하지 않은 상태에서 **조회, 페이지 이동, 표시 개수 변경**을 하면 입력한 내용이 사라집니다. 반드시 저장 후 이동하세요.
{% endhint %}

***

### 7. 품목 삭제 대신 "미사용" 처리

저장된 품목은 목록에서 삭제할 수 없습니다. 더 이상 취급하지 않는 품목은 **사용 여부 체크를 해제**한 뒤 저장하세요.

***

### 8. 자주 묻는 질문 (FAQ)

**Q. 품목 추가 시 단위·LOT·선입선출을 매번 입력하기 번거로워요.** \
카테고리 관리에서 카테고리별 기본값을 설정해 두세요. \
품목에서 카테고리를 선택하면 자동으로 채워집니다.

**Q. 품목의 카테고리를 바꿨더니 단위가 바뀌었어요.** \
카테고리를 선택하면 해당 카테고리의 기본값으로 덮어써집니다. \
필요하면 단위 셀을 다시 수정한 뒤 저장해 주세요.

**Q. 카테고리 선택 목록에 방금 만든 카테고리가 안 보여요.** \
카테고리 관리 탭에서 **저장**을 했는지 확인해 주세요. 저장해야 이 화면에 반영됩니다.

**Q. 행을 잘못 추가했어요. 어떻게 지우나요?** \
저장하기 전이라면 **조회** 버튼을 눌러 목록을 다시 불러오면 추가한 행이 사라집니다. \
(단, 저장하지 않은 다른 수정 내용도 함께 사라집니다.)

**Q. LOT 관리와 S/N 관리는 무엇이 다른가요?** \
**LOT 관리**는 같은 날 생산된 묶음 단위(예: 유통기한이 같은 식품)로 재고를 구분합니다. \
**S/N 관리**는 개별 제품마다 고유한 시리얼 번호(예: 전자제품)로 재고를 구분합니다.

**Q. 품목을 삭제하고 싶어요.** \
저장된 품목은 삭제되지 않습니다. \
**사용 여부를 해제**하여 미사용 처리해 주세요.
