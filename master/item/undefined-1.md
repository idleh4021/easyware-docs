# 카테고리 관리

품목을 분류하는 **카테고리**를 **대분류 → 중분류 → 소분류**의 3단계로 등록하고 관리하는 화면입니다.

```
전체 카테고리
 └─ [대] 식품
     └─ [중] 과자
         └─ [소] 스낵
```

카테고리마다 **기본 단위, LOT 관리, S/N 관리, 선입선출**을 설정할 수 있으며, 이 값은 품목 관리에서 카테고리를 선택할 때 자동으로 채워집니다.

### 1. 화면 구성

화면은 좌우 두 영역으로 나뉩니다.

| 영역            | 위치  | 역할                                 |
| ------------- | --- | ---------------------------------- |
| ① 카테고리 계층     | 왼쪽  | 전체 카테고리를 트리 구조로 표시, 카테고리 선택        |
| ② 하위 카테고리 리스트 | 오른쪽 | 선택한 카테고리 바로 아래 단계의 카테고리 조회, 추가, 수정 |

#### 1.1 카테고리 계층 (트리)

| 요소            | 설명                                                                                                                                            |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 🔄 새로고침       | 트리를 다시 불러옵니다.                                                                                                                                 |
| `▾` / `▸` 화살표 | 하위 카테고리를 펼치거나 접습니다. (하위가 있을 때만 표시)                                                                                                            |
| 단계 배지         | \<mark style="color:blue;">**대**\</mark> 대분류 · \<mark style="color:orange;">**중**\</mark> 중분류 · \<mark style="color:green;">**소**\</mark> 소분류 |
| 카테고리명 (코드)    | 클릭하면 해당 카테고리가 선택되고, 오른쪽에 하위 목록이 표시됩니다.                                                                                                        |

#### 1.2 하위 카테고리 리스트

| 버튼/요소        | 설명                            |
| ------------ | ----------------------------- |
| \[선택한 카테고리명] | 현재 선택된 상위 카테고리                |
| 🔄 새로고침      | 하위 목록을 다시 불러옵니다.              |
| ➕ 하위 추가      | 선택한 카테고리 아래에 새 카테고리 행을 추가합니다. |
| **행 복제** | 마지막으로 클릭한 행을 바로 아래에 복사합니다. 단축키는 목록에서 `Ctrl + Shift + Enter`입니다. |
| 💾 저장        | 추가/수정한 내용을 저장합니다.             |

**목록 컬럼**

| 컬럼      | 설명                           |
| ------- | ---------------------------- |
| 카테고리 코드 | 카테고리를 구분하는 코드                |
| 카테고리명   | 카테고리의 이름                     |
| 기본 단위   | 이 카테고리의 품목에 자동 입력될 단위        |
| LOT 관리  | 이 카테고리의 품목에 자동 적용될 LOT 관리 여부 |
| S/N 관리  | 이 카테고리의 품목에 자동 적용될 S/N 관리 여부 |
| 선입선출    | 이 카테고리의 품목에 자동 적용될 선입선출 여부   |
| 출고 검수   | 이 카테고리의 품목에 자동 적용될 출고 검수 여부   |
| 사용 여부   | 사용 / 미사용                     |
| 작업      | 신규 행에만 **취소** 버튼 표시          |

### 2. 무엇을 선택하면 무엇이 보이나요?

| 트리에서 선택 | 오른쪽에 표시되는 목록   | 추가되는 카테고리 |
| ------- | -------------- | --------- |
| 전체 카테고리 | 대분류 목록         | 대분류       |
| 대분류     | 해당 대분류의 중분류 목록 | 중분류       |
| 중분류     | 해당 중분류의 소분류 목록 | 소분류       |
| 소분류     | (비활성화)         | 추가 불가     |

{% hint style="info" %}
**소분류**는 최하위 단계이므로, 선택하면 오른쪽 영역이 비활성화되고 _"최하위 단계(소분류) 카테고리"_ 안내가 표시됩니다.
{% endhint %}

***

### 3. 카테고리 추가

1. 왼쪽 트리에서 **상위 카테고리**를 선택합니다. (대분류를 만들려면 **전체 카테고리** 선택)
2. **➕ 하위 추가**를 클릭합니다. (단축키: 목록에서 `Shift + Enter`)
3. 목록 맨 아래에 새 행이 추가되고, **카테고리 코드 칸이 바로 입력 상태**가 됩니다.
4. 카테고리명 등을 입력합니다.
5. 💾 **저장**을 클릭합니다.

새 행의 기본값은 다음과 같습니다.

| 항목                       | 기본값                                                               |
| ------------------------ | ----------------------------------------------------------------- |
| 카테고리 코드                  | 상위 카테고리 코드를 기준으로 자동 생성 (필요 시 직접 수정 가능)                            |
| 기본 단위 / LOT / S/N / 선입선출 | **상위 카테고리의 설정을 그대로 물려받음** (대분류는 EA · LOT 미사용 · S/N 미사용 · 선입선출 사용) |
| 사용 여부                    | 사용                                                                |

{% hint style="warning" %}
**카테고리 코드**와 **카테고리명**은 필수입니다. 비어 있으면 저장되지 않습니다.&#x20;
{% endhint %}

#### 추가한 행 취소

저장하기 전 새로 추가한 행은 오른쪽 **작업** 컬럼의 **\[취소]** 버튼으로 목록에서 제거할 수 있습니다.

#### 행 복제

비슷한 행을 여러 개 등록할 때는 복사할 행을 클릭하고 툴바의 **행 복제**를 누르세요. (단축키: 하위 카테고리 목록에서 `Ctrl + Shift + Enter`) 클릭한 행 바로 아래에 새 행이 추가됩니다.

{% hint style="info" %}
카테고리명과 기본값 설정(단위·LOT·S/N·선입선출 등)이 복사됩니다. 복제한 행도 💾 **저장**해야 등록됩니다.
{% endhint %}

***

### 4. 카테고리 수정

| 컬럼                             | 수정 방법           |
| ------------------------------ | --------------- |
| 카테고리 코드 / 카테고리명 / 기본 단위        | 셀을 더블클릭하여 직접 입력 |
| LOT 관리 / S/N 관리 / 선입선출 / 출고 검수 / 사용 여부 | 체크박스 클릭         |

수정한 뒤에는 반드시 **💾 저장**을 눌러야 반영됩니다.

{% hint style="warning" %}
카테고리의 기본 단위·LOT·S/N·선입선출 설정을 바꿔도 **이미 등록된 품목에는 적용되지 않습니다.** 이후 품목에서 해당 카테고리를 선택할 때부터 새 설정이 자동 입력됩니다.
{% endhint %}

***

### 5. 저장

저장하면 **신규/수정된 행**만 저장되고, 왼쪽 트리와 오른쪽 목록이 함께 새로고침됩니다. 품목 관리 화면의 카테고리 선택 목록에도 바로 반영됩니다.

> 저장 완료! (신규: N건, 수정: N건)

| 상황                    | 안내 메시지               |
| --------------------- | -------------------- |
| 변경 사항이 없음             | 변경된 데이터가 없습니다.       |
| 필수값(카테고리 코드/카테고리명) 누락 | 누락된 항목에 대한 안내 메시지    |
| 서버에서 거부 (예: 중복 코드)    | 서버가 알려주는 사유 표시       |
| 그 외 오류                | 저장 중 시스템 오류가 발생했습니다. |

{% hint style="danger" %}
저장하지 않은 상태에서 **트리에서 다른 카테고리를 선택**하면 입력한 내용이 사라집니다. 반드시 저장 후 이동하세요.
{% endhint %}

***

### 6. 카테고리 삭제 대신 "미사용" 처리

저장된 카테고리는 삭제할 수 없습니다. 더 이상 사용하지 않는 카테고리는 **사용 여부 체크를 해제**한 뒤 저장하세요.

***

### 7. 자주 묻는 질문 (FAQ)

**Q. 소분류 아래에 카테고리를 더 만들 수 없나요?** \
카테고리는 대/중/소 3단계까지만 구성할 수 있습니다.

**Q. 카테고리 기본값을 바꿨는데 기존 품목은 그대로예요.** \
기본값은 품목에서 카테고리를 **선택하는 시점**에만 적용됩니다. \
기존 품목은 품목 관리에서 직접 수정해 주세요.

**Q. 하위 카테고리를 추가했더니 단위·LOT 설정이 이미 들어가 있어요.** \
새 카테고리는 상위 카테고리의 설정을 물려받습니다. \
필요하면 수정한 뒤 저장해 주세요.

**Q. 방금 만든 카테고리가 품목 관리에서 안 보여요.** \
**저장**을 했는지 확인해 주세요. \
저장해야 품목 관리 화면에 반영됩니다.

**Q. 카테고리를 삭제하고 싶어요.** \
저장된 카테고리는 삭제되지 않습니다. \
**사용 여부를 해제**하여 미사용 처리해 주세요.
