# 재고수불부

재고가 **언제, 무엇 때문에, 얼마나 들어오고 나갔는지**를 거래 한 건마다 한 줄씩 보여주는 화면입니다. 입고, 출고, 기타입출고, 재고이동, 재고실사 등 재고를 움직인 모든 처리가 여기에 기록됩니다.

| 이런 경우에 사용합니다                       |
| ---------------------------------- |
| 특정 품목의 재고가 왜 지금 수량이 되었는지 흐름을 확인할 때 |
| 특정 로케이션에서 어떤 입출고가 있었는지 확인할 때       |
| 기간별 입고·출고 내역을 거래처, 단가, 금액과 함께 볼 때  |
| 기타입출고 사유별 내역을 확인할 때                |

화면에 들어오면 전체 내역이 자동으로 조회됩니다.

### 1. 조회 조건

조회 조건은 세 부분으로 되어 있습니다.

| 부분         | 내용                                                 |
| ---------- | -------------------------------------------------- |
| ① 기본 조건    | 구분, 바코드 스캔, 상세 필터 버튼, 조회 버튼 (항상 표시)                |
| ② 상세 필터    | 입고유형, 출고유형, 품목, 로케이션, 조회기간 (**상세 필터** 버튼으로 펼치기/접기) |
| ③ 적용 중인 조건 | 지금 걸려 있는 상세 조건 목록 (조건이 있을 때만 표시)                   |

조건을 정한 뒤 **🔍 조회**를 누르면 결과가 표시됩니다.

#### 1.1 구분

| 선택                                                   | 조회 대상       |
| ---------------------------------------------------- | ----------- |
| **전체**                                               | 입고와 출고 모두   |
| <mark style="background-color:blue;">**입고**</mark>   | 재고가 늘어난 거래만 |
| <mark style="background-color:orange;">**출고**</mark> | 재고가 줄어든 거래만 |

선택한 구분은 목록의 구분 표시와 같은 색(입고 파란색, 출고 주황색)으로 표시됩니다.

#### 1.2 바코드 스캔

구분 옆의 스캔 입력란에 품목이나 로케이션 바코드를 스캔하면 상세 필터의 조건이 자동으로 채워집니다. (모바일에서는 화면에 들어오자마자 바로 스캔할 수 있습니다.)

| 스캔한 바코드  | 채워지는 조건 | 안내 메시지        |
| -------- | ------- | ------------- |
| 품목 바코드   | 품목      | 품목 \[…] 적용됨   |
| 로케이션 바코드 | 로케이션    | 로케이션 \[…] 적용됨 |

| 이런 메시지가 나오면         | 의미                   |
| ------------------- | -------------------- |
| 해당 품목을 찾을 수 없습니다.   | 등록되지 않은 품목 바코드입니다.   |
| 해당 로케이션을 찾을 수 없습니다. | 등록되지 않은 로케이션 바코드입니다. |
| 인식할 수 없는 바코드입니다.    | 품목·로케이션 바코드가 아닙니다.   |

{% hint style="success" %}
**현장에서 바로 확인하기**: 랙 앞에서 로케이션 바코드를 스캔하고 조회하면 그 로케이션의 입출고 내역을 바로 볼 수 있습니다.
{% endhint %}

#### 1.3 상세 필터

**⚙ 상세 필터** 버튼을 누르면 상세 조건이 펼쳐지고, 다시 누르면 접힙니다. (PC에서는 처음부터 펼쳐져 있습니다.) 상세 조건이 걸려 있으면 버튼에 **조건 개수**가 파란 숫자로 표시되므로, 접어 두어도 필터가 적용 중인지 알 수 있습니다.

| 항목   | 설명                                                                            |
| ---- | ----------------------------------------------------------------------------- |
| 입고유형 | 입고 유형으로 걸러봅니다. 여러 개를 선택할 수 있습니다. 구분이 **출고**이면 _"출고 조회 중"_ 으로 표시되고 선택할 수 없습니다. |
| 출고유형 | 출고 유형으로 걸러봅니다. 여러 개를 선택할 수 있습니다. 구분이 **입고**이면 _"입고 조회 중"_ 으로 표시되고 선택할 수 없습니다. |
| 품목   | 특정 품목의 내역만 조회합니다.                                                             |
| 로케이션 | 특정 로케이션의 내역만 조회합니다.                                                           |
| 조회기간 | 기간을 정합니다. (아래 1.4 참고)                                                         |

#### 1.4 조회기간

빠른 선택 버튼으로 기간을 정하거나, 날짜를 직접 입력합니다.

| 선택        | 조회 기간            |
| --------- | ---------------- |
| **전체 기간** | 기간 제한 없음 (처음 상태) |
| **1주**    | 7일 전 \~ 오늘       |
| **1개월**   | 한 달 전 \~ 오늘      |
| **3개월**   | 세 달 전 \~ 오늘      |
| 날짜 직접 입력  | 입력한 시작일 \~ 종료일   |

* 날짜를 직접 고치면 기간 조건이 자동으로 적용되고, 빠른 선택 버튼은 선택이 해제됩니다.
* **전체 기간**일 때는 날짜 입력란이 흐리게 표시됩니다.
* 시작일은 종료일보다 늦게 고를 수 없습니다.

#### 1.5 적용 중인 조건

상세 조건이 하나라도 걸려 있으면 조회 조건 영역 아래에 **조건 목록**이 표시됩니다.

> (품목: 새우깡 ✕) (로케이션: A-1-3 ✕) (기간: 2026-09-08 \~ 2026-10-08 ✕) ↺ 초기화

| 동작          | 결과                              |
| ----------- | ------------------------------- |
| 조건 옆의 **✕** | 그 조건만 지웁니다.                     |
| **↺ 초기화**   | 구분을 **전체**로 바꾸고 모든 상세 조건을 지웁니다. |

### 2. 조회 결과

#### 2.1 목록 컬럼

| 컬럼    | 설명                                                                                       |
| ----- | ---------------------------------------------------------------------------------------- |
| 구분    | \<mark style="color:blue;">**입고**\</mark> 또는 \<mark style="color:orange;">**출고**\</mark> |
| 유형    | 입고유형 또는 출고유형                                                                             |
| 발생일   | **실제로 입고·출고가 일어난 날**                                                                     |
| 품목코드  | 품목 코드 (**코드 표시**를 눌러야 보임)                                                                |
| 품목명   | 품목 이름                                                                                    |
| 로케이션  | 로케이션 코드 (**코드 표시**를 눌러야 보임)                                                              |
| 로케이션명 | 거래가 일어난 로케이션                                                                             |
| 입고수량  | 들어온 수량                                                                                   |
| 출고수량  | 나간 수량                                                                                    |
| 재고수량  | 이 거래가 끝난 뒤의 재고 수량. 계산할 수 없으면 \<mark style="color:orange;">**마감필요**\</mark> (아래 2.3 참고)   |
| 문서번호  | 이 거래를 처리한 문서의 번호                                                                         |
| LOT   | 로트번호                                                                                     |
| 재고입고일 | 이 재고가 **처음 창고에 들어온 날** (아래 2.2 참고)                                                       |
| 거래처   | 입고처 또는 출고처                                                                               |
| 단가    | 거래 단가                                                                                    |
| 금액    | 거래 금액                                                                                    |
| 참조번호  | 관련 참조 번호                                                                                 |
| 기타사유  | 기타입출고로 처리한 경우의 사유                                                                        |
| 비고    | 기타입출고로 처리할 때 입력한 비고                                                                      |

* **발생일**과 **재고입고일** 머리글에 마우스를 올리면 설명이 표시됩니다.
* 목록 오른쪽 위의 **👁️ 코드 표시 / 코드 숨기기**로 품목코드·로케이션 컬럼을 보이거나 숨길 수 있습니다.
* 한 페이지에 **100건**씩 표시되며, 하단에서 바꿀 수 있습니다.

#### 2.2 발생일과 재고입고일

두 날짜는 의미가 다릅니다.

| 날짜        | 의미                             |
| --------- | ------------------------------ |
| **발생일**   | 이 거래가 **일어난 날**                |
| **재고입고일** | 이 거래로 움직인 재고가 **처음 창고에 들어온 날** |

```
9/1   입고       발생일 9/1    재고입고일 9/1
10/5  재고이동   발생일 10/5   재고입고일 9/1   ← 옮겨도 그대로
10/15 출고       발생일 10/15  재고입고일 9/1
```

재고입고일은 **선입선출 순서**의 기준입니다. 출고 내역의 재고입고일을 보면 오래된 재고부터 나갔는지 확인할 수 있습니다.

#### 2.3 재고수량과 "마감필요"

**재고수량**은 각 거래가 끝난 뒤 남은 수량입니다. 위에서부터 따라가면 재고가 어떻게 바뀌었는지 알 수 있습니다.

| 발생일   | 구분 | 입고수량 | 출고수량 | 재고수량 |
| ----- | -- | ---: | ---: | ---: |
| 10/01 | 입고 |  100 |      |  100 |
| 10/05 | 출고 |      |   30 |   70 |
| 10/12 | 입고 |   50 |      |  120 |
| 10/20 | 출고 |      |   45 |   75 |

재고수량을 계산할 수 없는 줄에는 숫자 대신 <mark style="color:orange;">**마감필요**</mark>가 표시됩니다. **마우스를 올리면 이유**가 나타납니다.

{% hint style="info" %}
**마감필요**가 보이면 재고마감을 진행해 주세요.&#x20;
{% endhint %}

{% hint style="success" %}
&#x20;재고수량을 따라가며 보려면 **품목**을 지정해서 조회하세요. 여러 품목이 섞여 있으면 흐름을 읽기 어렵습니다.
{% endhint %}

### 3. 활용 예시

**재고가 맞지 않을 때 원인 찾기**

1. 품목 바코드를 스캔하거나 상세 필터에서 **품목**을 선택합니다.
2. **조회기간**의 시작일을 마지막으로 재고가 맞았던 날로 입력합니다.
3. **조회**를 누릅니다.
4. 입고수량·출고수량·재고수량을 따라가며 이상한 거래를 찾습니다.
5. 찾은 줄의 **문서번호**로 해당 문서를 열어 내용을 확인합니다.

**특정 로케이션의 입출고 내역 보기**

1. 로케이션 바코드를 스캔하거나 상세 필터에서 **로케이션**을 선택합니다.
2. **조회**를 누릅니다.

**이번 달 기타입출고 내역 보기**

1. 상세 필터의 **입고유형 / 출고유형**에서 기타입출고 유형을 선택합니다.
2. **조회기간**에 이번 달 1일 \~ 오늘을 입력합니다.
3. **조회**를 누르고 **기타사유**, **비고** 컬럼을 확인합니다.

### 4. 자주 묻는 질문 (FAQ)

**Q. 바코드를 스캔했는데 목록이 바뀌지 않아요.** \
스캔은 조건만 채웁니다. **조회**를 눌러 주세요.

**Q. 재고수량에 "마감필요"라고 나와요.** \
마우스를 올려 이유를 확인하고, 재고마감에서 이전 달을 마감해 주세요.

**Q. 입고유형이 "출고 조회 중"으로 나오고 선택되지 않아요.** \
구분이 **출고**로 되어 있습니다. \
**전체**나 **입고**로 바꾸면 선택할 수 있습니다.

**Q. 구분을 바꿨더니 골라둔 유형이 사라졌어요.** \
정상입니다. **입고**로 바꾸면 출고유형이, **출고**로 바꾸면 입고유형이 함께 쓸 수 없어서 자동으로 지워집니다.

**Q. 품목(또는 로케이션) 조건을 빼고 싶어요.** \
조회 조건 아래의 조건 목록에서 해당 조건 옆 X를 누르고 **조회**하세요. \
모든 조건을 지우려면 **↺ 초기화**를 누르세요.

**Q. 상세 필터를 접어 놨는데 결과가 적게 나와요.** **상세 필터** \
버튼에 숫자가 있다면 조건이 걸려 있는 상태입니다. \
아래 조건 목록에서 확인하고 필요 없는 조건을 지워 주세요.

**Q. 품목코드 컬럼이 안 보여요.** \
목록 오른쪽 위의 **코드 표시**를 누르세요.

**Q. 발생일과 재고입고일이 달라요.** \
정상입니다. 발생일은 거래가 일어난 날, 재고입고일은 그 재고가 처음 들어온 날입니다. (위 2.2 참고)

**Q. SN별 이력을 보고 싶어요.** \
[sn-history.md](sn-history.md "mention")에서 SN번호로 조회할 수 있습니다.

**Q. 지금 재고가 얼마인지만 빨리 보고 싶어요.** \
[stock.md](stock.md "mention")에서 품목·로케이션별 현재 수량을 볼 수 있습니다.
