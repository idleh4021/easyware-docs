# 재고마감

월별로 **재고를 마감**하고, 마감 시점의 재고를 **스냅샷(기록)으로 남기는** 화면입니다. 마감한 달의 재고는 그대로 보관되어, 나중에 "그 달 말에 재고가 얼마였는지" 확인할 수 있습니다.

| 마감하면         | 설명                             |
| ------------ | ------------------------------ |
| 📸 재고 스냅샷 저장 | 창고의 품목·로케이션·로트·입고일별 수량이 기록됩니다. |
| 🔒 입출고 잠금    | 마감한 달에는 입출고 처리를 할 수 없습니다.      |

<figure><img src="../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>

***

### 1. 화면 구성

| 영역       | 설명                                             |
| -------- | ---------------------------------------------- |
| ① 조회 조건  | 창고를 선택하고 조회합니다.                                |
| ② 마감 이력  | 지금까지 마감한 목록입니다. 오른쪽 위 **마감 처리** 버튼으로 새로 마감합니다. |
| ③ 마감 스냅샷 | 마감 이력에서 **마감월**을 클릭하면 아래에 그 달의 재고 스냅샷이 표시됩니다.  |

{% hint style="info" %}
마감 이력과 마감 스냅샷 목록은 **아래쪽 가장자리를 끌어서** 높이를 조절할 수 있습니다.
{% endhint %}

#### 1.1 조회 조건

| 항목    | 설명                                               |
| ----- | ------------------------------------------------ |
| 창고    | 조회할 창고를 선택합니다. 창고를 바꾸면 바로 다시 조회됩니다. (기본값: 전체 창고) |
| 🔍 조회 | 마감 이력을 다시 불러옵니다.                                 |

#### 1.2 마감 이력

| 컬럼      | 설명                              |
| ------- | ------------------------------- |
| 마감월     | 마감한 달. **클릭하면 아래에 스냅샷**이 표시됩니다. |
| 창고      | 마감한 창고                          |
| 마감일시    | 마감을 실행한 일시                      |
| 스냅샷 건수  | 저장된 재고 기록 건수                    |
| (취소 버튼) | 마감을 취소합니다. (아래 4. 참고)           |

***

### 2. 마감 처리

1. 마감 이력 오른쪽 위의 **마감 처리**를 클릭합니다.
2. **창고**를 선택합니다.
3. **마감월**(연도, 월)을 선택합니다.
4. **마감 실행**을 클릭합니다.

<figure><img src="../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>

| 항목  | 설명                                       |
| --- | ---------------------------------------- |
| 창고  | 마감할 창고. **창고별로** 마감합니다.                  |
| 마감월 | 마감할 연도와 월. 기본값은 **지난달**입니다. (최근 3년 중 선택) |

완료되면 _"마감 처리되었습니다."_ 메시지가 표시되고 마감 이력에 추가됩니다. 이미 마감한 달이거나 마감할 수 없는 경우에는 그 사유가 표시됩니다.

{% hint style="danger" %}
**이번 달을 선택하면** 아래 경고가 표시됩니다.

> 당월 마감입니다. 마감 처리되면 이번 달은 입출고 처리가 불가능해요.

이번 달을 마감하면 **남은 기간 동안 그 창고의 입고·출고·기타입출고·재고이동 등을 처리할 수 없습니다.** 특별한 이유가 없다면 이번 달은 마감하지 마세요.
{% endhint %}

#### 2.1 언제 마감하나요?

{% hint style="success" %}
**권장: 매달 초에 지난달을 마감합니다.**

예) 11월 1일 \~ 5일 사이에 **10월**을 마감

입출고 문서는 항상 **오늘 날짜**로 등록되므로, 지난달을 마감해도 이번 달 업무에는 영향이 없습니다.
{% endhint %}

마감 전에 재고실사로 실제 재고와 시스템 재고를 맞춰두면, 정확한 재고가 스냅샷으로 남습니다.

```
월말 재고실사  →  익월 초 전월 마감  →  스냅샷 확인
```

***

### 3. 마감 스냅샷 보기

마감 이력에서 **마감월**을 클릭하면 아래에 스냅샷이 펼쳐집니다.

> 2026-09 마감 스냅샷 — 본사 물류센터

| 컬럼    | 설명                          |
| ----- | --------------------------- |
| 품목코드  | 품목 코드. **클릭하면 상세**가 열립니다.   |
| 품목명   | 품목 이름                       |
| 로케이션  | 로케이션 코드. **클릭하면 상세**가 열립니다. |
| 로케이션명 | 로케이션 이름                     |
| 수량    | 마감 시점의 수량 (품목·로케이션별 합계)     |

스냅샷 제목을 클릭하면 목록을 **접거나 펼칠** 수 있습니다.

#### 3.1 스냅샷 상세

스냅샷에서 **품목코드** 또는 **로케이션**을 클릭하면, 그 품목·로케이션의 수량을 **로트번호와 입고일별로** 나눠서 보여줍니다.

<figure><img src="../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>

| 컬럼   | 설명               |
| ---- | ---------------- |
| 로트번호 | 로트번호 (LOT 관리 품목) |
| 입고일자 | 재고의 입고일          |
| 수량   | 해당 로트·입고일의 수량    |

***

### 4. 마감 취소

마감을 잘못했거나, 마감한 달의 재고를 다시 처리해야 할 때는 마감을 취소할 수 있습니다.

1. 마감 이력에서 취소할 마감의 **취소** 버튼을 클릭합니다.
2. 확인 창에서 **확인**을 클릭합니다.

> (마감월) 마감을 취소하시겠습니까?

완료되면 _"마감이 취소되었습니다."_ 메시지가 표시되고 마감 이력에서 사라집니다. 취소할 수 없는 경우에는 그 사유가 표시됩니다.

{% hint style="warning" %}
마감을 취소하면 그 달의 **스냅샷도 함께 삭제**됩니다. 다시 마감하면 **그 시점의 재고**로 새 스냅샷이 만들어집니다.&#x20;
{% endhint %}

***

### 5. 자주 묻는 질문 (FAQ)

**Q. 입고를 하려는데 마감되었다고 나와요.** \
이번 달이 마감된 상태입니다. \
관리자에게 이번 달 마감 취소를 요청해 주세요.

**Q. 지난달을 마감하면 이번 달 업무에 영향이 있나요?** \
없습니다. 입출고 문서는 항상 오늘 날짜로 등록되므로, 지난달 마감과 관계없이 업무를 계속할 수 있습니다.

**Q. 전체 창고를 한 번에 마감할 수 있나요?** \
아니요. 마감은 **창고별로** 처리합니다. \
창고마다 마감 처리를 해 주세요.

**Q. 스냅샷 수량과 지금 재고가 달라요.** \
스냅샷은 **마감한 시점**의 재고입니다. \
그 이후의 입출고는 반영되지 않습니다.

**Q. 스냅샷 수량을 로트별로 보고 싶어요.** \
스냅샷 목록에서 **품목코드**나 **로케이션**을 클릭하면 로트번호·입고일별 수량을 볼 수 있습니다.

**Q. 마감을 다시 하고 싶어요.** \
해당 마감을 **취소**한 뒤 다시 **마감 처리**하세요. 스냅샷은 다시 마감한 시점의 재고로 새로 만들어집니다.
