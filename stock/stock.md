# 재고현황

현재 창고에 있는 **재고를 품목별, 로케이션별로 조회**하는 화면입니다.

### 1. 재고현황 목록

#### 1.1 조회 조건

| 항목    | 설명                          |
| ----- | --------------------------- |
| 창고    | 조회할 창고를 선택합니다. (기본값: 전체 창고) |
| 품목    | 특정 품목만 조회할 때 선택합니다.         |
| 🔍 조회 | 조건에 맞는 재고를 조회합니다.           |

화면에 들어오면 전체 재고가 자동으로 조회되며, **품목코드 순서**로 표시됩니다.

#### 1.2 목록 컬럼

| 컬럼     | 설명                                       |
| ------ | ---------------------------------------- |
| 창고     | 재고가 있는 창고                                |
| 로케이션코드 | 재고가 있는 로케이션. **클릭하면 재고 상세**가 열립니다. |
| 로케이션명  | 로케이션 이름                                  |
| 품목코드   | 품목 코드. **클릭하면 재고 상세**가 열립니다.         |
| 품목명    | 품목 이름                                    |
| 재고수량   | 해당 로케이션에 있는 품목의 수량                       |
| 단위     | 수량 단위                                    |

{% hint style="info" %}
목록은 **품목 + 로케이션** 단위로 수량을 합쳐서 보여줍니다. 같은 로케이션에 로트번호나 입고일이 다른 재고가 있어도 한 줄로 표시되며, 나눠진 내역은 **재고 상세**에서 확인할 수 있습니다.&#x20;
{% endhint %}

#### 1.3 재고 상세 열기

목록에서 **품목코드** 또는 **로케이션코드**를 클릭하면 **재고 상세** 창이 열립니다. 처음에는 클릭한 줄의 **품목과 로케이션**이 조건으로 채워져, 그 위치의 재고가 로트번호·입고일별로 표시됩니다.

#### 1.4 모바일 화면

모바일에서는 목록 대신 **카드** 형태로 표시됩니다.

* 카드의 **품목** 또는 **로케이션**을 누르면 재고 상세 창이 열립니다.
* 카드 아래의 **이전 / 다음** 버튼으로 페이지를 넘깁니다.

### 2. 재고 상세

품목·로케이션·로트번호 조건으로 재고를 **로케이션·로트번호·입고일별로** 나눠서 보여주는 창입니다. [퀵스캔](../getting-started/quick-scan.md)으로 바코드를 스캔했을 때도 이 창이 열립니다.

> 📷 **[이미지]** '재고 상세' 창 (위쪽 품목·로케이션·로트번호 조건과 초기화·조회 버튼, 총 재고수량, '같은 품목 강조' 스위치, 아래 재고 목록과 오른쪽 위 바코드 출력 버튼이 보이도록)

<figure><img src="../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

#### 2.1 조회 조건

| 항목    | 설명                                                          |
| ----- | ----------------------------------------------------------- |
| 품목    | 볼 품목. 지우거나 다른 품목을 고르면 **바로 다시 조회**됩니다.                       |
| 로케이션  | 볼 로케이션. 지우거나 다른 로케이션을 고르면 **바로 다시 조회**됩니다.                   |
| 로트번호  | 로트번호로 걸러봅니다. **일부만 입력해도** 검색됩니다. `Enter` 또는 **조회**            |
| 초기화   | 창을 열었을 때 조건으로 되돌립니다. (로트번호는 비움)                              |

조건을 바꿔서 보는 범위를 넓히거나 좁힐 수 있습니다.

| 조건             | 보여주는 내용                                     |
| -------------- | ------------------------------------------- |
| 품목 + 로케이션      | 그 로케이션에 있는 그 품목의 재고                         |
| **품목만**        | 그 품목이 **어느 로케이션에** 얼마나 있는지 (창고와 관계없이 모든 로케이션) |
| **로케이션만**      | 그 로케이션에 **어떤 품목이** 얼마나 있는지                   |
| 둘 다 비움         | 조회하지 않습니다. _"품목 또는 로케이션을 선택하면 조회합니다."_         |

{% hint style="success" %}
**한 품목이 창고 어디에 있는지** 보려면 로케이션 조건을 지우세요. **한 로케이션에 무엇이 있는지** 보려면 품목 조건을 지우세요.
{% endhint %}

#### 2.2 요약

목록 위에 **총 재고수량**과 재고 건수가 표시됩니다.

> 총 재고수량 **1,250** (8건)

#### 2.3 같은 품목 / 같은 로케이션 강조

품목만 또는 로케이션만 조건으로 볼 때 **같은 로케이션 강조** 또는 **같은 품목 강조** 스위치가 표시됩니다. 켜면 마우스를 올린 줄과 **같은 코드의 줄을 함께 강조**해서, 같은 위치·같은 품목의 재고를 한눈에 찾을 수 있습니다.

#### 2.4 목록 컬럼

| 컬럼             | 설명                                            |
| -------------- | --------------------------------------------- |
| ☑ (선택)         | 바코드 출력 대상 선택. 머리글의 체크박스로 전체 선택/해제             |
| 로케이션코드 / 로케이션명 | 재고가 있는 로케이션 (로케이션 조건이 있으면 숨김)                 |
| 품목코드 / 품목명     | 재고 품목 (품목 조건이 있으면 숨김)                         |
| 로트번호           | 로트번호 (LOT 관리 품목)                              |
| 입고일자           | 재고의 입고일                                       |
| 재고수량           | 현재 수량                                         |
| SN             | SN 관리 품목이면 버튼이 표시됩니다. 누르면 보유 SN 목록을 볼 수 있습니다. |

<figure><img src="../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
**로케이션 정리할 때 유용합니다.** 랙 앞에서 로케이션만 조건으로 재고 상세를 열어 두고 실제 물건과 비교하면, 위치가 잘못된 물건을 빠르게 찾을 수 있습니다. 차이가 있다면 재고실사나 재고이동으로 바로잡으세요.
{% endhint %}

### 3. 품목 바코드 출력

재고 상세 창에서 물건에 붙일 **품목 라벨**을 출력할 수 있습니다.

1. 재고 상세 창을 엽니다.
2. 출력할 재고의 **☑ 체크박스**를 선택합니다.
3. 오른쪽 위의 **🖨️ 바코드 출력**을 클릭합니다.
4. **품목 라벨 출력** 창에서 라벨 형식과 **라벨 1건당 매수**를 정하고 **출력**을 누릅니다.

> 📷 **[이미지]** '품목 라벨 출력' 창 (라벨 100×50 / 50×25 / 30×30 형식 선택과 '라벨 1건당 매수' 입력란이 보이도록)

| 라벨 형식      | 내용                       |
| ---------- | ------------------------ |
| 라벨 100×50  | 품목코드, 품목명, 규격, LOT·SN·입고일 |
| 라벨 50×25   | 품목코드, 품목명, 핵심 정보 1개      |
| 라벨 30×30   | QR과 품목명                  |

| 품목           | 출력되는 라벨                                            |
| ------------ | -------------------------------------------------- |
| 일반 품목        | 선택한 재고(품목·로트·입고일)의 라벨                             |
| **SN 관리 품목** | 그 재고가 보유한 **SN마다 1장씩** 전부 출력 (일부만 출력하려면 아래 3.1 참고) |

{% hint style="warning" %}
SN 관리 재고를 선택하면 _"SN 관리 재고 N건은 보유 SN N건 전체가 출력됩니다."_ 메시지가 표시됩니다. SN이 많은 재고는 출력량이 많아지니 확인하고 진행하세요.
{% endhint %}

선택한 재고가 없으면 _"출력할 재고을 선택해주세요."_ 메시지가 표시됩니다. 한 번에 최대 100건까지 선택할 수 있습니다.

#### 3.1 SN 골라서 출력하기

SN 관리 품목에서 **필요한 SN만** 출력하려면 SN 조회 창을 사용하세요.

1. 재고 상세 창에서 해당 재고의 **SN** 버튼을 클릭합니다.
2. **SN 조회** 창에서 출력할 SN의 **☑ 체크박스**를 선택합니다.
3. **🖨️ 선택 SN 바코드 출력**을 클릭하고, **SN 라벨 출력** 창에서 형식을 고릅니다.

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

| 항목               | 설명                                   |
| ---------------- | ------------------------------------ |
| 창 제목             | 품목명과 함께 **로케이션 / LOT / 입고일**이 표시됩니다. |
| SN 목록            | 해당 재고가 **현재 보유한** SN 목록              |
| ☑ (선택)           | 출력할 SN 선택. 머리글의 체크박스로 전체 선택/해제       |
| 총 N건             | 보유 SN 개수                             |
| 🖨️ 선택 SN 바코드 출력 | 선택한 SN만 라벨을 출력합니다.                   |

선택한 SN이 없으면 _"바코드를 출력할 SN을 선택해주세요."_ 메시지가 표시됩니다. 한 번에 최대 500건까지 출력할 수 있습니다.

{% hint style="success" %}
**라벨이 훼손된 제품 1개만 다시 붙여야 할 때** 유용합니다. 재고 상세에서 바로 출력하면 보유 SN 전체가 출력되니, SN 조회 창에서 해당 SN만 골라 출력하세요.
{% endhint %}

### 4. 자주 묻는 질문 (FAQ)

**Q. 재고 상세에 다른 창고 로케이션도 보여요.** \
품목만 조건으로 보면 창고와 관계없이 그 품목의 **모든 재고**를 보여줍니다. \
로케이션명으로 창고를 구분해 주세요.

**Q. 재고현황 목록에서는 한 줄인데, 상세에서는 여러 줄이에요.** \
목록은 품목+로케이션별로 수량을 합쳐서 보여주고, 상세는 **로트번호·입고일별로** 나눠서 보여줍니다.

**Q. 같은 품목, 같은 로케이션인데 상세에서 왜 줄이 여러 개인가요?** \
재고는 **품목·로케이션·로트번호·입고일**이 모두 같아야 한 줄로 묶입니다. \
로트번호나 입고일이 다르면 따로 표시됩니다.

**Q. 로트번호를 정확히 몰라요.** \
로트번호는 **일부만 입력해도** 검색됩니다. \
예를 들어 `2401`만 입력하면 `LOT-2401-A`, `LOT-2401-B`가 모두 조회됩니다.

**Q. SN 관리 품목이 어떤 SN을 가지고 있는지 보고 싶어요.** \
재고 상세 창의 **SN** 버튼을 누르세요. \
SN별 이력은 SN수불에서 확인할 수 있습니다.

**Q. SN 품목 바코드를 하나만 출력하고 싶어요.** \
재고 상세에서 바로 출력하면 보유 SN 전체가 출력됩니다. \
**SN** 버튼으로 SN 조회 창을 열고 필요한 SN만 골라 **선택 SN 바코드 출력**을 누르세요. (위 3.1 참고)

**Q. 한 품목이 창고 어디에 있는지 한 번에 보고 싶어요.** \
재고 상세 창에서 **로케이션 조건을 지우면** 그 품목이 있는 모든 로케이션이 표시됩니다. **같은 로케이션 강조**를 켜면 위치별로 구분하기 쉽습니다.
