# 기타입출고

일반적인 입고·출고 업무가 아닌 이유로 **재고를 늘리거나 줄일 때** 사용하는 화면입니다.

| 이런 경우에 사용합니다              | 구분 |
| ------------------------- | -- |
| 실사 결과 재고가 장부보다 많을 때       | 입고 |
| 파손, 분실, 폐기로 재고를 빼야 할 때    | 출고 |
| 샘플 지급, 사내 사용 등으로 물건이 나갈 때 | 출고 |
| 시스템 도입 시 기초 재고를 등록할 때     | 입고 |

{% hint style="warning" %}
기타입출고는 저장하는 즉시 **재고에 반영**되며, 저장한 뒤에는 **수정하거나 삭제할 수 없습니다.** 잘못 등록했다면 반대 구분(입고 ↔ 출고)으로 다시 등록해서 바로잡아 주세요.
{% endhint %}

### 1. 재고를 구분하는 기준

이 화면을 이해하려면 먼저 시스템이 재고를 어떻게 구분하는지 알아두면 좋습니다. 재고는 아래 네 가지가 **모두 같아야** 같은 재고로 봅니다.

| 기준   | 예시                    |
| ---- | --------------------- |
| 품목   | 새우깡                   |
| 로케이션 | A-1-3                 |
| 로트번호 | LOT-2401 (LOT 관리 품목만) |
| 입고일  | 2026-10-01            |

예를 들어 같은 새우깡이 같은 A-1-3에 있어도 **입고일이 다르면 다른 재고**입니다. 그래서 **출고**할 때는 정확히 어떤 재고에서 뺄지 고르는 것이 중요합니다. (아래 3.4 재고선택 참고)

***

### 2. 기타입출고 목록

#### 2.1 조회 조건

| 항목      | 설명                                           |
| ------- | -------------------------------------------- |
| 창고      | 조회할 창고를 선택합니다. (기본값: 전체 창고)                  |
| 조회기간 설정 | 체크하면 기간 입력란이 나타납니다. 체크하지 않으면 기간 제한 없이 조회합니다. |
| 🔍 조회   | 조건에 맞는 기타입출고를 조회합니다.                         |

#### 2.2 목록 컬럼

| 컬럼      | 설명                           |
| ------- | ---------------------------- |
| 기타입출고번호 | 문서 번호. **클릭하면 상세 화면**이 열립니다. |
| 일자      | 기타입출고 일자                     |
| 창고      | 처리한 창고                       |
| 제목      | 문서 제목                        |
| 비고      | 등록할 때 입력한 메모                 |
| 등록일시    | 문서를 등록한 일시                   |

목록은 **일자가 최신인 순서**로 표시됩니다.

### 3. 기타입출고 등록

목록 오른쪽 위의 **➕ 신규**를 누르면 등록 화면이 열립니다.

<figure><img src="../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

#### 3.1 등록 순서

1. **창고**를 선택합니다.
2. 라인(처리할 품목)을 추가합니다. 추가 방법은 세 가지입니다.
   * **바코드 스캔** (아래 3.3 참고)
   * **라인 수동추가** 후 품목·로케이션 입력 (아래 3.2 참고)
   * 라인의 **재고선택** 버튼으로 기존 재고 선택 (아래 3.4 참고)
3. 라인마다 **구분(입고/출고), 수량, 사유**를 입력합니다.
4. 💾 **저장**을 클릭합니다.

**상단 입력 항목**

| 항목      |  필수 | 설명                                                 |
| ------- | :-: | -------------------------------------------------- |
| 창고      |  ✅  | 처리할 창고. 선택하지 않고 로케이션을 입력하면 **로케이션의 창고로 자동 설정**됩니다. |
| 기타입출고일자 |     | **오늘 날짜**로 고정되며 변경할 수 없습니다.                        |
| 비고      |     | 문서 전체에 대한 메모                                       |

**라인 컬럼**

| 컬럼      |  필수 | 설명                                          |
| ------- | :-: | ------------------------------------------- |
| 품목코드    |     | 품목을 선택하면 자동 입력                              |
| 품목명     |  ✅  | 클릭해서 품목을 검색·선택                              |
| 로케이션코드  |     | 로케이션을 선택하면 자동 입력                            |
| 로케이션    |  ✅  | 클릭해서 로케이션을 검색·선택                            |
| 📦 재고선택 |     | 기존 재고를 골라 품목·로케이션·로트·입고일을 한 번에 채움           |
| SN      |     | SN 관리 품목에만 표시 (아래 3.5 참고)                   |
| 로트번호    | 조건부 | **LOT 관리 품목만** 입력 가능하며, 이때는 필수              |
| 입고일     |  ✅  | 재고의 입고일 (`YYYY-MM-DD`). 새 라인은 오늘 날짜로 채워집니다. |
| 현재고(참고) |     | 품목·로케이션·로트·입고일이 같은 재고의 현재 수량                |
| 구분      |  ✅  | **입고**(파란색) 또는 **출고**(빨간색)                  |
| 수량      |  ✅  | 처리할 수량 (SN 관리 품목은 SN 개수로 자동 입력)             |
| 사유      |  ✅  | 기타입출고 사유                                    |
| 비고      | 조건부 | 사유가 **기타**이면 필수 (입력 전까지 분홍색으로 표시)           |
| 삭제      |     | 라인 삭제                                       |

#### 3.2 라인 수동추가

1. **➕ 라인 수동추가**를 클릭합니다. 새 라인이 추가되고 품목명 칸이 입력 상태가 됩니다.
2. **품목명**을 검색해서 선택합니다.
3. **로케이션**을 검색해서 선택합니다.
4. LOT 관리 품목이라면 **로트번호**를 입력합니다.
5. 필요하면 **입고일**을 수정합니다.
6. **구분, 수량, 사유**를 입력합니다.

품목·로케이션·로트번호·입고일을 입력하면 **현재고(참고)** 가 자동으로 표시됩니다. 일치하는 재고가 없으면 `0`으로 표시됩니다.

{% hint style="warning" %}
**출고**할 때 현재고가 `0`이라면 로트번호나 입고일이 실제 재고와 다를 수 있습니다. 정확한 재고를 고르려면 **재고선택**을 사용하세요.
{% endhint %}

#### 3.3 바코드 스캔

**바코드 스캔 (품목 또는 로케이션)** 을 눌러 스캔 영역을 펼칩니다.

<figure><img src="../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>

1. **스캔 시 구분**에서 **입고** 또는 **출고**를 선택합니다. (기본값: 출고)
2. **품목 바코드**와 **로케이션 바코드**를 스캔합니다. 순서는 상관없습니다.
3. 두 바코드가 모두 스캔되면 라인이 자동으로 추가됩니다.
4. 추가된 라인에 **수량**과 **사유**를 입력합니다.

**스캔 결과에 따른 동작**

| 상황                     | 동작                                |
| ---------------------- | --------------------------------- |
| 해당 위치에 일치하는 재고가 하나     | 로트·입고일·현재고가 채워진 라인이 추가됩니다.        |
| 일치하는 재고가 여러 개          | **재고 선택 창**이 열립니다. 처리할 재고를 고르세요.  |
| 일치하는 재고가 없음            | 🆕 **신규 조합**으로 라인이 추가됩니다. (입고할 때) |
| LOT 관리 품목인데 로트를 알 수 없음 | _"로트번호가 포함된 바코드를 다시 스캔해주세요."_     |

**로케이션 고정 🔒**

같은 로케이션에서 여러 품목을 처리할 때는 로케이션 칸 오른쪽의 🔒 버튼을 누르세요. 로케이션이 고정되어 **품목 바코드만 연달아 스캔**하면 됩니다. 다시 누르면 고정이 풀립니다.

**스캔 초기화 ⓧ**

잘못 스캔했다면 스캔 입력란 옆의 ⓧ 버튼으로 스캔한 품목·로케이션을 비울 수 있습니다.

{% hint style="info" %}
* 스캔으로 추가한 라인도 **사유**는 직접 선택해야 합니다.
* 재고 선택 창이 열려 있는 동안에는 다음 바코드를 스캔할 수 없습니다. 먼저 재고를 선택하거나 창을 닫아 주세요.&#x20;
{% endhint %}

#### 3.4 재고선택

라인의 **📦 재고선택** 버튼을 누르면 재고 목록에서 처리할 재고를 직접 고를 수 있습니다. 선택한 재고의 **품목, 로케이션, 로트번호, 입고일, 현재고**가 라인에 한 번에 채워집니다.

{% hint style="success" %}
**출고할 때 가장 정확한 방법**입니다. 실제로 있는 재고 중에서 고르기 때문에 로트번호나 입고일을 잘못 입력할 일이 없습니다.
{% endhint %}

#### 3.5 SN 관리 품목

SN(시리얼 번호) 관리 품목은 수량을 직접 입력하지 않고 **SN을 등록**합니다. 등록한 SN 개수가 수량이 됩니다.

| 구분 | 버튼           | 하는 일                          |
| -- | ------------ | ----------------------------- |
| 입고 | **SN등록 (N)** | 새로 들어오는 제품의 SN을 입력합니다.        |
| 출고 | **SN찾기 (N)** | 해당 재고에 있는 SN 중에서 나갈 제품을 고릅니다. |

{% hint style="warning" %}
* SN 버튼은 **구분(입고/출고)을 먼저 선택**해야 사용할 수 있습니다.
* **출고**는 **재고선택**이나 **바코드 스캔**으로 정확한 재고를 먼저 지정해야 **SN찾기**를 사용할 수 있습니다.
* 재고가 없는 위치에서는 SN 관리 품목을 출고할 수 없습니다.
* 같은 SN을 여러 라인에 중복으로 등록할 수 없습니다.
{% endhint %}

**SN이 초기화되는 경우**

아래 항목을 바꾸면 이전에 등록한 SN이 맞지 않게 되므로 **SN과 수량이 비워집니다.** SN을 다시 등록해 주세요.

* 품목 또는 로케이션 변경
* 구분(입고 ↔ 출고) 변경
* 재고선택으로 다른 재고 선택

{% hint style="info" %}
품목 바코드에 SN이 포함되어 있으면, **출고** 스캔 시 해당 SN이 자동으로 등록됩니다. 재고에서 확인되지 않는 SN은 무시되니 **SN찾기**로 추가해 주세요.&#x20;
{% endhint %}

#### 3.6 사유

사유는 **공통코드**에서 관리하는 기타입출고 사유 목록에서 선택합니다. 사유가 **기타**인 경우에는 **비고를 반드시 입력**해야 합니다.

{% hint style="info" %}
사유 목록을 추가하거나 바꾸려면 관리자에게 요청하세요. 관리자는 공통코드 관리의 기타입출고 사유 그룹에서 변경할 수 있습니다.
{% endhint %}

#### 3.7 저장

**💾 저장**을 누르면 입력 내용을 확인한 뒤 저장합니다. 저장되면 문서 번호와 함께 완료 메시지가 표시됩니다.

> 기타입출고 \[문서번호] 저장 완료 (N건)

**저장 전 확인 항목**

| 상황                | 안내 메시지                                                 |
| ----------------- | ------------------------------------------------------ |
| 창고 미선택            | 창고를 선택해주세요.                                            |
| 라인 없음             | 라인을 1건 이상 추가해주세요.                                      |
| 품목 누락             | 품목이 입력되지 않은 라인이 있습니다.                                  |
| 로케이션 누락           | 로케이션이 입력되지 않은 라인이 있습니다.                                |
| 입고일 누락            | 입고일이 입력되지 않은 라인이 있습니다.                                 |
| 입고일 형식 오류         | 입고일 형식이 올바르지 않습니다 (YYYY-MM-DD): (품목코드)                 |
| 구분 미선택            | 입고/출고 구분이 선택되지 않은 라인이 있습니다.                            |
| 수량이 0 이하          | 수량은 0보다 커야 합니다.                                        |
| 사유 미선택            | 사유가 선택되지 않은 라인이 있습니다.                                  |
| 사유 '기타'인데 비고 없음   | 사유가 '기타'인 경우 비고를 입력해야 합니다: (품목코드)                      |
| SN 미등록            | SN 관리 품목입니다. SN을 등록해주세요: (품목코드)                        |
| SN 품목 출고인데 재고 미지정 | SN 관리 품목은 재고를 찾아서 출고해야 합니다(재고선택/스캔으로 다시 채워주세요): (품목코드) |
| SN 개수와 수량 불일치     | SN 개수와 수량이 일치하지 않습니다: (품목코드)                           |
| SN 중복             | SN이 중복되었습니다: (SN)                                      |

LOT 관리 품목에 로트번호가 없을 때도 안내 메시지가 표시됩니다. 서버에서 저장이 거부되면 그 사유가 표시됩니다.

{% hint style="danger" %}
* 저장하지 않고 **닫기**를 누르면 입력한 라인이 모두 사라집니다.
* 저장한 뒤에는 **수정하거나 삭제할 수 없습니다.** 저장 전에 구분과 수량을 꼭 확인하세요.
{% endhint %}

### 5. 자주 묻는 질문 (FAQ)

**Q. 잘못 등록했어요. 수정이나 삭제가 안 돼요.** \
기타입출고는 저장 즉시 재고에 반영되어 수정·삭제할 수 없습니다. \
**반대 구분으로 다시 등록**해서 바로잡아 주세요. \
(예: 10개를 잘못 출고했다면 같은 재고로 10개 입고)

**Q. 날짜를 어제로 바꿀 수 없나요?** \
기타입출고일자는 오늘 날짜로 고정됩니다.

**Q. 출고하려는데 현재고(참고)가 0으로 나와요.** \
품목·로케이션은 같아도 로트번호나 입고일이 실제 재고와 다를 수 있습니다. \
**📦 재고선택**으로 실제 재고를 골라 주세요.

**Q. 바코드를 스캔했는데 재고 선택 창이 떠요.** \
같은 위치에 같은 품목의 재고가 여러 개(로트번호나 입고일이 다름) 있다는 뜻입니다. \
처리할 재고를 골라 주세요.

**Q. 바코드 스캔 후 "신규 조합으로 추가됨"이라고 나와요.** \
그 위치에 해당 재고가 없다는 뜻입니다. \
입고라면 그대로 진행하면 되고, 출고라면 품목이나 로케이션을 잘못 스캔한 것은 아닌지 확인해 주세요.

**Q. SN찾기 버튼이 눌리지 않아요.** \
출고할 재고가 지정되지 않은 상태입니다. \
**재고선택**이나 **바코드 스캔**으로 재고를 먼저 지정해 주세요.

**Q. 등록해 둔 SN이 사라졌어요.** \
품목, 로케이션, 구분을 바꾸거나 재고를 다시 선택하면 SN이 초기화됩니다. \
SN을 다시 등록해 주세요.

**Q. 사유 목록에 원하는 사유가 없어요.** \
관리자에게 사유 추가를 요청하거나, **기타**를 선택하고 비고에 내용을 적어 주세요.
