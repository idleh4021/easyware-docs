# SN관리

창고에 **현재 보유 중인 SN(시리얼 번호)** 목록을 조회하고, 잘못 등록된 SN번호를 **변경**하는 화면입니다.

| 화면              | 보여주는 내용                                |
| --------------- | -------------------------------------- |
| **SN관리** (이 화면) | 지금 창고에 **있는** SN과 위치                   |
| SN수불            | SN이 **언제 들어오고 나갔는지** 이력 (이미 출고된 SN 포함) |

{% hint style="info" %}
이 화면에는 **현재 보유 중인 SN만** 표시됩니다. 이미 출고된 SN은 SN수불에서 확인하세요.
{% endhint %}

### 1. 조회 조건

#### 1.1 바코드 스캔

**바코드 스캔 (품목 · 로케이션 · SN)** 을 눌러 스캔 영역을 펼칩니다. (모바일에서는 처음부터 펼쳐져 있습니다.)

| 스캔한 바코드        | 채워지는 조건  | 안내 메시지         |
| -------------- | -------- | -------------- |
| SN이 포함된 품목 바코드 | **SN번호** | SN \[…] 필터 적용됨 |
| 품목 바코드 (SN 없음) | **품목**   | 품목 \[…] 적용됨    |
| 로케이션 바코드       | **로케이션** | 로케이션 \[…] 적용됨  |

| 이런 메시지가 나오면         | 의미                    |
| ------------------- | --------------------- |
| 해당 품목을 찾을 수 없습니다.   | 등록되지 않은 품목 바코드입니다.    |
| 해당 로케이션을 찾을 수 없습니다. | 등록되지 않은 로케이션 바코드입니다.  |
| 인식할 수 없는 바코드입니다.    | 품목·로케이션·SN 바코드가 아닙니다. |

{% hint style="success" %}
**로케이션의 SN 확인하기**: 랙 앞에서 로케이션 바코드를 스캔하고 조회하면, 그 로케이션에 있어야 할 SN 목록을 바로 볼 수 있습니다.
{% endhint %}

#### 1.2 SN번호

SN번호로 검색합니다. **일부만 입력해도** 검색됩니다. (예: 끝자리 `0042`)

#### 1.3 상세 필터

**상세 필터 (품목, 로케이션)** 을 눌러 펼치거나 접을 수 있습니다. (PC에서는 처음부터 펼쳐져 있습니다.)

| 항목   | 설명                     |
| ---- | ---------------------- |
| 품목   | 특정 품목의 SN만 조회합니다.      |
| 로케이션 | 특정 로케이션에 있는 SN만 조회합니다. |

모든 조건을 정한 뒤 **🔍 조회**를 누릅니다.

***

### 2. 조회 결과

| 컬럼    | 설명                                          |
| ----- | ------------------------------------------- |
| SN번호  | 시리얼 번호                                      |
| 품목코드  | 품목 코드 (**코드 표시**를 눌러야 보임)                   |
| 품목명   | 품목 이름                                       |
| 로케이션  | 로케이션 코드 (**코드 표시**를 눌러야 보임)                 |
| 로케이션명 | SN이 현재 있는 로케이션                              |
| LOT   | 로트번호                                        |
| 입고일   | 재고의 입고일                                     |
| 변경    | **🔄 변경** 버튼. 누르면 SN 변경 창이 열립니다. (아래 3. 참고) |

* 목록 오른쪽 위의 **👁️ 코드 표시 / 코드 숨기기**로 품목코드·로케이션 컬럼을 보이거나 숨길 수 있습니다.
* 한 페이지에 **100건**씩 표시됩니다. 하단에서 바꿀 수 있습니다.

***

### 3. SN 변경

라벨이 잘못 붙었거나 SN을 잘못 입력해서 등록된 경우, 보유 중인 SN의 번호를 바꿀 수 있습니다.

1. 목록에서 변경할 SN을 찾습니다. (SN 바코드를 스캔하고 조회하면 빠릅니다.)
2. 해당 줄의 **🔄 변경** 버튼을 클릭합니다.
3. SN 변경 창에서 내용을 입력합니다.
4. 저장하면 목록이 새로고침됩니다.

{% endhint %}

{% hint style="info" %}

### 4. 자주 묻는 질문 (FAQ)

**Q. 찾는 SN이 목록에 없어요.** \
이미 출고되었거나 아직 입고되지 않은 SN입니다. \
SN수불에서 SN번호로 이력을 확인해 주세요.

**Q. SN번호를 끝자리만 알아요.** \
**일부만 입력해도** 검색됩니다.

**Q. 바코드를 스캔했는데 결과가 바뀌지 않아요.** \
스캔은 조건만 채웁니다. \
**조회**를 눌러 주세요.

**Q. 제품 바코드를 스캔했는데 품목 조건이 채워져요.** \
그 바코드에 SN이 들어 있지 않은 경우입니다. \
SN이 포함된 바코드를 스캔하거나 **SN번호**를 직접 입력해 주세요.

**Q. 품목코드 컬럼이 안 보여요.** \
목록 오른쪽 위의 **코드 표시** 버튼을 누르세요.

**Q. SN을 다른 로케이션으로 옮기고 싶어요.** \
위치 변경은 [move.md](move.md "mention")에서 처리합니다.
