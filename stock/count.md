# 재고실사

창고의 **실제 재고를 세어서 시스템 재고와 맞추는** 화면입니다. 로케이션별로 실제 수량을 입력하면, 시스템 수량과의 **차이만큼 재고가 자동으로 조정**됩니다.

| 차이                                                     | 의미               | 자동 처리             |
| ------------------------------------------------------ | ---------------- | ----------------- |
| <mark style="background-color:blue;">**+(플러스)**</mark> | 실제가 시스템보다 **많음** | 차이만큼 **입고 조정**    |
| <mark style="background-color:red;">**-(마이너스)**</mark> | 실제가 시스템보다 **적음** | 차이만큼 **출고 조정**    |
| 0                                                      | 일치               | 조정 없음 (실사 기록만 남음) |

```
예) 시스템수량 100, 실사수량 97  →  차이 -3  →  3개 출고 조정  →  재고 97
```

{% hint style="warning" %}
재고실사는 저장하는 즉시 **재고가 조정**되며, 저장한 뒤에는 **수정하거나 삭제할 수 없습니다.** 저장 전에 실사수량을 꼭 확인하세요.&#x20;
{% endhint %}

### 2. 재고실사 등록

목록 오른쪽 위의 **➕ 신규**를 누르면 등록 화면이 열립니다.

#### 2.1 전체 흐름

```
① 창고 선택 → 실사 시작
② 로케이션 선택 (검색 또는 바코드)  →  해당 로케이션 재고가 목록에 표시
③ 실제로 세어서 실사수량 입력
④ 다음 로케이션으로 ②~③ 반복
⑤ 저장  →  차이만큼 재고 자동 조정
```

#### 2.2 실사 시작

<figure><img src="../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

1. **창고**를 선택합니다.
2. **실사 시작**을 클릭합니다.

| 항목   | 설명                             |
| ---- | ------------------------------ |
| 실사일자 | **오늘 날짜**로 고정되며 변경할 수 없습니다.    |
| 창고   | 실사할 창고. 실사를 시작한 뒤에는 바꿀 수 없습니다. |

실사번호는 **저장할 때 발급**됩니다.

#### 2.3 로케이션 불러오기

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

실사 화면 위쪽에서 로케이션을 선택합니다. 방법은 두 가지입니다.

| 방법         | 설명                         |
| ---------- | -------------------------- |
| **검색**     | 로케이션 입력란에서 검색해 선택합니다.      |
| **바코드 스캔** | 바코드 입력란에서 로케이션 바코드를 스캔합니다. |

로케이션을 선택하면 그 로케이션의 **현재 재고가 목록에 추가**됩니다.

> A-1-3 로케이션 N건 불러옴 (실사수량 기본값=현재고)

* 여러 로케이션을 차례로 불러오면 **목록에 계속 쌓입니다.**
* **같은 로케이션을 다시 불러와도** 이미 입력한 실사수량과 확인한 SN은 그대로 유지되고, 시스템수량만 최신 값으로 바뀝니다.
* 일반 품목은 **실사수량이 현재고로 미리 채워집니다.** 실제와 다른 품목만 고치면 됩니다.
* SN 관리 품목은 실사수량이 비어 있습니다. SN을 직접 확인해야 합니다. (아래 2.6 참고)

{% hint style="warning" %}
다른 창고의 로케이션은 불러올 수 없습니다. _"로케이션 \[…]는 다른 창고 소속입니다."_ 메시지가 표시됩니다.
{% endhint %}

{% hint style="info" %}
**불러온 로케이션만 실사 대상입니다.** 불러오지 않은 로케이션의 재고는 이번 실사에서 조정되지 않습니다. 창고 일부만 나눠서 실사해도 됩니다.
{% endhint %}

#### 2.4 실사 목록 컬럼

| 컬럼         | 설명                                                                |
| ---------- | ----------------------------------------------------------------- |
| 로케이션       | 로케이션 코드                                                           |
| 품목코드 / 품목명 | 품목. **신규** 라인만 품목을 선택할 수 있습니다.                                    |
| 로트번호       | **신규** 라인 중 LOT 관리 품목만 입력할 수 있습니다.                                |
| 입고일        | 재고의 입고일 (수정 불가, 아래 참고)                                            |
| SN         | SN 관리 품목만 표시 (아래 2.6 참고)                                          |
| 시스템수량      | 시스템에 등록된 현재 수량                                                    |
| 실사수량       | **실제로 센 수량** (노란색 칸)                                              |
| 차이         | 실사수량 − 시스템수량. **많으면 파란색(+), 적으면 빨간색(−)**                          |
| 구분         | 시스템에 없던 재고를 새로 찾은 라인은 \<mark style="color:red;">**신규**\</mark> 표시 |
| 작업         | **신규** 라인만 **취소** 버튼으로 제거 가능                                      |

{% hint style="info" %}
* 라인의 셀은 **한 번 클릭**하면 바로 입력 상태가 됩니다.
* **신규** 라인의 입고일은 바코드에 입고일이 있으면 그 날짜로, 없으면 **실사일자(오늘)** 로 정해지며 직접 바꿀 수 없습니다.
{% endhint %}

#### 2.5 실사수량 입력

**직접 입력**

실사수량 칸을 클릭해서 실제로 센 수량을 입력합니다. 차이가 바로 계산되어 표시됩니다.

**품목 바코드 스캔**

로케이션을 선택한 상태에서 품목 바코드를 스캔하면 해당 품목 라인으로 바로 이동합니다.

| 상황            | 동작                                        |
| ------------- | ----------------------------------------- |
| 목록에 있는 품목     | 해당 라인의 **실사수량 칸이 입력 상태**가 됩니다. 수량을 입력하세요. |
| 목록에 없는 품목     | 🆕 **신규 발견**으로 새 라인이 추가됩니다. 실사수량을 입력하세요.  |
| 로케이션을 선택하지 않음 | _"먼저 로케이션을 선택해주세요."_                      |

{% hint style="info" %}
LOT 관리 품목은 로트번호가 포함된 바코드를 스캔해야 정확한 라인을 찾습니다.
{% endhint %}

**수동추가**

시스템에 없는 재고를 발견했는데 바코드가 없다면 **➕ 수동추가 (선택된 로케이션 기준)** 를 누르세요. 현재 선택된 로케이션으로 신규 라인이 추가되며, **품목**과 **실사수량**을 입력합니다. LOT 관리 품목이라면 **로트번호**도 입력합니다. 입고일은 실사일자(오늘)로 정해집니다.

{% hint style="info" %}
* 수동추가는 로케이션을 먼저 선택해야 사용할 수 있습니다.
* **신규** 라인만 **취소**로 제거할 수 있습니다. 로케이션에서 불러온 라인은 제거할 수 없습니다.
{% endhint %}

#### 2.6 SN 관리 품목 실사

SN 관리 품목은 수량을 직접 입력하지 않고 **SN을 하나씩 확인**합니다. 확인한 SN 개수가 실사수량이 됩니다.

**SN실사 버튼**

```
SN실사 (확인한 개수 / 시스템 개수)   -N  +N
```

| 표시                                                 | 의미                                 |
| -------------------------------------------------- | ---------------------------------- |
| `SN실사 (8/10)`                                      | 시스템에는 10개, 지금까지 8개 확인              |
| <mark style="background-color:red;">**-N**</mark>  | 시스템에는 있는데 **찾지 못한 SN** 개수 → 출고 조정  |
| <mark style="background-color:blue;">**+N**</mark> | 시스템에는 없는데 **새로 발견한 SN** 개수 → 입고 조정 |

**SN 확인 방법**

| 방법          | 설명                                                          |
| ----------- | ----------------------------------------------------------- |
| **SN실사 버튼** | 버튼을 눌러 **SN 실사 창**에서 SN을 확인합니다. (아래 참고)                     |
| **바코드 스캔**  | 실사 화면의 바코드 입력란에서 SN이 포함된 품목 바코드를 스캔하면 창을 열지 않고 바로 확인 처리됩니다. |

**SN 실사 창**

<figure><img src="../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

SN 실사 창에는 **시스템에 등록된 SN 목록**이 표시되고, 하나씩 확인하면 상태가 바뀝니다.

| 상태                                                    | 의미                                         |
| ----------------------------------------------------- | ------------------------------------------ |
| <mark style="background-color:green;">**✔ 확인**</mark> | 시스템에 있고, 실제로도 확인한 SN                       |
| **○ 미확인**                                             | 시스템에 있는데 아직 확인하지 않은 SN. 그대로 저장하면 **출고 조정** |
| <mark style="background-color:blue;">**⊕ 추가**</mark>  | 시스템에 없는데 새로 발견한 SN. 저장하면 **입고 조정**         |

| 기능        | 설명                                                |
| --------- | ------------------------------------------------- |
| SN 입력란    | SN을 스캔하거나 입력하고 `Enter` (또는 **➕ 추가**)              |
| ✓ 버튼      | **미확인** SN 옆의 ✓를 누르면 스캔 없이 확인 처리합니다. (눈으로 확인한 경우) |
| 🗑️ 버튼    | 확인·추가한 SN을 실사 목록에서 뺍니다.                           |
| **전체 일치** | 시스템 SN을 **모두 확인 처리**합니다. 실제와 시스템이 같을 때 사용하세요.     |
| **초기화**   | 확인한 SN을 모두 비웁니다.                                  |
| 확인 진행바    | `확인 N / 대상 N` 으로 진행 상황을 보여주며, 모두 확인하면 초록색이 됩니다.   |
| **확인**    | 실사 결과를 라인에 반영합니다. 확인한 SN 개수가 실사수량이 됩니다.           |
| **닫기**    | 반영하지 않고 창을 닫습니다.                                  |

{% hint style="warning" %}
SN 실사 창에서 작업한 내용은 **확인**을 눌러야 라인에 반영됩니다. **닫기**를 누르면 이번에 확인한 내용은 반영되지 않습니다.
{% endhint %}

**SN 바코드 스캔 결과**

| 상황                                       | 동작                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------- |
| 시스템에 있는 SN                               | ✅ _"SN 확인: …"_                                                       |
| 이미 확인한 SN                                | _"이미 실사한 SN입니다: …"_                                                  |
| 시스템에 없는 SN                               | ➕ _"시스템에 없는 SN 추가: …"_ (+로 집계)                                       |
| 다른 라인에서 이미 확인한 SN                        | _"다른 라인에서 이미 실사한 SN입니다."_ (SN 실사 창)                                  |
| **다른 로케이션**에 있는 SN                       | _"(로케이션)에 있는 SN입니다. 재고이동으로 처리하세요: …"_ → 추가되지 않음                      |
| 같은 로케이션의 **다른 재고 라인**(로트·입고일이 다름)에 속한 SN | _"같은 로케이션의 다른 재고 라인(LOT/입고일)에 속한 SN입니다. 해당 라인에서 확인하세요: …"_ → 추가되지 않음 |
| 목록에 없는 품목의 SN                            | 🆕 신규 라인이 추가되고 SN이 등록됩니다.                                            |

{% hint style="info" %}
다른 로케이션에 있어야 할 SN을 여기서 발견했다면, 실사로 처리하지 말고 재고이동으로 원래 위치에서 이 로케이션으로 옮겨 주세요. 실사로 처리하면 한쪽은 입고, 다른 쪽은 출고 조정되어 기록이 꼬입니다.
{% endhint %}

{% hint style="warning" %}
SN 관리 품목은 SN 실사 창에서 **확인**을 누르기 전까지 실사수량이 비어 있어 **저장에서 제외**됩니다. 실제로 **하나도 없다면** SN 실사 창을 열고 아무것도 확인하지 않은 채 **확인**을 누르세요. 실사수량이 `0`이 되고, 시스템 SN이 모두 출고 조정됩니다.
{% endhint %}

#### 2.7 저장

**💾 저장**을 누르면 입력 내용을 확인한 뒤 저장합니다.

**실사수량이 비어 있는 라인이 있을 때**

> 실사수량 미입력 항목이 있습니다 N건은 실사수량이 입력되지 않아 이번 저장에서 제외됩니다. 계속하시겠습니까?

* **계속 저장**: 실사수량을 입력한 라인만 저장합니다. 제외된 라인의 재고는 그대로입니다.
* **취소**: 저장하지 않고 돌아가 수량을 마저 입력합니다.

저장되면 실사번호와 함께 완료 메시지가 표시되고, 차이만큼 재고가 조정됩니다.

> 실사 \[실사번호] 저장 완료 (N건)

{% hint style="info" %}
저장 중 확인이 필요한 내용이 있으면 ⚠️ 안내 메시지가 함께 표시됩니다. 내용을 확인해 주세요.
{% endhint %}

**저장 전 확인 항목**

실사수량을 입력한 라인만 확인합니다.

| 상황                | 안내 메시지                                 |
| ----------------- | -------------------------------------- |
| 실사수량을 입력한 라인이 없음  | 실사수량이 입력된 항목이 없습니다.                    |
| 신규 라인에 품목·로케이션 없음 | 신규라인은 품목/로케이션을 모두 지정해야 합니다.            |
| 실사수량이 음수          | 실사수량은 0 이상이어야 합니다: (품목코드)              |
| 신규 라인 입고일 형식 오류   | 입고일 형식이 올바르지 않습니다 (YYYY-MM-DD): (품목코드) |
| 신규 라인 입고일이 미래     | 입고일이 오늘 이후일 수 없습니다: (품목코드)             |
| SN 개수와 실사수량 불일치   | SN 개수와 실사수량이 일치하지 않습니다: (품목코드)         |
| SN 중복             | SN이 중복되었습니다: (SN)                      |

신규 라인 중 LOT 관리 품목에 로트번호가 없거나, LOT 관리 품목이 아닌데 로트번호가 있을 때도 안내 메시지가 표시됩니다. 서버에서 저장이 거부되면 그 사유가 표시됩니다.

{% hint style="danger" %}
* 저장하지 않고 **닫기**를 누르면 실사한 내용이 모두 사라집니다.
* 저장한 뒤에는 **수정하거나 삭제할 수 없습니다.**
{% endhint %}

### 3. 재고실사 상세

목록에서 **실사번호**를 클릭하면 상세 화면이 열립니다. 상세 화면은 **조회 전용**입니다.

### 4. 실사 진행 팁

{% hint style="success" %}
**정확한 실사를 위한 권장 순서**

1. 실사하는 동안에는 해당 구역의 **입고·출고·재고이동을 멈춥니다.** 실사 중에 재고가 움직이면 차이가 잘못 계산될 수 있습니다.
2. 로케이션 바코드를 스캔 → 그 로케이션의 물건을 센다 → 다른 품목만 수정 → 다음 로케이션, 순서로 진행합니다.
3. 저장 전에 **차이** 컬럼에서 큰 차이가 난 라인을 다시 한 번 확인합니다.
{% endhint %}

창고가 크다면 구역별로 나눠서 여러 번 실사해도 됩니다. 불러온 로케이션만 조정되므로 다른 구역에는 영향이 없습니다.

### 5. 자주 묻는 질문 (FAQ)

**Q. 실사수량이 이미 채워져 있어요. 그대로 저장해도 되나요?** \
일반 품목은 현재고가 기본값으로 채워집니다. \
**실제로 센 수량과 같다면** 그대로 두면 되고, 다를 때만 고치세요. \
차이가 0이면 재고는 바뀌지 않습니다.

**Q. 실사수량을 비워두면 어떻게 되나요?** \
해당 라인은 저장에서 **제외**되고 재고도 바뀌지 않습니다. \
저장할 때 제외되는 건수를 알려줍니다.

**Q. 목록에 없는 물건을 발견했어요.** \
품목 바코드를 스캔하거나 **수동추가**로 라인을 추가하세요. \
**신규** 라인으로 표시되며, 저장하면 실사수량만큼 입고 조정됩니다.

**Q. 시스템에는 있는데 실제로는 없어요.** \
실사수량에 `0`을 입력하세요. \
시스템수량만큼 출고 조정됩니다.

**Q. 불러온 라인을 목록에서 지우고 싶어요.** \
로케이션에서 불러온 라인은 지울 수 없습니다. \
이번에 조정하지 않으려면 실사수량을 비워 두세요. \
(SN 관리 품목이 아닌 경우 기본값이 채워져 있으니 지우고 비워 두면 됩니다.)

**Q. 다른 창고 로케이션이 불러와지지 않아요.** \
실사는 시작할 때 고른 창고의 로케이션만 대상입니다. \
다른 창고는 별도로 실사를 등록해 주세요.

**Q. SN 버튼 옆에 -2, +1이 보여요.** \
**-2**는 시스템에 있는데 찾지 못한 SN 2개, \
**+1**은 시스템에 없는데 새로 발견한 SN 1개입니다. \
저장하면 각각 출고·입고 조정됩니다.

**Q. SN 관리 품목이 실제로 하나도 없어요.** \
SN실사 버튼을 눌러 SN 실사 창을 열고, 아무것도 확인하지 않은 채 **확인**을 누르세요. \
실사수량이 `0`이 됩니다.

**Q. SN을 스캔했더니 "재고이동으로 처리하세요"라고 나와요.** \
그 SN은 시스템상 다른 로케이션에 있습니다. \
실사가 아니라 재고이동으로 이 로케이션으로 옮겨 주세요.

**Q. 시스템 SN과 실제가 전부 같아요. 하나씩 스캔해야 하나요?** \
SN 실사 창의 **전체 일치**를 누르면 한 번에 모두 확인 처리됩니다.

**Q. 신규 라인의 입고일을 바꾸고 싶어요.** \
신규 라인의 입고일은 바코드의 입고일 또는 실사일자로 정해지며 바꿀 수 없습니다.

**Q. 잘못 저장했어요.** \
저장한 실사는 수정·삭제할 수 없습니다. \
해당 로케이션을 다시 실사해서 올바른 수량으로 저장하면 그 차이만큼 다시 조정됩니다.
