# 재고이동

재고를 **한 로케이션에서 다른 로케이션으로 옮길 때** 사용하는 화면입니다. 재고 수량은 그대로이고, **보관 위치만 바뀝니다.**

| 이런 경우에 사용합니다                |
| --------------------------- |
| 계획 완료·취소 후 입고존·출고존에 남은 재고를 보관 로케이션으로 돌려놓을 때 |
| 랙 정리, 위치 재배치로 물건을 옮길 때      |
| 피킹하기 쉬운 곳으로 자주 나가는 품목을 옮길 때 |

{% hint style="warning" %}
재고이동은 저장하는 즉시 **재고 위치에 반영**되며, 저장한 뒤에는 **수정하거나 삭제할 수 없습니다.** 잘못 옮겼다면 도착 로케이션에서 원래 로케이션으로 다시 이동해서 바로잡아 주세요.
{% endhint %}

***

### 1. 재고를 구분하는 기준

재고는 아래 네 가지가 **모두 같아야** 같은 재고로 봅니다.

| 기준   | 예시                    |
| ---- | --------------------- |
| 품목   | 새우깡                   |
| 로케이션 | A-1-3                 |
| 로트번호 | LOT-2401 (LOT 관리 품목만) |
| 입고일  | 2026-10-01            |

같은 품목이 같은 로케이션에 있어도 로트번호나 입고일이 다르면 다른 재고입니다. 그래서 재고이동에서는 **출발 로케이션의 어떤 재고를 옮길지** 정확히 고르는 것이 중요합니다.

{% hint style="info" %}
재고를 옮겨도 **로트번호와 입고일은 그대로 유지**됩니다. 바뀌는 것은 로케이션뿐이므로, 선입선출 순서에도 영향이 없습니다.
{% endhint %}

***

### 2. 재고이동 목록

#### 2.1 조회 조건

| 항목      | 설명                                                                  |
| ------- | ------------------------------------------------------------------- |
| 키워드     | **재고이동번호, 제목, 품목코드·품목명, 로케이션코드·로케이션명**으로 검색합니다. `Enter`를 눌러도 조회됩니다. |
| 조회기간 설정 | 체크하면 기간 입력란이 나타납니다. 체크하지 않으면 기간 제한 없이 조회합니다.                        |
| 🔍 조회   | 조건에 맞는 재고이동을 조회합니다.                                                 |

{% hint style="success" %}
**특정 품목이 언제 어디로 옮겨졌는지** 찾고 싶다면 키워드에 품목명이나 로케이션 코드를 입력해 보세요.
{% endhint %}

#### 2.2 목록 컬럼

| 컬럼     | 설명                           |
| ------ | ---------------------------- |
| 재고이동번호 | 문서 번호. **클릭하면 상세 화면**이 열립니다. |
| 일자     | 재고이동 일자                      |
| 제목     | 문서 제목                        |
| 비고     | 등록할 때 입력한 메모                 |
| 등록일시   | 문서를 등록한 일시                   |
| 작성자    | 문서를 등록한 사람                   |

목록은 **일자가 최신인 순서**로 표시됩니다.

### 3. 재고이동 등록

목록 오른쪽 위의 **➕ 신규**를 누르면 등록 화면이 열립니다.

<figure><img src="../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

#### 3.1 등록 순서

1. 이동할 라인을 추가합니다. 추가 방법은 세 가지입니다.
   * **바코드 스캔** (아래 3.3 참고)
   * **라인 수동추가** 후 품목·출발·도착 로케이션 입력 (아래 3.2 참고)
   * 라인의 **📦 선택** 버튼으로 출발 재고 선택 (아래 3.4 참고)
2. 라인마다 **도착 로케이션**과 **이동수량**을 확인합니다.
3. 💾 **저장**을 클릭합니다.

**상단 입력 항목**

| 항목   | 설명                          |
| ---- | --------------------------- |
| 이동일자 | **오늘 날짜**로 고정되며 변경할 수 없습니다. |
| 제목   | **자동생성**에 체크하면 저장할 때 품목 기준(첫품목명 외 n건)으로 만들어집니다. 체크를 해제하면 직접 입력합니다. |
| 비고   | 문서 전체에 대한 메모                |

{% hint style="info" %}
재고이동은 **로케이션 단위**로 처리하므로 창고를 따로 선택하지 않습니다.
{% endhint %}

**라인 컬럼**

| 컬럼      |  필수 | 설명                                   |
| ------- | :-: | ------------------------------------ |
| 품목코드    |     | 품목을 선택하면 자동 입력                       |
| 품목명     |  ✅  | 클릭해서 품목을 검색·선택                       |
| 출발코드    |     | 출발 로케이션을 선택하면 자동 입력                  |
| 출발 로케이션 |  ✅  | 물건이 **지금 있는** 로케이션                   |
| 📦 선택   |     | 출발 재고를 골라 품목·출발 로케이션·로트·입고일을 한 번에 채움 |
| 도착코드    |     | 도착 로케이션을 선택하면 자동 입력                  |
| 도착 로케이션 |  ✅  | 물건을 **옮길** 로케이션                      |
| 로트번호    | 조건부 | **LOT 관리 품목만** 입력 가능하며, 이때는 필수       |
| 입고일     |  ✅  | 옮길 재고의 입고일                           |
| 출발 잔여수량 |     | 출발 로케이션에 있는 해당 재고의 현재 수량             |
| 이동수량    |  ✅  | 옮길 수량 (SN 관리 품목은 SN 개수로 자동 입력)       |
| SN      |     | SN 관리 품목에만 표시 (아래 3.5 참고)            |
| 삭제      |     | 라인 삭제                                |



{% hint style="warning" %}
이동수량이 **출발 잔여수량보다 많으면** 이동수량 칸이 **빨간색**으로 표시되고 저장되지 않습니다.
{% endhint %}

{% hint style="info" %}
라인의 셀은 **한 번 클릭**하면 바로 입력 상태가 됩니다.
{% endhint %}

#### 3.2 라인 수동추가

1. **➕ 라인 수동추가**를 클릭합니다. 새 라인이 추가되고 품목명 칸이 입력 상태가 됩니다.
2. **품목명**을 검색해서 선택합니다.
3. **출발 로케이션**을 검색해서 선택합니다.
4. **도착 로케이션**을 검색해서 선택합니다.
5. **이동수량**을 입력합니다.

품목과 출발 로케이션을 입력하면 시스템이 **출발 로케이션의 재고를 자동으로 찾아** 로트번호·입고일·출발 잔여수량을 채워줍니다.

| 찾은 결과                 | 동작                                            |
| --------------------- | --------------------------------------------- |
| 재고가 하나                | 로트번호·입고일·잔여수량이 자동으로 채워집니다.                    |
| 재고가 여러 개 (로트·입고일이 다름) | **재고 선택 창**이 열립니다. 옮길 재고를 고르세요.               |
| 재고가 없음                | 출발 잔여수량이 `0`으로 표시됩니다. 품목이나 출발 로케이션을 다시 확인하세요. |

로트번호나 입고일을 직접 바꾸면 그 값으로 다시 재고를 찾습니다.

#### 3.3 바코드 스캔

**바코드 스캔 (품목 또는 로케이션)** 을 눌러 스캔 영역을 펼칩니다.

<figure><img src="../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure>

스캔 영역에는 **품목 / 출발 로케이션 / 도착 로케이션** 세 칸이 있습니다. 세 칸이 모두 채워지면 라인이 자동으로 추가됩니다.

1. **품목 바코드**를 스캔합니다.
2. **출발 로케이션 바코드**를 스캔합니다.
3. **도착 로케이션 바코드**를 스캔합니다.
4. 라인이 추가되면 **이동수량**을 입력합니다.

**로케이션 스캔 시 채울 위치**

로케이션 바코드는 품목 바코드와 달리 출발인지 도착인지 구분할 수 없습니다. 그래서 **로케이션 스캔 시 채울 위치**에서 선택한 칸(**출발** 또는 **도착**)에 채워집니다.

* 기본값은 **출발**입니다.
* 출발을 채우면 **자동으로 도착으로 전환**되어, 출발 → 도착 순서로 연달아 스캔하면 됩니다.
* 순서를 바꿔야 할 때는 버튼을 직접 눌러 전환하세요.

**스캔 결과에 따른 동작**

| 상황                     | 동작                              |
| ---------------------- | ------------------------------- |
| 출발 로케이션에 일치하는 재고가 하나   | 로트·입고일·잔여수량이 채워진 라인이 추가됩니다.     |
| 일치하는 재고가 여러 개          | **재고 선택 창**이 열립니다. 옮길 재고를 고르세요. |
| 출발 로케이션에 재고가 없음        | _"출발 로케이션(…)에 해당 품목 재고가 없습니다."_ |
| LOT 관리 품목인데 로트를 알 수 없음 | _"로트번호가 포함된 바코드를 다시 스캔해주세요."_   |

**로케이션 고정 🔒**

출발 로케이션과 도착 로케이션은 각각 따로 고정할 수 있습니다.

| 고정         | 이런 때 편리합니다                                     | 스캔 방법      |
| ---------- | ---------------------------------------------- | ---------- |
| **출발 고정**  | 한 곳에 있는 여러 품목을 여기저기로 옮길 때 (예: 임시 보관 구역 → 각 보관 로케이션) | 품목 → 도착 반복 |
| **도착 고정**  | 여기저기 있는 품목을 한 곳으로 모을 때 (예: 각 로케이션 → 한 랙으로 모으기)       | 품목 → 출발 반복 |
| **둘 다 고정** | 같은 출발지에서 같은 도착지로 여러 품목을 옮길 때                   | 품목만 반복     |

**스캔 초기화 ⓧ**

잘못 스캔했다면 스캔 입력란 옆의 ⓧ 버튼으로 스캔한 내용을 비울 수 있습니다. 고정한 로케이션은 비워지지 않습니다.

{% hint style="info" %}
재고 선택 창이 열려 있는 동안에는 다음 바코드를 스캔할 수 없습니다.&#x20;

먼저 재고를 선택하거나 창을 닫아 주세요.&#x20;
{% endhint %}

#### 3.4 📦 선택 (출발 재고 선택)

라인의 **📦 선택** 버튼을 누르면 재고 목록에서 옮길 재고를 직접 고를 수 있습니다. 선택한 재고의 **품목, 출발 로케이션, 로트번호, 입고일, 잔여수량**이 라인에 한 번에 채워집니다. 도착 로케이션과 이동수량만 입력하면 됩니다.

{% hint style="success" %}
**가장 정확한 방법**입니다. 실제로 있는 재고 중에서 고르기 때문에 로트번호나 입고일을 잘못 입력할 일이 없습니다.
{% endhint %}

#### 3.5 SN 관리 품목

SN(시리얼 번호) 관리 품목은 이동수량을 직접 입력하지 않고, **옮길 제품의 SN을 찾아서** 등록합니다. 등록한 SN 개수가 이동수량이 됩니다.

1. 출발 재고가 정해진 상태에서 라인의 **SN찾기 (N)** 버튼을 클릭합니다.
2. 출발 재고에 있는 SN 중에서 옮길 제품을 고릅니다.
3. 확인하면 SN 개수만큼 이동수량이 채워집니다.

**바코드로 SN 스캔하기**

품목 바코드에 SN이 포함되어 있다면 스캔만으로 SN이 등록됩니다. **같은 출발 재고 → 같은 도착 로케이션**으로 옮기는 제품을 연달아 스캔하면 새 라인이 생기지 않고 **기존 라인에 SN이 합쳐집니다.**

```
SN-001 스캔 → 라인 추가 (이동수량 1)
SN-002 스캔 → 같은 라인에 합산 (이동수량 2)
SN-003 스캔 → 같은 라인에 합산 (이동수량 3)
```

{% hint style="success" %}
출발과 도착 로케이션을 **둘 다 고정**하고 제품 바코드만 연달아 스캔하면 가장 빠릅니다.&#x20;
{% endhint %}

{% hint style="warning" %}
* **SN찾기**는 출발 재고가 정해져야 사용할 수 있습니다. 버튼이 비활성화되어 있다면 **📦 선택**이나 **바코드 스캔**으로 재고를 먼저 지정해 주세요.
* 출발 재고에서 확인되지 않는 SN을 스캔하면 _"해당 재고에서 SN(…)을 찾을 수 없습니다."_ 메시지가 표시됩니다.
* 같은 SN을 여러 라인에 중복으로 등록할 수 없습니다.
* 품목, 출발 로케이션, 로트번호, 입고일을 바꿔서 **다른 재고가 선택되면 등록한 SN이 초기화**됩니다.
{% endhint %}

#### 3.6 입고존·출고존 재고 이동

입고존·출고존은 가입고·가출고로만 재고가 들어오는 특별한 위치입니다. 재고이동에서는 아래 규칙이 적용됩니다.

| 상황                | 동작                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------ |
| 도착 로케이션이 출고존      | 이동할 수 없습니다. _"출고존으로는 재고이동할 수 없습니다. 출고존 입고는 가출고로 처리해주세요."_                         |
| 출발 로케이션이 입고존·출고존  | 재고를 담는 순간 **출발지가 입고존·출고존입니다** 확인 창이 뜹니다. 계획 완료·취소 후 남은 재고를 일반 로케이션으로 돌려놓을 때 사용합니다. |
| 출고존 재고 중 진행 중인 출고계획 몫 | 옮길 수 없습니다. **진행 중인 출고계획 몫은 이동할 수 없습니다** 창에 품목별 이동 가능 수량과 계획번호가 표시됩니다.            |
| 강제완료된 출고계획이 가출고한 재고 | **강제완료된 출고계획의 가출고 재고입니다** 확인 창이 뜹니다. 확인하면 옮길 수 있습니다.                               |

{% hint style="info" %}
가입고한 물건을 보관 로케이션으로 옮기는 일은 [입고(적치)](../inbound/putaway.md)에서, 출고할 물건을 출고존으로 옮기는 일은 [가출고](../pre-outbound.md)에서 처리하세요.
{% endhint %}

#### 3.7 저장

**💾 저장**을 누르면 입력 내용을 확인한 뒤 저장합니다. 저장되면 문서 번호와 함께 완료 메시지가 표시됩니다.

> 재고이동 \[문서번호] 저장 완료 (N건)

**저장 전 확인 항목**

문제가 있는 라인은 **몇 번째 행인지** 함께 표시됩니다.

| 상황                     | 안내 메시지                                       |
| ---------------------- | -------------------------------------------- |
| 라인 없음                  | 이동할 라인을 1건 이상 등록해주세요.                        |
| 품목 누락                  | N번 행: 품목을 선택해주세요.                            |
| 출발 로케이션 누락             | N번 행: 출발 로케이션을 선택해주세요.                       |
| 도착 로케이션 누락             | N번 행: 도착 로케이션을 선택해주세요.                       |
| 출발과 도착이 같음             | N번 행: 출발 로케이션과 도착 로케이션이 동일합니다.               |
| LOT 관리 품목에 로트번호 없음     | N번 행: 로트번호를 입력해주세요.                          |
| LOT 관리 품목이 아닌데 로트번호 있음 | N번 행: LOT 관리 품목이 아니므로 로트번호를 입력할 수 없습니다.      |
| SN 품목인데 재고 미확정         | N번 행: 재고가 먼저 확정되어야 합니다. (품목/로케이션을 다시 선택해주세요) |
| SN 품목인데 SN 없음          | N번 행: SN을 찾아 등록해주세요.                         |
| 이동수량 없음                | N번 행: 이동수량을 입력해주세요.                          |
| SN 개수와 이동수량 불일치        | N번 행: SN을 수량만큼 찾아주세요. (N/N)                  |
| 잔여수량 초과                | N번 행: 이동수량(N)이 출발 재고 잔여수량(N)을 초과했습니다.        |

서버에서 저장이 거부되면 그 사유가 표시됩니다.

{% hint style="danger" %}
* 저장하지 않고 **닫기**를 누르면 입력한 라인이 모두 사라집니다.
* 저장한 뒤에는 **수정하거나 삭제할 수 없습니다.** 저장 전에 도착 로케이션과 이동수량을 꼭 확인하세요.&#x20;
{% endhint %}

### 5. 자주 묻는 질문 (FAQ)

**Q. 잘못 옮겼어요. 수정이나 삭제가 안 돼요.** \
재고이동은 저장 즉시 반영되어 수정·삭제할 수 없습니다. \
**도착 로케이션 → 원래 로케이션**으로 다시 이동해서 바로잡아 주세요.

**Q. 이동수량 칸이 빨간색이에요.** \
이동수량이 출발 로케이션에 있는 재고보다 많습니다. \
**출발 잔여수량**을 확인하고 수량을 줄여 주세요.

**Q. 출발 잔여수량이 0으로 나와요.** \
출발 로케이션에 해당 재고가 없다는 뜻입니다. \
품목·출발 로케이션·로트번호·입고일이 맞는지 확인하거나, **📦 선택**으로 실제 재고를 골라 주세요.

**Q. 로케이션을 스캔했는데 엉뚱한 칸에 들어가요.** \
**로케이션 스캔 시 채울 위치**가 **출발**인지 **도착**인지 확인해 주세요. \
출발을 채우면 자동으로 도착으로 바뀝니다.

**Q. 바코드를 스캔했는데 재고 선택 창이 떠요.** \
출발 로케이션에 같은 품목의 재고가 여러 개(로트번호나 입고일이 다름) 있다는 뜻입니다. \
옮길 재고를 골라 주세요.

**Q. SN 제품을 여러 개 스캔했는데 라인이 하나만 있어요.** \
정상입니다. 같은 재고를 같은 도착 로케이션으로 옮기는 SN은 한 라인에 합쳐지고, 이동수량이 SN 개수만큼 늘어납니다.

**Q. SN찾기 버튼이 눌리지 않아요.** \
출발 재고가 정해지지 않은 상태입니다. \
**📦 선택**이나 **바코드 스캔**으로 재고를 먼저 지정해 주세요.

**Q. 이동하면 입고일이 오늘로 바뀌나요?** \
아니요. 로트번호와 입고일은 그대로 유지되고 로케이션만 바뀝니다.
