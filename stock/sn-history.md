# SN수불

**SN(시리얼 번호)별로 입고·출고 이력**을 조회하는 화면입니다. 특정 제품이 **언제 들어와서, 어디에 있었고, 언제 어디로 나갔는지** 추적할 수 있습니다.

| 이런 경우에 사용합니다                  |
| ----------------------------- |
| 고객이 반품한 제품이 언제 출고된 것인지 확인할 때  |
| A/S 접수된 제품의 입고일과 거래처를 확인할 때   |
| 특정 SN이 지금 어디에 있는지 추적할 때       |
| 특정 기간 동안 들어오고 나간 SN 목록이 필요할 때 |

### 1. 조회 조건

조회 조건은 세 부분으로 되어 있습니다.

| 부분         | 내용                                                 |
| ---------- | -------------------------------------------------- |
| ① 기본 조건    | 구분, SN번호, 바코드 스캔, 상세 필터 버튼, 조회 버튼 (항상 표시)          |
| ② 상세 필터    | 입고유형, 출고유형, 품목, 로케이션, 조회기간 (**상세 필터** 버튼으로 펼치기/접기) |
| ③ 적용 중인 조건 | 지금 걸려 있는 상세 조건 목록 (조건이 있을 때만 표시)                   |

조건을 정한 뒤 **🔍 조회**를 누르면 결과가 표시됩니다.

#### 1.1 구분

| 선택                                                   | 조회 대상     |
| ---------------------------------------------------- | --------- |
| **전체**                                               | 입고와 출고 모두 |
| <mark style="background-color:blue;">**입고**</mark>   | 들어온 이력만   |
| <mark style="background-color:orange;">**출고**</mark> | 나간 이력만    |

선택한 구분은 목록의 구분 표시와 같은 색(입고 파란색, 출고 주황색)으로 표시됩니다.

#### 1.2 SN번호

SN수불의 가장 중요한 조건이라 기본 조건에 항상 표시됩니다.

* **일부만 입력해도** 검색됩니다. 예를 들어 끝자리 `0042`만 입력해도 됩니다.
* 입력한 뒤 `Enter`를 누르면 바로 조회됩니다.
* 입력란 오른쪽의 X로 입력한 SN번호를 지울 수 있습니다.

#### 1.3 바코드 스캔

SN번호 옆의 스캔 입력란에 바코드를 스캔하면 조건이 자동으로 채워집니다. (모바일에서는 화면에 들어오자마자 바로 스캔할 수 있습니다.)

| 스캔한 바코드        | 채워지는 조건  | 안내 메시지         |
| -------------- | -------- | -------------- |
| SN이 포함된 품목 바코드 | **SN번호** | SN \[…] 필터 적용됨 |
| 품목 바코드 (SN 없음) | **품목**   | 품목 \[…] 적용됨    |
| 로케이션 바코드       | **로케이션** | 로케이션 \[…] 적용됨  |

| 이런 메시지가 나오면         | 의미                    |
| ------------------- | --------------------- |
| 해당 품목을 찾을 수 없습니다.   | 등록되지 않은 품목 바코드입니다.    |
| 해당 로케이션을 찾을 수 없습니다. | 등록되지 않은 로케이션 바코드입니다.  |
| 인식할 수 없는 바코드입니다.    | 품목·로케이션·SN 바코드가 아닙니다. |

{% hint style="success" %}
**제품 하나의 이력을 빠르게 보기**: 제품의 바코드를 스캔하고 **조회**를 누르면 그 SN의 입고부터 출고까지 이력이 표시됩니다.
{% endhint %}

#### 1.4 상세 필터

**⚙ 상세 필터** 버튼을 누르면 상세 조건이 펼쳐지고, 다시 누르면 접힙니다. (PC에서는 처음부터 펼쳐져 있습니다.) 상세 조건이 걸려 있으면 버튼에 **조건 개수**가 파란 숫자로 표시되므로, 접어 두어도 필터가 적용 중인지 알 수 있습니다.

**적용 중인 조건 표시**

상세 조건을 걸면 필터 아래에 적용 중인 조건이 표시됩니다. (예: _입고유형: …_, _로케이션: …_) 조건 옆의 ✕를 누르면 그 조건만 지워지고, **초기화**를 누르면 상세 조건이 모두 지워집니다.

| 항목   | 설명                                                                            |
| ---- | ----------------------------------------------------------------------------- |
| 입고유형 | 입고 유형으로 걸러봅니다. 여러 개를 선택할 수 있습니다. 구분이 **출고**이면 _"출고 조회 중"_ 으로 표시되고 선택할 수 없습니다. |
| 출고유형 | 출고 유형으로 걸러봅니다. 여러 개를 선택할 수 있습니다. 구분이 **입고**이면 _"입고 조회 중"_ 으로 표시되고 선택할 수 없습니다. |
| 품목   | 특정 품목의 SN만 조회합니다.                                                             |
| 로케이션 | 특정 로케이션에서 처리된 SN만 조회합니다.                                                      |
| 조회기간 | 기간을 정합니다. (아래 1.5 참고)                                                         |

#### 1.5 조회기간

빠른 선택 버튼으로 기간을 정하거나, 날짜를 직접 입력합니다.

| 선택        | 조회 기간            |
| --------- | ---------------- |
| **전체 기간** | 기간 제한 없음 (처음 상태) |
| **1주**    | 7일 전 \~ 오늘       |
| **1개월**   | 한 달 전 \~ 오늘      |
| **3개월**   | 세 달 전 \~ 오늘      |
| 날짜 직접 입력  | 입력한 시작일 \~ 종료일   |

* 날짜를 직접 고치면 기간 조건이 자동으로 적용되고, 빠른 선택 버튼은 선택이 해제됩니다.
* **전체 기간**일 때는 날짜 입력란이 흐리게 표시됩니다.
* 시작일은 종료일보다 늦게 고를 수 없습니다.

#### 1.6 적용 중인 조건

상세 조건이 하나라도 걸려 있으면 조회 조건 영역 아래에 **조건 목록**이 표시됩니다.

> (품목: 무선 이어폰 ✕) (기간: 2026-09-08 \~ 2026-10-08 ✕) ↺ 초기화

| 동작          | 결과                                     |
| ----------- | -------------------------------------- |
| 조건 옆의 **✕** | 그 조건만 지웁니다.                            |
| **↺ 초기화**   | 구분을 **전체**로 바꾸고, SN번호와 모든 상세 조건을 지웁니다. |

### 2. 조회 결과

| 컬럼    | 설명                                                                                       |
| ----- | ---------------------------------------------------------------------------------------- |
| 구분    | \<mark style="color:blue;">**입고**\</mark> 또는 \<mark style="color:orange;">**출고**\</mark> |
| 유형    | 입고·출고 유형 (공통코드의 입고유형·출고유형)                                                               |
| 일자    | 처리 일자                                                                                    |
| SN번호  | 시리얼 번호                                                                                   |
| 품목코드  | 품목 코드 (**코드 표시**를 눌러야 보임)                                                                |
| 품목명   | 품목 이름                                                                                    |
| 로케이션  | 로케이션 코드 (**코드 표시**를 눌러야 보임)                                                              |
| 로케이션명 | 처리된 로케이션                                                                                 |
| LOT   | 로트번호                                                                                     |
| 문서번호  | 처리한 문서 번호 (입고, 출고, 기타입출고, 재고이동, 재고실사 등)                                                  |
| 거래처   | 입고처 또는 출고처                                                                               |
| 기타사유  | 기타입출고로 처리한 경우의 사유                                                                        |
| 비고    | 메모                                                                                       |

* 오른쪽 위의 **👁️ 코드 표시 / 코드 숨기기**로 품목코드·로케이션 컬럼을 보이거나 숨길 수 있습니다.
* 한 페이지에 **100건**씩 표시됩니다. 하단에서 바꿀 수 있습니다.

{% hint style="info" %}
**재고이동**은 출발 로케이션에서 **출고**, 도착 로케이션으로 **입고** 두 줄로 기록됩니다. **재고실사**로 조정된 SN도 입고 또는 출고로 기록됩니다.
{% endhint %}

### 3. 활용 예시

**특정 SN의 전체 이력 보기**

1. 구분을 **전체**로 둡니다.
2. **SN번호**를 입력하고 `Enter`를 누르거나, 제품 바코드를 스캔하고 **조회**를 누릅니다.
3. **일자** 순서대로 보면 입고 → 이동 → 출고 흐름을 확인할 수 있습니다.

**이번 달 특정 거래처로 출고된 SN 목록**

1. 구분을 **출고**로 선택합니다.
2. 상세 필터의 **조회기간**에 이번 달 1일 \~ 오늘을 입력합니다.
3. 필요하면 **품목**을 선택합니다.
4. **조회**를 클릭하고 **거래처** 컬럼을 확인합니다.

### 4. 자주 묻는 질문 (FAQ)

**Q. SN번호를 끝자리만 알아요.** \
**일부만 입력해도** 검색됩니다. \
입력한 뒤 `Enter`를 누르세요.

**Q. 바코드를 스캔했는데 결과가 바뀌지 않아요.** \
스캔은 조건만 채웁니다.\
**조회**를 눌러 주세요.

**Q. 제품 바코드를 스캔했는데 품목 조건이 채워져요.** \
그 바코드에 SN이 들어 있지 않은 경우입니다. \
SN이 포함된 바코드를 스캔하거나 **SN번호**를 직접 입력해 주세요.

**Q. 입고유형이 "출고 조회 중"으로 나오고 선택되지 않아요.** \
구분이 **출고**로 되어 있습니다. \
**전체**나 **입고**로 바꾸면 선택할 수 있습니다.

**Q. 구분을 바꿨더니 골라둔 유형이 사라졌어요.** \
정상입니다. \
**입고**로 바꾸면 출고유형이, **출고**로 바꾸면 입고유형이 함께 쓸 수 없어서 자동으로 지워집니다.

**Q. 품목(또는 로케이션) 조건을 빼고 싶어요.** \
조회 조건 아래의 조건 목록에서 해당 조건 옆 X를 누르고 **조회**하세요. \
모든 조건을 지우려면 **↺ 초기화**를 누르세요.

**Q. 상세 필터를 접어 놨는데 결과가 적게 나와요.** \
**상세 필터** 버튼에 숫자가 있다면 조건이 걸려 있는 상태입니다. \
아래 조건 목록에서 확인하고 필요 없는 조건을 지워 주세요.

**Q. 품목코드 컬럼이 안 보여요.** \
목록 오른쪽 위의 **코드 표시** 버튼을 누르세요.

**Q. 재고이동했는데 출고와 입고가 둘 다 나와요.** \
정상입니다. \
재고이동은 출발 로케이션 출고, 도착 로케이션 입고로 함께 기록됩니다.

**Q. 재고 흐름을 수량으로 보고 싶어요.** \
[history.md](history.md "mention")에서 거래별 입고·출고·재고수량을 볼 수 있습니다.
