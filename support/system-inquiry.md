# 시스템 문의

## 시스템문의

시스템을 사용하면서 생긴 **오류 신고, 기능 요청, 사용 문의**를 운영자에게 남기고 답변을 받는 게시판입니다.

<figure><img src="../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

***

### 1. 화면 구성

#### 1.1 조회 조건

| 항목      | 설명                                     |
| ------- | -------------------------------------- |
| 구분      | 문의 구분으로 걸러봅니다. 여러 개를 함께 선택할 수 있습니다.    |
| 상태      | 처리 상태로 걸러봅니다. 여러 개를 함께 선택할 수 있습니다.     |
| 제목      | 제목에 포함된 단어로 검색합니다. `Enter`를 눌러도 조회됩니다. |
| 내가 쓴 글만 | 체크하면 내가 작성한 문의만 표시합니다.                 |
| 🔍 조회   | 조건에 맞는 문의를 조회합니다.                      |

{% hint style="info" %}
구분과 상태에서 **전체**를 누르면 선택이 모두 해제되고, 해당 조건 없이 조회합니다.
{% endhint %}

#### 1.2 문의 목록

| 컬럼  | 설명                            |
| --- | ----------------------------- |
| 번호  | 문의 번호                         |
| 상태  | 처리 상태 (아래 4번 참고)              |
| 구분  | 문의 구분                         |
| 제목  | 문의 제목과 아래 표시                  |
| 작성자 | 작성자 이름 (**내가 쓴 글은 파란색**으로 표시) |
| 등록일 | 문의를 등록한 일시                    |

**제목 옆 표시**

| 표시                                                      | 의미            |
| ------------------------------------------------------- | ------------- |
| 🔒                                                      | 나만보기 글        |
| 🖼️ N                                                   | 첨부 이미지 개수     |
| 💬 N                                                    | 댓글 개수         |
| <mark style="background-color:purple;">**운영자답변**</mark> | 운영자가 답변을 남긴 글 |

목록의 행을 **클릭**하면 문의 상세가 열립니다.

하단에서 페이지를 이동하거나 한 페이지에 표시할 개수를 바꿀 수 있습니다. (기본 50개씩)

***

### 2. 문의 등록

1. 목록 오른쪽 위의 **➕ 문의 등록**을 클릭합니다.
2. **구분**을 선택합니다.
3. **제목**과 **내용**을 입력합니다.
4. 필요하면 **이미지**를 첨부합니다.
5. 공개 범위를 정합니다. (**나만보기** 체크 여부)
6. 💾 **저장**을 클릭합니다.

<figure><img src="../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>

| 항목     |  필수 | 설명                              |
| ------ | :-: | ------------------------------- |
| 구분     |  ✅  | 문의 구분 (기본값: 오류/버그)              |
| 제목     |  ✅  | 문의 제목 (최대 **200자**)             |
| 내용     |  ✅  | 문의 내용 (최대 **10,000자**, 마크다운 지원) |
| 이미지 첨부 |     | 화면 캡처 등 이미지 파일 (최대 **10개**)     |
| 나만보기   |     | 체크하면 나만 볼 수 있습니다. (아래 2.3 참고)   |

저장하면 등록한 문의의 상세 화면으로 바로 이동합니다.

**문의 구분**

| 구분                                                     | 이런 때 선택하세요             | 예시                      |
| ------------------------------------------------------ | ---------------------- | ----------------------- |
| <mark style="background-color:red;">**오류/버그**</mark>   | 화면이 동작하지 않거나 결과가 이상할 때 | 저장 버튼을 눌렀는데 오류 메시지가 나와요 |
| <mark style="background-color:purple;">**기능요청**</mark> | 새 기능이나 개선을 제안할 때       | 품목 목록을 엑셀로 내려받고 싶어요     |
| **일반문의**                                               | 사용 방법 등 그 밖의 문의        | 로케이션은 어떤 순서로 만들어야 하나요?  |

**입력 확인 안내**

저장할 때 아래 조건에 맞지 않으면 안내 메시지가 표시되고 저장되지 않습니다.

| 상황              | 안내 메시지                  |
| --------------- | ----------------------- |
| 제목이 비어 있음       | 제목을 입력해주세요.             |
| 제목이 200자를 넘음    | 제목은 200자 이내로 입력해주세요.    |
| 내용이 비어 있음       | 내용을 입력해주세요.             |
| 내용이 10,000자를 넘음 | 내용은 10,000자 이내로 입력해주세요. |

{% hint style="info" %}
제목과 내용 입력란은 최대 글자 수를 넘으면 더 이상 입력되지 않습니다.
{% endhint %}

{% hint style="success" %}
**오류를 신고할 때는** 아래 내용을 함께 적어주시면 훨씬 빠르게 처리할 수 있습니다.

* **어떤 화면**에서
* **어떤 작업**을 했을 때
* **어떤 문제**가 발생했는지
* 가능하면 **화면 캡처** 첨부
{% endhint %}

{% hint style="danger" %}
저장하지 않고 **닫기**를 누르면 작성 중인 내용이 사라집니다.
{% endhint %}

#### 2.1 내용 작성 (마크다운)

내용 입력란은 **마크다운**을 지원합니다.

* **작성** 탭에서 내용을 입력하고, **미리보기** 탭에서 실제로 보이는 모습을 확인할 수 있습니다.
* 입력란 오른쪽 위에 현재 글자 수와 최대 글자 수가 표시됩니다.

| 입력         | 결과        |
| ---------- | --------- |
| `**굵게**`   | **굵게**    |
| `- 항목`     | 글머리 기호 목록 |
| `1. 항목`    | 번호 목록     |
| `` `코드` `` | `코드`      |

#### 2.2 이미지 첨부

이미지는 세 가지 방법으로 첨부할 수 있습니다.

| 방법         | 설명                                              |
| ---------- | ----------------------------------------------- |
| **파일 선택**  | 이미지 영역의 ➕ 칸을 눌러 파일을 고릅니다. 여러 개를 한 번에 고를 수 있습니다. |
| **끌어다 놓기** | 이미지 파일을 작성 화면 위로 끌어다 놓습니다.                      |
| **붙여넣기**   | 화면을 캡처한 뒤 내용 입력란에서 `Ctrl + V` 를 누릅니다.           |

**첨부 제한**

| 항목             | 제한                                      |
| -------------- | --------------------------------------- |
| 파일 형식          | PNG, JPG, GIF, WEBP, BMP (움직이는 GIF도 가능) |
| 파일당 용량         | 최대 **10MB**                             |
| 한 번에 올리는 전체 용량 | 최대 **30MB**                             |
| 문의 1건당 개수      | 최대 **10개**                              |
| 댓글 1개당 개수      | 최대 **5개**                               |

| 상황         | 안내 메시지                        |
| ---------- | ----------------------------- |
| 이미지가 아닌 파일 | 이미지 파일만 첨부할 수 있습니다.           |
| 개수 초과      | 이미지는 최대 N개까지 첨부할 수 있습니다.      |
| 파일 용량 초과   | 파일당 최대 10.0MB까지 가능합니다: (파일명)  |
| 전체 용량 초과   | 한 번에 최대 30.0MB까지 업로드할 수 있습니다. |

{% hint style="info" %}
* 첨부한 이미지 아래에 파일 용량이 표시되고, ✕ 버튼을 누르면 첨부가 취소됩니다.
* **같은 파일을 두 번 선택하면 한 번만 첨부됩니다.**
* 첨부 칸에 현재 개수와 최대 개수(예: `3/10`)가 표시되며, 최대 개수에 도달하면 ➕ 칸이 사라집니다.
* 이미지가 많아 전체 용량이 30MB를 넘는다면, 일부만 먼저 등록하고 나머지는 **수정**이나 **댓글**로 나눠서 올려 주세요.
{% endhint %}

#### 2.3 공개 범위 (나만보기)

| 설정              | 볼 수 있는 사람                       |
| --------------- | ------------------------------- |
| 나만보기 **체크 안 함** | 같은 회사의 모든 사용자                   |
| 나만보기 **체크** 🔒  | 작성자 본인 (운영자는 답변을 위해 확인할 수 있습니다) |

{% hint style="warning" %}
데모시연기업에서 작성한 문의는 항상 나만보기로 등록되며, 변경할 수 없습니다.&#x20;
{% endhint %}

***

### 3. 문의 상세

목록에서 문의를 클릭하면 상세 화면이 열립니다.

<figure><img src="../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>

상세 화면 위쪽에는 **상태, 구분, 나만보기 여부, 작성자, 등록일**이 표시되고, 완료된 문의는 **완료 일시와 처리자**도 함께 표시됩니다.

첨부 이미지를 클릭하면 **크게 볼 수 있습니다.** 크게 본 이미지를 다시 클릭하면 닫힙니다.

#### 3.1 문의 수정

1. 상세 화면 위쪽의 ✏️ **수정**을 클릭합니다.
2. 구분, 제목, 내용, 이미지, 나만보기를 수정합니다.
3. 💾 **저장**을 클릭합니다.

**첨부 이미지 수정**

* 기존 이미지의 ✕ 버튼을 누르면 **삭제 표시**가 됩니다. 저장할 때 실제로 삭제됩니다.
* 삭제 표시한 이미지의 ↩️ 버튼을 누르면 삭제가 취소됩니다.
* 새 이미지는 등록할 때와 같은 방법으로 추가합니다.
* 기존 이미지와 새 이미지를 합쳐 **최대 10개**까지 첨부할 수 있습니다. 삭제 표시한 이미지는 개수에서 빠집니다.

수정 중에 **취소**를 누르면 수정한 내용은 반영되지 않고 상세 화면으로 돌아갑니다.

#### 3.2 문의 삭제

1. 상세 화면 위쪽의 🗑️ **삭제**를 클릭합니다.
2. 확인 창에서 **삭제**를 클릭합니다.

{% hint style="danger" %}
삭제한 문의는 **복구할 수 없습니다.**
{% endhint %}

{% hint style="warning" %}
**수정 / 삭제** 버튼은 내가 쓴 글에만 표시됩니다. 운영자가 **완료** 처리한 문의는 수정하거나 삭제할 수 없습니다.
{% endhint %}

#### 3.3 댓글

상세 화면 아래쪽에서 댓글로 운영자와 대화를 이어갈 수 있습니다.

1. 댓글 입력란에 내용을 입력합니다. (최대 **5,000자**, 마크다운 지원)
2. 필요하면 이미지를 첨부합니다. (최대 **5개**, 끌어다 놓기, `Ctrl + V` 붙여넣기 가능)
3. ➤ **등록**을 클릭합니다.

{% hint style="info" %}
**이미지만으로도** 댓글을 등록할 수 있습니다. 내용과 이미지가 모두 비어 있으면 _"댓글 내용 또는 이미지를 입력해주세요."_ 메시지가 표시됩니다.
{% endhint %}

* 운영자가 남긴 댓글은 <mark style="background-color:purple;">**운영자**</mark> 표시와 함께 다른 색 배경으로 표시됩니다.
* 내가 쓴 댓글은 🗑️ 버튼으로 삭제할 수 있습니다.
* 문의가 **완료**된 뒤에도 댓글은 계속 남길 수 있습니다.

### 4. 처리 상태

문의의 처리 상태는 **운영자가 변경**합니다.

```
접수  →  진행  →  완료
```

| 상태                                                     | 의미                        | 작성자가 할 수 있는 것          |
| ------------------------------------------------------ | ------------------------- | ---------------------- |
| <mark style="background-color:orange;">**접수**</mark>   | 문의가 등록되어 운영자의 확인을 기다리는 상태 | 수정, 삭제, 댓글             |
| <mark style="background-color:blue;">**진행**</mark>     | 운영자가 확인하고 처리 중인 상태        | 수정, 삭제, 댓글             |
| <mark style="background-color:$success;">**완료**</mark> | 처리가 끝난 상태                 | **댓글만 가능** (수정, 삭제 불가) |

{% hint style="info" %}
운영자가 답변을 남기면 목록의 제목 옆에 <mark style="background-color:purple;">**운영자답변**</mark> 표시가 나타납니다. **내가 쓴 글만**을 체크해서 내 문의의 답변 여부를 한눈에 확인해 보세요.&#x20;
{% endhint %}

### 5. 자주 묻는 질문 (FAQ)

**Q. 같은 회사 동료가 쓴 문의도 볼 수 있나요?** \
네. 나만보기로 등록하지 않은 문의는 같은 회사 사용자 모두 볼 수 있습니다. \
같은 문제를 이미 문의했는지 먼저 확인해 보세요.

**Q. 나만보기를 체크할 수 없어요. 항상 체크되어 있어요.** \
체험 계정은 모든 문의가 나만보기로 등록됩니다.

**Q. 수정 / 삭제 버튼이 보이지 않아요.** \
다른 사람이 쓴 글이거나, 운영자가 **완료** 처리한 문의입니다. \
추가로 전할 내용이 있다면 댓글을 남겨 주세요.

**Q. 화면 캡처를 바로 붙여넣을 수 있나요?** \
네. 캡처한 뒤 내용 입력란이나 댓글 입력란에서 `Ctrl + V` 를 누르면 이미지로 첨부됩니다.

**Q. 이미지가 첨부되지 않아요.** \
PNG, JPG, GIF, WEBP, BMP 파일인지 확인해 주세요. \
파일당 **10MB**, 한 번에 **30MB**, 문의 1건당 **10개**(댓글은 **5개**)까지 첨부할 수 있습니다.

**Q. 완료된 문의에 추가로 궁금한 게 생겼어요.** \
완료된 문의에도 댓글을 남길 수 있습니다. \
내용이 다르다면 새 문의로 등록해 주세요.

**Q. 어떤 구분을 골라야 할지 모르겠어요.** \
문제가 생겼다면 **오류/버그**, 새로운 기능을 원한다면 **기능요청**, 그 밖의 궁금한 점은 **일반문의**를 선택해 주세요. 구분은 등록한 뒤에도 수정할 수 있습니다.

**Q. 내 문의가 처리되고 있는지 어떻게 알 수 있나요?** \
목록의 **상태**를 확인해 주세요. \
**접수 → 진행 → 완료** 순서로 바뀝니다.

### 6. 키 조작 요약

| 키          | 위치          | 동작         |
| ---------- | ----------- | ---------- |
| `Enter`    | 제목 검색창      | 조회         |
| `Ctrl + V` | 내용 / 댓글 입력란 | 복사한 이미지 첨부 |
