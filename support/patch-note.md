# 패치노트

EasyWare에 **새로 추가되거나 바뀐 기능**은 패치노트에서 확인할 수 있습니다. 패치노트는 별도 페이지(노션)로 운영합니다.

> 📷 **[이미지]** 단계별 일러스트: ① 사이드바 '운영지원 > 패치노트' 또는 사이드바 아래 버전 표시 클릭 → ② 새 탭에서 패치노트 페이지 열림 흐름을 보여주는 그림

***

### 패치노트 여는 방법

| 방법            | 설명                                         |
| ------------- | ------------------------------------------ |
| **사이드바 메뉴**   | **운영지원 > 패치노트**를 누릅니다.                     |
| **버전 표시**     | 사이드바 맨 아래의 버전 표시(예: `v0.2.0`)를 누릅니다. (_패치노트 보기_) |

패치노트는 **새 탭**에서 열립니다.
