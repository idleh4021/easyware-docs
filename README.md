## EasyWare에 오신 것을 환영합니다. 


EasyWare는 창고에서 일어나는 **입고, 출고, 재고 관리**를 하나의 시스템에서 쉽고 정확하게 처리할 수 있도록 만든 웹 기반 창고관리시스템(WMS)입니다. 작은 창고에서 바로 시작할 수 있고, 업무 규모가 커져도 같은 방식으로 계속 사용할 수 있습니다.

### EasyWare로 할 수 있는 일

* **입고 관리** \
  입고 예정 등록부터 화물 도착 확인, 지정된 위치에 보관(적치)하기까지 한 흐름으로 관리합니다.
* **출고 관리** \
  출고 예정 등록, 물건 꺼내기(피킹), 출고 준비, 실제 출고까지 단계별로 처리합니다.
* **재고 관리** \
  현재 어떤 물건이 어디에 얼마나 있는지 확인하고, 입출고 내역 조회, 재고 이동, 재고 실사와 마감까지 할 수 있습니다.
* **바코드 기반 작업** \
  바코드를 스캔해서 입력 실수를 줄이고 작업 속도를 높입니다. PC뿐 아니라 PDA와 모바일 환경에서도 사용할 수 있습니다.
* **품목 특성에 맞는 관리** \
  LOT 번호, 선입선출, 시리얼번호(SN)처럼 품목마다 다른 관리 방식을 지원합니다.

### 이 매뉴얼은 이런 분들을 위해 만들었습니다

* 처음 EasyWare를 사용하는 관리자
* 현장에서 입고, 출고, 재고 작업을 직접 하는 작업자
* 각 화면의 사용법이 궁금한 모든 사용자



### 이렇게 읽어 보세요

1. **처음 사용하신다면** [시스템 훑어보기](https://app.gitbook.com/s/Pd5zp2Co7sL6fXg6Xfh6/getting-started "mention")의 [process-flow.md](getting-started/process-flow.md "mention")부터 읽어 보세요. 입고에서 출고까지 이어지는 큰 흐름을 그림으로 먼저 파악할 수 있습니다.
2. **특정 화면의 사용법이 궁금하다면** 목차에서 해당 메뉴를 찾아보세요. 사이드바 메뉴 구성과 같은 순서로 정리되어 있습니다.

### 도움이 필요할 때

매뉴얼을 읽어도 해결되지 않는 점이 있다면 EasyWare 안의 [system-inquiry.md](support/system-inquiry.md "mention") 메뉴에서 문의해 주세요. 오류 제보, 기능 요청, 일반 문의를 남기실 수 있습니다.
